## 1. DiscCraft について

DiscCraft は映像・音声・静止画から DVD-Video と Blu-ray（BDMV）を作るオーサリングソフト。
メニュー、チャプター、複数の音声・字幕、ナビゲーションを組み立て、規格に合わない素材を自動で変換して、
フォルダか ISO イメージに書き出す。

できること:

- DVD-Video（`VIDEO_TS` フォルダ、ISO）と Blu-ray（`BDMV` フォルダ、ISO）
- 静止メニューとモーションメニュー、ボタンとハイライト、PSD からのメニュー作成
- 複数のビデオクリップをつないだ 1 本のタイトル、チャプター、オーディオ / 字幕トラック
- DVD に合った MPEG-2 の映像と、AC-3 / WAV / DTS の音声は、変換せずにそのまま収録
- スライドショー、再生リスト、チャプター再生リスト、ファーストプレイ、タイトルボタン
- ビルドしないプレビュー（プロジェクトプレビュー）と、ビルド結果のモニター再生
- GUI・コマンドライン・MCP で同じ操作（すべての操作はエンジンのコマンド）

できないこと（いまのところ）:

- macOS と Linux でのディスクへの書き込み。Windows ではビルドパネルの出力「ディスク」でレコーダーのディスクに書き込める。
  ほかの OS ではフォルダと ISO を作り、焼くのは別のソフトに任せる
- コピーガード（CSS、AACS など）。リージョンコードのフラグ設定だけ
- BD-J メニュー（Blu-ray は HDMV のみ）、DTS / Dolby TrueHD / DTS-HD のエンコード（DTS のファイルをディスクにそのまま入れることはできる）
- 動画の編集そのもの（編集は FilmCraft で作り、DiscCraft でディスクにする）
- 4K（Ultra HD Blu-ray）

Blu-ray の映像は SD（720×480 / 720×576）か、HD。HD は 1080p（23.976 / 24）と 720p が H.264、
1080i（59.94 / 50）が MPEG-2。ディスクの **Blu-ray のコーデック** を **H.264（すべての形式）** にすると、1080i も H.264
（インターレースのフレームとして、上のフィールドを先に。ビットレートは H.264 のもの）。SD は DVD と同じ MPEG-2 か、
**H.264（すべての形式）** なら 720×480 / 720×576 の H.264（インターレースのフレームとして。画素の形はタイトルの 4:3 / 16:9 に
合わせる。ビットレートは HD の H.264 と同じく決める。メニューは MPEG-2 のまま）。**MPEG-2（すべての形式）** にすると、
1080p と 720p も MPEG-2（その形式のフレームレートのプログレッシブの絵として。ビットレートは MPEG-2 のもの）。ビデオごとに
コーデックを選ぶこともできる（**トランスコード設定…**。4.1 を参照）。1080 の形式には 1440×1080 の幅のものもある（1440x1080 の
59.94i / 50i / 23.976p / 24p。HDV や AVCHD の大きさで、画素が 4:3 の横長なので 16:9 に見える）。映像は 1440 の幅で作り、メニューと
字幕は Blu-ray の規格の描き方どおり 1920×1080 のまま。29.97 fps や 25 fps で撮った素材は、1080i 59.94 / 50 を選ぶとそのままの速さで HD になる
（Blu-ray の規格には 1920×1080 の 29.97p / 25p がないので、1 コマを 2 フィールドに分けた 1080i で入れる）。
HD の映像のビットレートは、H.264 が平均 12 Mbps、1080i の MPEG-2 が平均 25 Mbps。タイトルが長くてディスクに収まらないときは、
収まるところまで自動で下げる（H.264 は 3 Mbps、MPEG-2 は 8 Mbps まで。それでも収まらなければビルドできない）。
容量メーターとプロジェクトのチェックも、このビットレートで見積もる。
Blu-ray にそのまま載る H.264 が入った `.m2ts` / `.mkv` / `.mp4` / `.mov` は、変換せずにそのまま収録する（4.1 を参照）。

## 2. はじめに

### 2.1 ようこそ画面

起動するとようこそ画面が開く。

- **最近使用したプロジェクト**: 開いたことのあるファイル（最大 10 件）。行をクリックすると開く。
  右クリックの **一覧から削除** で一覧から外す（ファイルは消えない）。なくなったファイルは灰色になり、開けない
- **新規プロジェクト**: 新規プロジェクトダイアログを開く
- **プロジェクトを開く…**: `.dcproj` を選ぶ
- **終了**: アプリを終了する

ようこそ画面を閉じたあとは、**ファイル ▸ 新規 ▸ プロジェクト**（Ctrl+N）と
**ファイル ▸ プロジェクトを開く…**（Ctrl+O）で同じことができる。

### 2.2 新規プロジェクト

**新規プロジェクト** ダイアログは **基本** と **詳細設定** の 2 タブ。

| タブ | 項目 |
|---|---|
| 基本 | 名前、場所、オーサリングモード（DVD / Blu-ray）、テレビ方式（NTSC / PAL）、Blu-ray のビデオ形式（Blu-ray のみ）、トランスコードの設定の要約 |
| 詳細設定 | 縦横比（4:3 / 16:9）、ディスク容量（DVD5 / DVD9、BD25 / BD50 / BD100 / BD128） |

- 場所を空にすると、保存のときに場所を聞く
- テレビ方式の初期設定は [環境設定](#15-環境設定) で変えられる
- 新しい Blu-ray のプロジェクトは HD（NTSC は 1920 x 1080 の 23.976 fps、PAL は H.264 の 1080i の 25 fps。どちらも Encore の
  新規プロジェクトのダイアログと同じ）。形式に合うファイルは
  そのままディスクに入れ、合わないものは変換する（初期設定では平均 12 Mbps の H.264、1080i は平均 25 Mbps の MPEG-2。ディスクに余裕があれば、それを使うように H.264 は 25 Mbps、
  MPEG-2 は 32 Mbps まで上げ、入りきらなければ下げる）。
  Blu-ray のビデオ形式を **SD (MPEG-2)** にすると、HD の素材は SD に縮めて変換する
- **OK** を押すと `<場所>/<名前>.dcproj` がその場で作られ、編集が始まる

あとから変えられるもの: **ファイル ▸ プロジェクト設定…** でオーサリングモード・Blu-ray のビデオ形式・縦横比・容量、
**ビルド** パネルの **ディスク情報** でディスクの名前と容量、**ディスク** パネルでディスクの設定全般
（Blu-ray の映像の大きさ SD（MPEG-2）/ HD（H.264）と、Blu-ray のコーデック **自動（SD と 1080i は MPEG-2）**・
**H.264（すべての形式）**・**MPEG-2（すべての形式）** もここ）。

### 2.3 保存

- **ファイル ▸ 保存**（Ctrl+S）。ビルドするときも先に保存される
- **ファイル ▸ 別名で保存…**（Shift+Ctrl+S）
- 未保存の変更がある状態でプロジェクトを閉じる・開き直す・終了しようとすると確認が出る

プロジェクト（`.dcproj`）は JSON のテキストファイル。素材はコピーせず、パスで参照する。
素材を別の場所に動かすと「オフライン」になるので、**アセットを置き換え…** で新しい場所を教える。
プロジェクトの横に `<プロジェクト>.menus` フォルダができることがある（メニューを PhotoCraft などで編集するときの
PSD を入れる場所）。

### 2.4 設定の保存場所

ワークスペースの並び、表示言語、最近使用したプロジェクト、表の列の幅は設定ファイルに保存する。

| 場所 | 内容 |
|---|---|
| Windows: `%APPDATA%\disccraft\workspace.json`<br>ほか: `~/.config/disccraft/workspace.json` | ワークスペース、パネルの並び、表示言語、最近使用したプロジェクト、既定のテレビ方式 |
| 同じフォルダの `library.json` | ライブラリに足した自分のメニュー、ボタン、背景、テキストアイテム、レイヤーセット、置換レイヤー |

## 3. 画面の構成

メニューバーの下にツールバー、いちばん下にステータスバー、その間をパネル（ドッキングするタブグループ）が埋める。
ステータスバーには直前の操作の結果と、ビルド中の進み具合が出る（Encore にない DiscCraft だけの部分）。

### 3.1 メニューバー

**ファイル / 編集 / オブジェクト / メニュー / タイムライン / 表示 / ウィンドウ / ヘルプ** の 8 つ。
項目とショートカットは Encore の既定に寄せている。よく使うもの:

- **ファイル ▸ 新規 ▸**（プロジェクト / メニュー / タイムライン / スライドショー / 再生リスト / チャプター再生リスト）
- **ファイル ▸ 読み込み ▸**（アセット… / メニュー… / ポップアップメニュー… / メニューページ… / タイムライン… / スライドショー…）
- **ファイル ▸ プレビュー / プロジェクトをチェック… / ビルド ▸ フォルダー…・イメージ…**
- **編集 ▸ 環境設定…**、**編集 ▸ ヒストリー ▸**（取り消せる操作の一覧からまとめて巻き戻す）
- **オブジェクト ▸**（ボタンに変換 / 置換レイヤーに変換 / オブジェクトに変換、サブピクチャを作成、リンクの指定…、ドロップシャドウ…、反転、回転、アレンジ、整列、均等配置）
- **メニュー ▸**（新規メニュー、チャプターインデックスを作成、メニューを置き換え…、新規ページを追加、カラーセットを編集…、
  ユーザー操作を設定…、メニューをファイルとして保存…、メニューをテンプレートとして保存…、エンドアクションを設定…）
- **タイムライン ▸**（新規タイムライン / 新規スライドショー / 新規チャプター再生リスト、トラックの追加と削除、
  字幕の読み込みと書き出し、チャプターポイントの追加）
- **表示 ▸**（ズーム、サブピクチャの 3 状態、セーフエリア、ボタンルート、ガイド、チャプター名）
- **ウィンドウ ▸**（ワークスペース、パネルの出し入れ、表示言語）
- **ヘルプ ▸**（ArtCraft の Discord に参加… / ArtCraft の Web サイト / GitHub の DiscCraft / 問題を報告… /
  ログファイルを表示… / システム互換性レポート… / アップデートを確認… / DiscCraft について / DiscCraft ヘルプ…（F1））。
  項目にポインターを置くと、開くアドレスか、することが出る。**DiscCraft ヘルプ…** はこのマニュアルを開く

### 3.2 ツールバー

左にメニュー編集のツール、右端にワークスペースの選択。

| ツール | キー |
|---|---|
| 選択ツール | V |
| ダイレクト選択ツール | A |
| 移動ツール | M |
| 回転ツール | R |
| 横書き文字ツール | T |
| 縦書き文字ツール | Y |
| ズームツール | Z |

その右に **メニューを PhotoCraft で編集**（Shift+Ctrl+M）と **プレビュー**（Alt+Ctrl+Space）のボタンがある。

### 3.3 パネル

初期設定のワークスペースの並びは Encore と同じ。

| 場所 | タブ |
|---|---|
| 左 | プロジェクト / メニュー / タイムライン / ビルド |
| 中央 | モニター / メニュービューア / フローチャート |
| 右上 | プロパティ / ディスク |
| 右下 | ライブラリ / レイヤー |
| 下 | タイムラインビューア / スライドショービューア |

- **プロジェクト**: すべての項目（アセット、タイムライン、メニュー、スライドショー、再生リスト、チャプター再生リスト、
  フォルダー）の一覧。列は並べ替え・表示 / 非表示・幅の調整ができる。右クリックに 開く / 名前の変更… /
  ファーストプレイに設定 / アセットを置き換え… / エクスプローラーで表示 / 削除 など
- **メニュー**: メニューの一覧と、選んだメニューのボタン一覧。メニューの右クリックは Encore と同じく ファーストプレイに
  設定 / コピー / 消去 / 名前の変更… / メニューを PhotoCraft で編集 / 開く / ここからプレビューする、ボタンの右クリックは
  消去 / メニュービューアで開く / リンクを開く / ここからプレビューする（そのボタンを選んだメニューから）
- **タイムライン**: タイムラインの一覧と、その下に選んだタイムラインのチャプター（番号、名前、タイムライン、チャプター
  イン、ポスター）。クリックでチャプターを選び、ダブルクリックでタイムラインビューアに開く。タイムラインの右クリックは
  ファーストプレイに設定 / コピー / 消去 / 名前の変更… / 開く / ここからプレビューする、チャプターの右クリックは 消去 /
  開く / ここからプレビューする（そのチャプターからタイトルを）。最初のチャプターは消去できない
- **ビルド**: [ビルドパネル](#13-ビルドする)
- **モニター**: ビルドしたディスクの再生と、タイムラインのプレビュー。下の操作バーにタイムコードとズーム、
  チャプターの旗付きのスクラブバー、再生 / 停止 / 前・次のチャプター / 前後 1 フレーム / チャプターポイントを追加 /
  ポスターフレーム、セーフエリアと字幕のボタン、**ビルド結果を開く** がある
- **メニュービューア**: メニューのキャンバス。タブの名前は開いているメニューの名前になる
- **フローチャート**: 項目とリンクの図。ノードはドラッグで動かせる
- **プロパティ**: 選んでいる項目のシート。何も選んでいないときはディスクの設定
- **ディスク**: ディスクの名前・説明・縦横比・オーディオ / 字幕・ユーザー操作
- **レイヤー**: メニューの層（目と鍵、`(+)` ボタンセット、`(=1)`〜`(=3)` のハイライト、T のテキスト、% の図形、背景は固定）
- **ライブラリ**: DiscCraft 独自のプリセット（メニュー / ボタン / 画像 / 背景 / レイヤーセット / シェイプ / 置換
  レイヤー）と、自分の項目（テキストアイテムも）
- **タイムラインビューア**: FilmCraft と同じ形のタイムライン（V1 / A1 / S1 の見出し、波形、チャプターの旗）
- **スライドショービューア**: スライドの一覧と並べ替え、スケールとトランジション

### 3.4 パネルの並べ替えとワークスペース

タブはドラッグで並べ替え、ほかのグループへ移動、分割、フローティングができる。中クリックか × で閉じ、
**ウィンドウ** メニューから開き直すと閉じる前の場所に戻る。並びはワークスペースごとに自動で保存される。

**ウィンドウ ▸ ワークスペース** に組み込みの 4 つと、自分で保存したものが並ぶ。

| 名前 | 前面に出すもの |
|---|---|
| 初期設定 | Encore の既定の配置（すべてのグループ） |
| メニュー | メニューの一覧、メニュービューア、レイヤー |
| ナビゲーション | フローチャート |
| ビルド | ビルドパネルとディスク |

**新規ワークスペース…** で現在の並びに名前を付けて保存する（最大 32 個、名前は 64 文字）。
**ワークスペースを削除**、**「名前」をリセット** もここ。ツールバー右端の **ワークスペース** のコンボでも切り替えられる。

## 4. 素材を読み込む

### 4.1 読み込み方

- **ファイル ▸ 読み込み ▸ アセット…**（Ctrl+I）
- ウィンドウにファイルをドラッグ＆ドロップ（フォルダを落とすと中のメディアファイルを取り出す。1 回に最大 500 件）
- **ファイル ▸ 読み込み ▸ タイムライン…**（Shift+Ctrl+T）: 選んだビデオ 1 本ごとにアセットとタイムラインを作る
- **ファイル ▸ 読み込み ▸ スライドショー…**（Shift+Ctrl+G）: 選んだ画像をスライドにしたスライドショーを 1 つ作る
- **ファイル ▸ 読み込み ▸ メニュー… / ポップアップメニュー… / メニューページ…**（Shift+Ctrl+I / Shift+Ctrl+K /
  Shift+Ctrl+U）: 階層 PSD（または PhotoCraft の `.pcraft`）をメニューにする。Encore と同じく、プロジェクトパネルには
  メニューだけが出る（PSD はメニューの一部で、アセットとしては並ばず、メニューを消すと一緒に消える）。そうした PSD を
  アセットに並べていた以前の版のプロジェクトも、開くとこの形になる

何時間もある大きな動画（数十 GB の mkv や mp4）は、取り込んだ直後は裏で開いている。そのあいだ画面は止まらず、
ステータスバーに「メディアを読み込み中…」と出て、開き終わると長さ・寸法・サムネールと容量の見積もりが入る。
一度開いたファイルの長さ・寸法・サムネールは覚えておくので、次にそのプロジェクトを開いたときは待たない
（ファイルの場所・大きさ・更新日時が同じあいだ）。
mkv（H.264）の長さ・寸法・フレームレートはファイルの先頭から読むので、それと容量の見積もりはすぐ出る。
開き終わるのを待つのはサムネールだけ。
モニターとメニューに映るフレーム、タイムラインのクリップの絵も、開き終わるまでは空のままで、画面は止まらない。
モニターの絵は裏でデコードするので、再生ヘッドをドラッグしているあいだも、間に合った絵から順に映る。

インターレースの H.264（ビデオカメラやレコーダーの 1080i や 576i / 480i。フィールドピクチャでも MBAFF のフレームでも）は
デコードできる: サムネールとモニターに絵が出て、DVD にも、ほかの形式の Blu-ray にも変換できる。1080i の Blu-ray には
今までどおり変換せずにそのまま収録する（下の「HD の Blu-ray にそのまま収録する H.264」）。
DVD と同じフレームレートのインターレースの動画（NTSC は 1080i 59.94 や 480i、PAL は 1080i 50 や 576i。MPEG-2 でも H.264 でも）は、
DVD でも 2 つのフィールドを分けたまま入る: フィールドごとに縮め、元のフィールドの順でインターレースとして記録するので、
各行で 2 つの時刻の絵が混ざらず、元と同じなめらかな動きになる（「最高のレンダリング品質を使用」のときも、こうした動画は
通常の縮め方で縮める）。符号化も、動きのある部分は 2 つのフィールドを別々に予測するので、同じビットレートでよりきれいになる。
Blu-ray のインターレースの形式（1080i 59.94 / 50 と SD）に変換するときも、同じフレームレートの動画は同じように 2 つの
フィールドを分けたまま入る（MPEG-2 ならフィールドの予測も）。下のフィールドが先の動画は、そのまま下のフィールドが先として入る。
フィルム（23.976）とほかのフレームレートの動画は今までどおりフレームとして縮める。
絵をデコードできない動画（たとえば MPEG-4 Part 2 の DivX / Xvid）も取り込めるが、変換が要るディスクでは、プロジェクトの
チェックが「絵をデコードできないため、このディスク用に変換できません。」とエラーにする（ビルドを始める前に分かる）。
絵をデコードできない動画も、タイムラインの再生では音が鳴る。モニターは黒い画面に理由を出し、時刻と再生ヘッドは
進むので、音を聞きながらチャプターポイントを置ける。
トランスポートストリーム（`.m2ts` / `.mts` / `.ts`: AVCHD のビデオカメラ、レコーダーの録画）のインターレースの H.264 も
取り込める。長さ・寸法・フレームレートはファイルの時刻とヘッダーから読み、Dolby Digital の音はそのままディスクに入る。
音（Dolby Digital、LPCM、AAC、MPEG オーディオ）は、初めて要るときにファイルから取り出してメディアキャッシュに置くので、
モニターで鳴り、波形も出て、Dolby Digital 以外の音はビルドで変換される。絵も上のとおり出て変換でき、チャプターの
サムネールも出る。

**HD の Blu-ray にそのまま収録する H.264**: `.m2ts` / `.ts` / `.mkv` / `.mp4` / `.m4v` / `.mov` の H.264 は、次のすべてに合えば再エンコードせずに
ディスクに入る（画質はそのまま、ビルドも速い）。

- ディスクのプロパティの Blu-ray の映像と、大きさ・フレームレート・走査が同じ（1080i 59.94 / 50 にはインターレースの
  1920×1080 29.97 / 25 fps、1080p 23.976 / 24 と 720p にはプログレッシブ）。1080 ラインの形式には、ビデオカメラ
  （HDV / AVCHD）の 1440×1080 も合う
- High か Main プロファイル、レベル 4.1 まで、4:2:0 の 8 ビット、ファイル全体の平均が 40 Mbps 以下
- キーフレーム（IDR）から始まる
- 1080i では、そのクリップ 1 本だけのタイムライン

こうしたファイルのクリップは、トリムしてもそのまま収録できる。インポイントはいちばん近い IDR ピクチャへ、
アウトポイントはいちばん近いキーピクチャ（またはファイルの終わり）へ吸着し、ファイル自身の音も同じ範囲に切る。
キーピクチャの前に B ピクチャがある（オープン GOP の）ファイルでは、クリップが数フレーム早く終わる。

**HD の Blu-ray にそのまま収録する HD の MPEG-2**: トランスポートストリーム（`.m2ts` / `.mts` / `.m2t` / `.ts`）や
プログラムストリーム（`.mpg` / `.vob`）（HDV のビデオカメラの 1440×1080i、放送の録画の 1920×1080i や 1440×1080i、1280×720p）の MPEG-2 のビデオも、再エンコードせずに
ディスクに入る。大きさ・フレームレート・走査がディスクの Blu-ray の映像と同じで、Main プロファイルの High か
High-1440 レベル、40 Mbps 以下のとき（フレームピクチャでも、放送の録画にある、1 フレームを 2 枚のフィールドピクチャにしたものでも）。トリムは GOP 単位で（タイムラインのトリムが GOP に吸着する）、
1080i のディスクでは 1920 x 1080 のものはタイトルのほかのクリップと並べてもそのまま入る。HDV の 1440 x 1080 は、タイトルの
そのまま入るクリップのうち 1920 x 1080 のものより多ければそのまま入る。そのタイトルは 1440 x 1080（16:9 で表示）で作り、ほかの
クリップとすき間はその大きさでエンコードする（4:3 のクリップは左右に黒）。1920 x 1080 のものもエンコードする。そうでなければ
HDV のクリップを 1920 でエンコードする。GOP の途中から始まる録画は、最初の I ピクチャの
前の B ピクチャ（2 枚ほど）が落ちる。条件に合う MPEG-2 のエレメンタリーストリーム（`.m2v`）も同じようにそのまま入り、
ファイルそのものから読む（キャッシュには小さな索引だけを置く）。

合うファイルは、プロジェクトパネルの変換の状態が「トランスコードしない」になり、容量の見積もりはファイルの大きさで数える。
音声は今までどおり（AC-3 と WAV 以外は Dolby Digital に変換する）。合わないファイルは変換し、プロパティパネルでそのアセットの
**Blu-ray トランスコードステータス** にポインターを置くと理由が出る（例: 「H.264 のレベルが 5.1（Blu-ray は 4.1 まで）」、HEVC なら
「H.264 ではない」、大きさ・フレームレート・走査の違い、平均 40 Mbps 超）。

### 4.2 読めるファイル

| 種類 | 拡張子 |
|---|---|
| 映像 | mp4、mov、m4v、avi、mkv、webm、mxf、m2v、m1v、mpg、mpeg、vob、m2ts、mts、m2t、ts、dv、dif |
| 音声 | wav、ac3、dts、mp3、aac、m4a、mka、mp2、ogg、oga、opus、flac、aif、aiff |
| 画像 | png、jpg、jpeg、bmp、tif、tiff、psd、psb、pcraft、svg |
| 字幕 | srt、vtt、txt、idx（VobSub）、sup（PGS） |
| メニューのデザイン | psd、pcraft |
| Craft の書類 | `.scraft`（SoundCraft のセッション → 音声）、`.ecproj`（EffectCraft のプロジェクト → ビデオ）、`.fcproj`（FilmCraft のシーケンス → タイムライン） |

WAV は 16 ビット・48 kHz ならそのまま（LPCM）、それ以外（44.1 kHz など）は変換して収録する。DVD では 24 ビットと
96 kHz の WAV もそのまま LPCM になる（96 kHz・24 ビットはステレオまで。4.6 Mbps を使うので、そのぶん映像の
ビットレートが下がる。そのまま使う映像と合わせて上限を超えるときは、プロジェクトのチェックが知らせる）。20 ビットの
WAV は 24 ビットとして収録する。
Blu-ray では、16・20・24 ビットで 48・96・192 kHz の WAV を、8 チャンネル・27.648 Mbps まで（24 ビット・192 kHz は
5.1 まで）そのまま LPCM にする。スピーカーの配置は、モノラル、ステレオ、前の左右にセンターやサラウンド（後ろの中央 1 つ、
または後ろか横の左右）を足したもの、5.1、7.0、7.1。それ以外の配置（2.1、4.1、6.1）や、配置を書いていない 7 チャンネルの
WAV は変換する。音声が大きいほど、映像のピークのビットレートが下がる（ストリームは 48 Mbps）。
PAL の DVD では、48 kHz の MPEG-1 Layer II（`.mp2`、`.mpa`）もそのまま収録する（NTSC の DVD と Blu-ray では変換する:
NTSC のプレーヤーは MPEG オーディオを再生できるとは限らない）。映像ファイルに
音声のストリームが複数入っているとき（2 か国語の MKV など）は、そのファイルから作るタイムラインにストリームごとの
オーディオトラックができる（8 本まで）。トラックが使うストリームの選び方は 5.4。

ビデオカメラの DV は、パソコンに取り込んだ AVI（タイプ 1 でもタイプ 2 でも）でも、そのままの `.dv` / `.dif` のファイルでも、
QuickTime のムービー（`.mov`。iMovie や Final Cut が書き出したもの）でも、Matroska（`.mkv`）でも、DiscCraft の自前のデコーダーで読む: NTSC（4:1:1）、PAL（4:2:0）、DVCPRO の PAL（4:1:1）。4:3 と 16:9。ディスク用には、
フィールドの順（下のフィールドが先）のまま変換する。タイプ 2 の AVI の音はその PCM のストリーム。DV のフレームの中の音
（タイプ 1 の AVI、そのままの DV のファイル）は、カメラがどう録っていても読む: 16 ビット（48、44.1、32 kHz）と 12 ビット・
32 kHz。ビデオカメラの 12 ビットの音 2（アフレコ用）は、録られていれば、そのファイルの 2 本目の音声のストリームになる。
DVCPRO50（4:2:2、50 Mb/s）も読む（CH3 / CH4 が 2 本目の音声のストリーム）。DVCPRO HD は読めない。

AVI の中の MPEG-1 / MPEG-2 の映像（キャプチャーボードや変換ソフトが書いたもの）も、AVI の音と一緒に読み、ディスク用に変換する。

SVG は表示する大きさで描くのでぼけない。字幕のテキストは UTF-8 / UTF-16 / Shift_JIS を読む。

EffectCraft のプロジェクト（`.ecproj`）にコンポジションがいくつもあるときは、アセットのプロパティの **コンポジション** で
使うものを選ぶ（選ばなければ、EffectCraft で開いていたコンポジション）。同じファイルをもう一度読み込めば、
アセットごとに別のコンポジションを使える。

DTS のファイル（`.dts`）は、DVD と Blu-ray のオーディオトラックにデコードせずにそのまま入る（48 kHz、1509.75 kbps まで）。
モニターとプレビューでは鳴らない。

### 4.3 素材について

- プロジェクトパネルの行に、寸法・フレームレート・長さ・変換が必要かどうかが出る
- ビデオのプロパティには **フィールドタイプ** も Encore と同じ言葉で出る: **フィールドなし（プログレッシブスキャン）**、
  **奇数フィールドから**、**偶数フィールドから**（MPEG-2 と H.264 のヘッダーから読む。H.264 は最初のピクチャのヘッダーから。MP4 と MKV のインターレースの H.264 は奇数フィールドからと出す）
- 規格に合わない素材はビルドのときに自動で変換する（音声は Dolby Digital（AC-3）192 kbps、
  ビデオのビットレートは容量に合わせて決める。既定では 9.8 Mbps まで）
- すでに DVD に合っている MPEG-2 の映像は変換しない: エレメンタリーストリーム（`.m2v`）も、映像と音が一緒に入った
  プログラムストリーム（`.mpg` / `.vob`。AC-3 の音もそのまま）も、704×480・352×480・352×240（PAL は 576 / 288 ライン）の
  映像もそのまま使う。HD の Blu-ray では DVD 用の変換は走らない
- **編集 ▸ オリジナルを編集**（Ctrl+E）で、その素材を作ったアプリ（画像は PhotoCraft、音声は SoundCraft、
  ビデオは FilmCraft または EffectCraft）で開く。保存すると自動で読み直す
- プロジェクトパネルの右クリックに **アセットを置き換え…**（offline になった素材の場所を教える）と
  **エクスプローラーで表示** がある
- 右クリックか **ファイル ▸ トランスコード** の **今すぐトランスコード** は、その素材の変換をビルドの前に済ませる。変換は裏で進み（進み具合は
  ステータスバー）、そのあいだも編集できる。終わると変換の状態が「トランスコード済み」になり、ビルドはその変換を
  使う。変換はビルドパネルの出力先の中に置く。変換が要らない素材と、絵をデコードできない素材では選べない
  （デコードできない素材は変換もできない）。**オリジナルに戻す** は、済ませた変換を捨てて「トランスコードされていません」に
  戻す（次のビルドか 今すぐトランスコード で作り直す）。**ファイル ▸ トランスコード ▸ すべてトランスコード** は、
  プロジェクトのビルドが変換するものを全部、先に済ませる
- **ファイル ▸ トランスコードされたファイルを検索 ▸ DVD… / Blu-ray…**（ビデオの右クリックにもある）で、そのディスク用に
  変換済みのファイルをビデオに結び付ける。ビデオ（DVD なら `.m2v` などの MPEG-2）を選び、続けて音声（`.ac3`、`.wav` など。
  ないときはキャンセル）を選ぶ。その種類のビルドは元の素材の代わりにそのファイルをそのまま使うので、元の素材がなくても
  よい（素材を消したあとや、ほかのソフトで変換したファイルに）。変換の状態は「トランスコード済み」になり、
  **オリジナルに戻す** で結び付けを外す。プロジェクトをファイルごと動かしても、結び付けたファイルは見つけ直す
- **ウィンドウ ▸ メタデータ** は、Encore と同じ並びで、選んだアセットのファイル（タイムラインならそのビデオ）の XMP メタデータを
  見て書き換えるパネル。上に検索欄、その下の行に選んだファイルの名前と **再読み込み**。その下に 12 の分類（ダブリンコア、基本、
  著作権管理、メディア管理、基本ジョブチケット、ページ化テキスト、ダイナミックメディア、Adobe PDF、Photoshop、EXIF の 3 つ）がいつも
  並び（アセットを選んでいないときは灰色）、開くと、その分類の標準の項目が、ファイルに値がなくても全部並ぶ（ダブリンコアなら寄稿者から
  種類までの 14 項目）。Encore が編集できる項目は入力欄（作成者やサブジェクトのようなリストは ; で区切る。レーティングは選ぶ欄、
  マーク付きはチェックボックス）、ほかは値だけ（日付は「11/10/26, 21:44:09」の形）、構造の項目は ▸ で中を開く。入力欄を離れるか
  Enter を押すと、その項目だけをすぐ書き込む（空にするとその項目を消す）。ほかの項目は書かれたまま残る。書く先は、サイドカー
  （メディアの隣の `名前.xmp` か `名前.拡張子.xmp`。読むときもファイル本体より先）があればサイドカー、PNG・JPEG・MP4 ならファイルの中
  （XMP の決まった場所。MP4 は末尾に足すので、映像のデータは動かない）、そのほか（MOV、MPEG、PSD など）は新しいサイドカー
  `名前.xmp`（同じ名前のほかのファイルがあれば `名前.拡張子.xmp`）。パネルが知らない分類は、名前空間の名前で最後に並ぶ（値だけ）。
  検索欄は、名前か値にその文字のある項目だけを残す。コマンドは `asset.getMetadata` と `asset.setMetadata`（項目は `dc:title` の形）
- **ウィンドウ ▸ 進行状況**（F10）に、ビルドや「今すぐトランスコード」が変換しているものと進み具合、まだ変換する
  ファイルの一覧（終わったものから一覧から消える）、裏で読み込んでいるメディアが出る。**停止** は変換を止める
  （それぞれ次の絵のところでやめる）: ビルドや「今すぐトランスコード」は停止として終わり、済んでいた変換は残り、
  途中だったものは次に作り直す。音声の変換は区切りごとに止まり、ビルドはほかの手順の合間でも終わる: タイトルを
  多重化している途中（DVD は次の VOBU、Blu-ray は次のユニットのところ）、ROM コンテンツのファイルのあいだ、
  イメージを書く前、イメージを書いている途中（書きかけのイメージは消す）
- 同じメニューの **トランスコード設定…** は Encore と同じ並び。左の **DVD トランスコード** に DVD の **品質プリセット**、
  **Blu-ray トランスコード** に **コーデック**・**寸法**・**フレームレート**・**フィールド** と Blu-ray の **品質プリセット**。
  HD の Blu-ray では、コーデック・寸法・フレームレートで、このビデオのタイトルを作る形式を選べ、プロジェクトの形式と
  違ってよい（たとえば 1080p23.976 のディスクに 720p59.94 のビデオ）。どの形式も MPEG-2 と H.264 のどちらでもよく（Encore と
  同じく MPEG-2 が先）、どれもほかに合うものが出て（寸法、その寸法のフレームレート。小さいものから）、フィールドはそれで
  決まり、品質プリセットの一覧はその形式・そのコーデックのものになる。一覧の **プロジェクト設定を使用** で、プロジェクトの
  形式・コーデックと自動のレートに戻る。選んだ形式にそのまま入るビデオには
  **トランスコードしない** が出る。SD の Blu-ray ではタイトルはすべてプロジェクトの形式なので灰色（右の
  **トランスコードの初期設定…** で開くプロジェクト設定で選ぶ）。右に **OK**・**キャンセル**・**品質プリセットを編集…**・**トランスコードの初期設定…** と、
  ビデオの変換（どちらの種類のディスクでも）の絵の作り方のチェック 2 つ。**最高のレンダリング品質を使用** は、フィルターで
  大きさを変える: 縮めるときは新しい画素が覆う画素を平均するので、細かいもの（細い線、細かい模様）がちらつかずに平均の色に
  なり、広げるときは画素の中心のあいだで補間する。時間がかかる。**フレームブレンドを使用** は、ディスクのフレームレートが
  ビデオと違うとき（29.97 の DVD に 24 fps のビデオなど）、ビデオの 2 つのフレームのあいだに来る絵を、前のフレームの
  くり返しにせず、それぞれへの近さで 2 つを混ぜる。どちらも初めは外れていて、変えると変換は作り直しになる。
  ビデオのアセットを選ぶと、プロパティパネルにも同じ 2 つの一覧がコンボで出て、その下にチェック 2 つが Encore と同じく灰色で出る
  （変えるのはこのトランスコード設定で）。トランスコード設定の列にはプリセットの名前が出る。プロパティパネルの
  **Blu-ray トランスコード** のコンボは Encore と同じく全部の一覧: テレビ方式の形式の Blu-ray のプリセットを両方のコーデックで、DVD の
  プリセット、SD のものを名前の順に、続けて形式とコーデックごとの **自動：<形式>**、最後に **自動**（プロジェクトの形式とコーデック）。
  選ぶと、そのビデオの形式・コーデック・レートがまとめて決まる。プロジェクトで作れないものは灰色で、理由が出る（HD の Blu-ray の
  SD のタイトル、SD の Blu-ray の HD のタイトル、SD の Blu-ray のもう一方のコーデック、MPEG-2 の SD の Blu-ray 以外の DVD のプリセット、フィルム）
- DVD の品質プリセットは Encore のもの: NTSC のプロジェクトでは先にフィルムの **NTSC DV 23.976 High quality 4Mb VBR
  2 Pass**、**7Mb VBR 2 Pass**、**8Mb CBR 1 Pass**、**NTSC DV 23.976 Low quality 4Mb CBR 1 Pass**、続いて **NTSC DV High
  quality 4Mb VBR 2 Pass**、**7Mb VBR 2 Pass**、**8Mb CBR 1 Pass**、**NTSC DV Low quality 4Mb CBR 1 Pass**、**NTSC
  Progressive High quality 7Mb VBR 2 Pass**（PAL のプロジェクトでは 23.976 のものを除いた PAL のもの）、続いて自分の
  プリセット、**自動**（初期値。ビルドがタイトルをディスクに収まるレートにする）。23.976 のプリセットはフィルムにする:
  ビデオを 1 秒 23.976 枚のプログレッシブの絵にし、3:2 プルダウンで見せる（ソフトプルダウン: 絵の指示どおりにプレーヤーが
  フィールドをくり返すので、ディスクは 29.97 で再生され、絵の数は 5 分の 4 になって 1 枚あたりのビットが増える）。
  High / Low quality は、エンコーダーが動きを探す手間（Encore の品質で 5 と 2）。Low quality のプリセットは探す範囲が狭く、
  1 画素単位までしか探さないので、変換は速く、同じビットレートでは絵が少し粗くなる。変換した MPEG-2 の映像（DVD と、1080i の
  HD の Blu-ray）は、Encore と同じく I B B P … の GOP で符号化する（参照ピクチャの間に B ピクチャ 2 枚。3:2 プルダウンで変換する
  フィルムも同じで、各ピクチャは表示の順の位置でフィールドを繰り返す）。プリセットはビデオのビットレート（ほかのタイトル
  にかかわらずそのビデオはそのレートになり、ほかは残りを分け合う。容量の見積もりにも入る）、その保ち方、音声を決める:
  **VBR 1 パス**（レートの平均がビットレートになり、最大値まで上下する）、**VBR 2 パス**（まずビデオ全体を一度通して
  調べ（何も書かない）、それから難しい場面にビットを多く、易しい場面に少なく回して変換する。時間は 2 倍かかり、進行状況の
  帯は 2 回分を通して 1 回進む）、**CBR 1 パス**（ビットレートを最大値にもする）。音声は **Dolby Digital**（192 kbit/s の
  ステレオ）か **PCM**（変換した 48 kHz 16 ビットのステレオのまま。1.536 Mbit/s なのでディスクを多く使い、そのタイトルの
  ビデオは 9.8 Mbit/s のうち残りが減る。ビデオ自身の音声と、それを使ったオーディオトラック（動かした・トリムした・
  複数のクリップのものも）に効き、プロパティパネルに出る）。そのままディスクに入るビデオは **トランスコードしない** と
  出る。そのビデオにもプリセットを選べ、選ぶとそのプリセットで変換し直し（Encore と同じ。DVD のプリセットは DVD で、Blu-ray の
  プリセットは Blu-ray で。Blu-ray にそのまま入る H.264 も）、**トランスコードしない** に戻すとファイルのまま入る。DVD と
  Blu-ray の列は、それぞれの種類のディスクにそのまま入るかどうかを出す。プリセットを変えると変換は作り直しになる（済んでいた変換の状態は「トランスコードされていません」に戻る）
- Blu-ray の品質プリセットは、プロジェクトの形式の Encore のもの: **High Quality**（25 Mbit/s、最大 30）、**Long Form**
  （9 Mbit/s、プログレッシブの形式は 8、最大 11）、**Maximum Quality**（35 Mbit/s、最大は H.264 が 35、MPEG-2 が 40）。
  名前は Encore と同じ（「1920x1080i 29.97 High Quality MPEG-2」「1920x1080p 23.976 Long Form H.264」）。続いて **自動：<形式>**。
  MPEG-2 の Long Form のプリセットは動きを探す手間が少し少ない（Encore の品質 3）。H.264 にはこの設定はない。
  Blu-ray はこの設定だけを、DVD は DVD の設定だけを使う
- **ファイル ▸ トランスコード ▸ 品質プリセットを編集…** で、自分のプリセットを残せる（32 個まで。どのプロジェクトでも
  使える）: 名前、ビデオのビットレート、**DVD** か **Blu-ray** か、エンコード（VBR 1 パス / VBR 2 パス / CBR）、
  音声（Dolby Digital / PCM。DVD のプリセットのもの）、品質（1〜5。上と同じ。新しいものは 5）。DVD のプリセットは組み込みの
  DVD のプリセットの後ろに並ぶ。Blu-ray のプリセットには **最大** のレート（ビデオのどの瞬間もこれを超えない）もあり、
  どの Blu-ray の形式でも Encore の Blu-ray のプリセットの後ろに並ぶ。エンコードは H.264 でも MPEG-2 でも効く（VBR 2 パスは
  ビデオを 2 回通し、1 回目は調べるだけ。CBR はレートをビットレートのまま保つ）
- **編集 ▸ ソースからマーカーを更新（すべてのマーカーを置換）**（Ctrl+F）は、ビューアのタイムラインの
  チャプターポイントを消して、そのビデオのファイル（MKV、MP4）に入っているチャプターに置き換える。チャプターの
  ないファイルでは何も変わらない
- **ファイル ▸ レンダリング ▸** で、ビルドより先にビルドのキャッシュへ作っておける: **プロジェクト**（変換の要る
  ビデオとスライドショーすべて。「すべてトランスコード」と同じ）、**モーションメニュー**（選んだモーションメニューの絵）、
  **スライドショー**（選んだスライドショー）。ビルドはそれをそのまま使う。プロジェクトを変えると、モーションメニューは
  作り直しになる。HD の Blu-ray のモーションメニューは、その HD の大きさで作る
- プロジェクトパネルの右クリックの **フッテージを変換…** で、ビデオのピクセルの形を決められる。
  **アセットのピクセル縦横比を使用**（初期値）はファイルの言うとおり、**ピクセル縦横比を指定** は 正方形ピクセル (1.0)、
  D1/DV NTSC (0.9091)、D1/DV NTSC ワイドスクリーン 16:9 (1.2121)、D1/DV PAL (1.0940)、D1/DV PAL ワイドスクリーン 16:9
  (1.4587)、アナモルフィック 2:1 (2.0)、HD アナモルフィック 1080 (1.333)、DVCPRO HD (1.5) から選ぶ。ファイルがピクセルの形を
  間違って（または何も）伝えていて、絵が縦長・横長につぶれて見えるときに使う。サムネール、モニター、変換のすべてが
  選んだ形に従い（絵がフレームを埋めないところには帯が入る）、済んでいた変換は作り直しになる。そのビデオから新しく作る
  タイムラインは、選んだ形で 16:9 か 4:3 になる（前に作ったタイムラインは変わらない）。そのままディスクに入るビデオ
  （DVD に入る MPEG-2）は変換しないが、タイムラインの形を名乗って入る: 16:9 のタイムラインでは 4:3 と言うファイルもディスクでは
  16:9 と記される（逆も）。変えるのはヘッダーのその数ビットだけで、ビルドのキャッシュの写しを使う
- 静止画の **フッテージを変換…** では **アルファチャンネルを無視** を選べる。透明なところのある絵（PNG など）を、
  透明を使わずにそのままの色で描く（メニューでは下の背景が透けず、スライドでは黒に重ねずにそのままの色になる）。
  アルファが壊れていたり、色を透明で消してしまっている絵に使う。静止画もビデオと同じくピクセル縦横比を選べる。
  何も選ばなければ、DVD のフレームの大きさ（720×480、720×486、720×576）の静止画は Encore と同じく SD のピクセル
  （「SD NTSC (0.9091)」）で、スライドでは 4:3 の DVD のフレームにピクセルどおりに収まる。ほかの大きさはファイルが
  言わなければ正方形ピクセル。プレビューのスライドも同じ形で映す
- 使用中の素材は削除できない。使っている項目から外すと、その項目へのリンクは未設定に戻る
- プロジェクトパネルの右クリックか **編集** メニューの **コピー** と **貼り付け**（Ctrl+C / Ctrl+V）、**複製**（Ctrl+D）で、メニュー（ページごと）、タイムライン、スライドショー、
  再生リスト、チャプター再生リストの複製を作れる。複製は「名前 2」のように番号の付いた名前で、同じフォルダーに入る。
  ほかの項目へのリンクはそのままで、自分自身へのリンクは複製を指す

## 5. タイムラインを作る

### 5.1 作成

ビデオのアセットを選んで **ファイル ▸ 新規 ▸ タイムライン**（Ctrl+T）、または **タイムライン ▸ 新規タイムライン**。
選んでいるビデオがないときは、**新規タイムライン** のサブメニューのビデオの一覧から選ぶ。
DiscCraft のタイムラインは必ずビデオを 1 本目に持つ。

FilmCraft で編集した作品からは **タイムライン ▸ FilmCraft のシーケンスからタイムラインを作成…** が使える。
**タイムライン ▸ FilmCraft のマーカーを読み込み…** で、開いているタイムラインにシーケンスのマーカーを
チャプターポイントとして追加することもできる。

### 5.2 複数のビデオクリップ

タイムラインビューアに別のビデオをドラッグすると、前のクリップの直後に詰めて置かれ、つなぎ目にチャプターができる
（1 本のタイトルに最大 99 本のクリップ）。Encore と同じく、クリップの音もその横に並ぶ: クリップの音のオーディオ
トラックに（前のクリップの音はつなぎ目で切る）、タイムラインにオーディオトラックがなければ新しいオーディオ 1 に。
オーディオトラックのない複数クリップのタイトルは、プレビューでもディスクでも各クリップの音が鳴る。
クリップと横の音は Encore と同じくリンクしていて、クリップをトリム・移動・削除すると音も同じようになり、後ろのクリップの音も
クリップと一緒に動く。
クリップの端をドラッグしてトリムする。そのままディスクに入る MPEG-2 では、切り口は GOP の頭へ吸着する。

- 変換が要らない MPEG-2 のクリップは、トリムしたままパススルーできる
- 変換が要るクリップ（H.264 など）もつないでビルドでき、DVD（と SD の Blu-ray）でもトリムしたフレームの位置どおりに
  切れる（変換がそこで GOP を始める）。トリムを動かすと、次のビルドでファイルを変換し直す
- HD の Blu-ray では、そのまま収録する H.264（5.1）はキーピクチャでトリムされる。ほかのクリップは H.264 に
  エンコードして IDR でつなぐので、指定したフレームどおりにトリムされる
- 1 本目のクリップも消せる（2 本目が新しい 1 本目になる）
- クリップの本体を左右にドラッグすると動かせる。前のクリップとの間にできた空きは、ディスクでは黒で再生される
  （モニターの再生は空きを飛ばす）。となりのクリップには重ねられない
- クリップを右クリック: **ビデオクリップを消去** は、クリップを消してその場所を空けたままにする（後ろのクリップと
  そのチャプターは動かない）。**リップル削除** は、クリップを消して後ろのクリップをその場所まで詰める。タイトルの
  ただ 1 つのクリップは消せない
- クリップ（ビデオかオーディオ）をクリックすると選ばれ、白い枠が付く。**編集 ▸ 消去**（Delete）でそのクリップを消す
  （ビデオはビデオクリップを消去と同じ。オーディオはトラックから外し、ただ 1 つのクリップならトラックごと）。
  **編集 ▸ リップル削除**（Shift+Delete）は選んだビデオクリップを消して詰める。選んでいないときは再生ヘッドの下の
  クリップ。クリップのないところやチャプターポイントをクリックすると、選択が外れる
- プログラムストリーム（`.mpg` / `.vob`）のクリップも、チャプターとトリムが GOP の頭に吸着する

音声と字幕の素材をタイムラインビューアに落とすと、A1 / S1 にはいる。

### 5.3 チャプターポイント

- 再生ヘッドの位置に **タイムライン ▸ チャプターポイントを追加**（テンキーの `*`）
- タイムラインビューアの目盛りの下の旗をドラッグしても動かせる
- **一定間隔でチャプターポイントを追加…**（既定 5 分）でまとめて打つ
- mkv や mp4 にチャプターが入っていれば、そのファイルからタイムラインを作ったときにチャプターポイントになる
  （名前も付く）。あとからは **タイムライン ▸ ソースからチャプターを読み込む**
- 旗を選んで **編集 ▸ 消去**（Delete）でそのチャプターを消す
- チャプターの名前はプロパティで付ける（空なら「チャプター N」と表示）。**表示 ▸ チャプター名を表示**（Ctrl+8）で
  タイムラインに名前を出す
- ポスターフレームはモニターの **ポスターフレーム** ボタンで、再生ヘッドの絵をセットする

DVD は 1 タイトル 99 チャプターまで。チャプターをボタンにリンクしてシーンを選ぶメニューは
[絵入りのシーン選択メニュー](#141-絵入りのシーン選択メニュー) に書く。

### 5.4 トラック

**タイムライン ▸ オーディオトラックを追加… / 字幕トラックを追加…** は下から 1 本ずつ、
**オーディオトラックを削除 / 字幕トラックを削除** は一番下のトラックから。**ディスク** パネル（何も選んでいないときの
プロパティと同じ）で、既定で聞くオーディオトラックと表示する字幕を決める。モニターでは見出しのスピーカーボタンで
聞くトラックを選ぶ。

トラックのファイルに音声のストリームが複数あるとき（MKV の各言語、ビデオカメラの 2 組目のステレオ）は、トラックの
右クリック ▸ **サウンドストリーム** ▸ **ストリーム 1**、**ストリーム 2**、… で、トラックが使うストリームを選ぶ。ディスクと
モニターはそのストリームを使う。そういうファイルから作るタイムラインは、初めからストリームごとのトラックを持つ。

オーディオトラックのクリップは、左右にドラッグして始まる位置を動かせる（フレーム単位）。動かした分だけ、トラックの
頭は無音になる。Dolby Digital（AC-3）のファイルは同じ形式の無音を前に足すだけで再エンコードせず、WAV は無音を
足して PCM のまま、ほかの音声は無音を足して Dolby Digital に変換する。DTS のトラックは動かせない（ビルドでエラーになるので、頭に戻す）。
クリップの左右の端をドラッグするとトリムできる（フレーム単位）。残る音は元の位置のままなので、頭をトリムすると
クリップの始まりも一緒に動く。端を外へ戻せば、ファイルの頭と終わりまで元に戻せる。トリムした Dolby Digital の
ファイルはそのフレーム（32 ms）の境目で切るだけで再エンコードせず、トリムした WAV は PCM のまま、ほかの音声は切って
Dolby Digital に変換する。
DTS のトラックはトリムできない。モニターとプレビューも、トリムした範囲を鳴らす。
1 本のトラックに複数のクリップを置ける（99 個まで）: クリップを始めたい位置でトラックを右クリックし、
**ここにオーディオクリップを追加 ▸** からプロジェクトの音声ファイルを選ぶか、プロジェクトパネルの音声ファイルをそのトラックの行へ
ドラッグする（クリップが始まる位置に線が出る。トラックの行以外に落とすと新しいトラックになる）。クリップには
それぞれのファイルの波形が出る。クリップ同士は重ならない: 重なる追加は
断られ、ドラッグしたクリップはとなりのクリップで止まり、端もとなりのクリップを越えない。**オーディオクリップを消去**
（複数あるトラックのクリップを右クリック）で 1 つ外せる。ディスクではそのトラックは 1 本のストリームになる:
各クリップの位置にそのファイルの範囲が入り、あいだは無音。クリップが全部 WAV なら PCM。全部が同じ形（ビットレートと
チャンネル）の Dolby Digital なら、それぞれのフレームのままつなぐ（再エンコードしない。位置は 32 ms 単位）。それ以外の
組み合わせはデコードして Dolby Digital に作り直す（
DTS のファイルは複数クリップの 1 つにできない）。モニターとプレビューも、クリップをそれぞれの位置で鳴らす。

上限はオーディオ 8 本、字幕 32 本。

### 5.5 エンドアクション、上書き、リモートメニュー

プロパティのタイムラインのシートに、Encore と同じ 3 つのリンク欄がある。

| 欄 | 意味 |
|---|---|
| エンドアクション | 最後まで再生したあとに行く先（メニュー、別のタイムライン、スライドショー、再生リスト、何もしない） |
| 上書き | エンドアクションの先が終わったあとに行く先（警告 → 本編 → 特典メニューのような流れ） |
| リモートメニュー | リモコンのメニューボタンで出るメニュー（Blu-ray ではポップアップメニュー） |

リンクの入れ方は 5 とおりある（[ボタンへのリンクの入れ方 5 とおり](#147-ボタンへのリンクの入れ方-5-とおり)）。速い 3 つ:

- 欄の右の **▶** を押してから、プロジェクトパネルの項目をクリック（ピックウィップ）
- **オブジェクト ▸ リンクの指定…**（Ctrl+L）でダイアログから選ぶ
- フローチャートでノードからノードへドラッグする

## 6. スライドショーを作る

**ファイル ▸ 新規 ▸ スライドショー**（Ctrl+G）で空のスライドショーを作り、スライドショービューアに画像をドラッグする。
画像を複数選んで **ファイル ▸ 読み込み ▸ スライドショー…**（Shift+Ctrl+G）でも作れる（名前は最初の画像の名前、
スライドの長さは既定の 6 秒）。

| 設定 | 内容 |
|---|---|
| スライドのデュレーション | 既定 6 秒。タイムコードで入力する（NTSC の 00;00;06;00） |
| スケール | 全体表示 / はみ出し / 拡大縮小なし |
| トランジション | なし / クロスディゾルブ / 黒にディップ / ワイプ。長さは 0.1〜10 秒（既定 2 秒）。スライドごとに上書きできる |
| 手動で進める | オンにすると、リモコンで進むまで各スライドで止まる。スライドを選んだときのシートの同じチェックは、そのスライドだけを止める |
| パンとズーム | スライドのプロパティの **パンとズーム** をオンにすると、スライドの間、絵がゆっくり動く（パン: なし / 左へ / 右へ / 上へ / 下へ、ズーム: ズームイン / ズームアウト / なし）。スライドショーの **ランダムにパンとズーム** は、自分の設定のないスライドすべてに動きを付ける |
| 字幕を作成 | 各スライドの名前と説明を字幕にする（**次を含む** で次のスライドの名前も入れる）。スライドごとにハイライト（グループ）・ストローク・整列を選べ、色はスライドショーのカラーセットで決める |

スライドはドラッグで並べ替え、**編集 ▸ 消去**（Delete）で消す。オーディオを足すと長さを合わせられる。
スライドの名前と説明はプロパティで書く（字幕にするとディスクのチャプター名にもなる）。

## 7. 再生リストとチャプター再生リスト

### 7.1 再生リスト

**ファイル ▸ 新規 ▸ 再生リスト…** で名前を付けて作り、プロパティに項目（タイムライン、スライドショー）を
ドラッグして入れる。上へ / 下へ、削除、ダブルクリックで開ける。メニューのボタンから再生リストへリンクできる。

### 7.2 チャプター再生リスト

タイムラインを選んで **タイムライン ▸ 新規チャプター再生リスト**。選んだタイムラインのチャプターを、
再生する順のリストにする（おまけを好きな順で観られる）。

- **連続 / ランダム / シャッフル** を選べる（Blu-ray のランダム / シャッフルも対応）
- 項目のリンク先を変えたり、別のタイムラインのチャプターも入れられる
- チャプター再生リストビューアでプレビューできる

### 7.3 チャプターインデックス

**メニュー ▸ チャプターインデックスを作成** は、チャプターごとにボタンを並べたメニューを作る。

- ビューアに開いているメニューにチャプターボタンがあるときは、リンク済みのボタンに続けて残りのチャプターを割り当てる
  （この場合、少なくとも 1 つのチャプターボタンがタイムラインにリンクしていないと作れない）
- そうでないときは、選んでいるタイムラインのチャプターごとにボタンを並べたメニューを作る（DiscCraft 独自）
- **複数ページのチャプターインデックスを作成** は 1 ページ 6 ボタンで分割し、**前へ / 次へ** ボタンを付ける
- ライブラリの **チャプターのページ**（文字のボタン）と **シーンのページ**（ビデオサムネールのボタン）は、チャプター
  ボタン 6 つと **前へ / メインメニュー / 次へ** のボタンを持つ、複数ページのチャプターインデックスのテンプレート
  （DiscCraft 独自）。新規メニューにして最初のチャプターボタンをタイムラインにリンクし、**複数ページのチャプター
  インデックスを作成** でページになる。配置はディスクの画面に合わせて伸び縮みするので、SD（4:3 / 16:9）でも HD でも使える
- ビューアに開いているメニューにチャプターボタンがあるときは、**複数ページのチャプターインデックスを作成** がその
  メニューを全ページのテンプレートにする。メニューを上と同じように埋め、ボタンが足りない分だけ、Encore と同じく
  同じメニューのページを足して（メニュー自身がページ 0、続いてページ 1、ページ 2…）、前のページの続きのチャプターを
  割り当てる。種類が **次へ** のボタンは次のページ、
  **前へ** のボタンは前のページにリンクする。そのページで使わないものは消す: 最後のチャプターより後ろの
  チャプターボタン、最後のページの 次へ、最初のページの 前へ（すでに別のところ、たとえばメインメニューへ
  リンクしている 前へ / 次へ は残す）
- 1 ページに置けるチャプターボタンは最大 18 個

## 8. メニューを作る

### 8.1 作り方

| 方法 | 結果 |
|---|---|
| **ファイル ▸ 新規 ▸ メニュー**（Ctrl+M） | 空のメニュー。Encore と同じガイドが入る |
| **ファイル ▸ 読み込み ▸ メニュー…**（Shift+Ctrl+I） | PSD / `.pcraft` をメニューにする。`(+)` で始まるグループがボタンになる |
| **ライブラリ** のプリセットで **新規メニュー** | DiscCraft 独自のテンプレートから作る |
| **メニュー ▸ 新規ページを追加** | 開いているメニューの次のページ（背景と設定は同じ）。ページは中身が空の 1 つのメニューなので、ボタンはそのページに置く。ページはメニューパネルでメニューの下に並び（**ページ 1**、**ページ 2**…）、ビューアのタブにどのページかが出る。ビューアの下の矢印でもページを移れる。レイヤーパネルでは Encore と同じく、最初のページのレイヤーの上に `(#) ページ n` のグループとして並ぶ（最後のページがいちばん上）。グループを押すとそのページを表示し、矢印で開くとそのページのレイヤーが出る。PSD から作ったメニューでは、Encore と同じく PSD のレイヤーをそのまま並べる（名前、グループの入れ子、非表示のレイヤーの目、`(+)` のボタンのセットの印。最初は表示中のページの `(#)` グループだけが開いている。開け閉めしたグループは、ページを移ってもそのまま）。ボタンのセットやその中のレイヤーを押すとそのボタンを選び、セットの目でそのボタンを隠せる。DiscCraft で足したテキスト・画像・ボタンは PSD のレイヤーの上に並ぶ。リンクの一覧では、メニューの名前 ▸ **ページ n** からそのページを選ぶ。Blu-ray では Encore と同じくページを 1 つのメニューにまとめるので、ページを移ってもボタンとそのページの絵が替わるだけで、背景の映像とメニューの音は止まらずに続く。そのためには、ページが最初のページと同じ背景・音・長さ・ループ（**新規ページを追加** で作ったまま）で、ページが 254 までであること（絵の多さは問わない）。そうでなければページごとに別のメニューとして作り、ページを移ると頭から再生し直す。ポップアップメニューのページは、タイトルの上にまとめて出る（[Blu-ray](#1410-blu-ray)）。DVD ではいつもページごとに別のメニュー |

最初に作ったメニューは、自動的に **ファーストプレイ** と **タイトルボタン** になる。

PSD のレイヤー名の決まり: `(+)` で始まるグループがボタン（Encore が作ったチャプターインデックスの `(+#)` チャプター、
`(+>)` 次のページ、`(+<)` 前のページのボタンも。種類もそのとおりになる）、`(=1)` / `(=2)` / `(=3)` がボタンのハイライト
（サブピクチャ）で、メニューのカラーセットの色 1 / 2 / 3 で描かれる。`(%)` がビデオサムネールのボタン、`(^)` が
自動アクティベート。カラーセットが **自動** のときは、Encore と同じく色をレイヤーから取る: 最初のボタンのレイヤーの色
（それぞれのレイヤーの最後の不透明な画素）がハイライトグループ 1、色の違う次のボタンがグループ 2 になり、同じ色の
ボタンはそのグループ、ほかはグループ 1 を使う。レイヤーのない色は、淡い色の 47 %。Encore と同じく、ボタンの範囲は
レイヤーセットの全レイヤー（非表示のものも）で、選んだときに出るのはそのボタン自身のハイライトのレイヤーだけ。
ハイライトのレイヤーのないセット（ボタンにした絵）は、選んでもハイライトが出ない（DiscCraft で作った、サブピクチャも
文字のハイライトもないボタンには、代わりに枠が出る）。

いちばん上の階層の、名前が `(#)` で始まるグループは、Encore と同じくメニューのページになる。そうしたグループごとに
ページができ（下にあるものが先。`(#)` のあとの名前は関係しない）、グループの中のボタンがそのページのボタン。
非表示のページのグループは、Encore と同じくページにならない。ページに出るのはグループの中のボタンだけで、グループの
そのほかのレイヤー（ボタンのセットに入っていない絵や文字）は、Encore が Blu-ray のメニューで出さないのと同じく出ない。
そうした絵はボタンのセットに入れるか、すべてのページに出すならページのグループの外に置く。
ページのグループの外の `(+)` グループが最初のページのボタンで、その外のボタンでないレイヤーはすべてのページに出る。
ページのグループの外にボタンがなければ、いちばん下のページのグループが最初のページ（Encore はそこに空の最初の
ページを作る）。Blu-ray では、これらのページは背景を止めずに移る。

PSD のレイヤースタイル（境界線、光彩、シャドウなど）は、PSD で見えるとおりにメニューの絵に入る。

**ハイライトをリッチカラーで書き出し**（メニューのプロパティの **基本**）をオンにすると、Blu-ray では Encore と
同じく、これらのレイヤーをそのままの色（グラデーションもぼかした縁もそのまま）で見せる。`(=1)` レイヤーだけの
ボタンは、選択時とアクティベート時にそれを見せる。`(=2)` か `(=3)` のレイヤーがあるボタンは、標準で `(=1)`、
選択時に `(=2)`、アクティベート時に `(=3)` を見せる（そのレイヤーのない状態では何も見せない）。メニュービューアの
**標準** / **選択時** / **アクティベート時** も同じように見せる。プロジェクトプレビューは Encore のプレビューと同じく
カラーセットの色のまま。DVD のハイライトはカラーセットの色のまま。

### 8.2 ボタン

- **メニュー ▸ ボタンを追加**、または既存のテキスト / 画像 / シェイプを選んで **オブジェクト ▸ ボタンに変換**（Ctrl+B）
- ドラッグで移動、ハンドルで大きさ変更、Shift で複数選択
- **オブジェクト ▸ 整列 / 均等配置 / アレンジ**（前面へ Ctrl+]、最前面へ Shift+Ctrl+]、背面へ Ctrl+[、
  最背面へ Shift+Ctrl+[）。**セーフエリアに相対的に整列** をオンにすると、キャンバスではなくセーフエリアの枠を基準にする
- **切り取り / コピー / 貼り付け / 複製**（Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D）、**消去**（Delete）
- ボタンは 1 メニューに最大 36 個。**初期設定ボタン**（リモコンの矢印で最初にハイライトされるボタン）は
  プロパティか右クリックで決める
- ボタンを重ねて編集できるが、**ディスクに載せるときハイライトは重ならない**（重なると赤枠が出て、チェックに
  「ボタンが重なっています。」が出る）
- **オブジェクト ▸ オブジェクトに変換** でボタンをテキストに戻す
- **オブジェクト ▸ 置換レイヤーに変換**（Ctrl+J）で、選んだ画像やシェイプを置換レイヤーにする（レイヤーパネルでは
  **(!)** が付く）。プロジェクトパネルから静止画をその上にドラッグすると、静止画がレイヤーの代わりになる（形を保って
  レイヤーに収まる大きさで中央に。レイヤーの不透明度・シャドウ・回転はそのまま）。ほかの場所に落とすと新しい
  レイヤーになる。**オブジェクトに変換** で普通のレイヤーに戻す
- **ウィンドウ ▸ 文字**（F3）に、選んだテキストかボタンの文字の設定だけが出る（プロパティと同じ行）。何も
  選んでいないときは、次に入力するテキストの設定が出る（Encore と同じ）: サイズ・色・フォント・スタイル・書式。
  テキストツールで作るテキストはその設定になる（足す操作と同じ 1 回の取り消しで消える）。**リセット** で初期設定に戻る。
  **カーニング** は **メトリクス**（フォントのペア）か、Encore と同じく一覧の数（−100〜200）または入力した数（−1000〜1000、
  1/1000 em）で、すべての文字のあいだの空きをその分だけ変える。**詰め**
  （0〜100 %）は、日本語の文字のまわりの空きを、フォントの字形ごとの空き（輪郭から測る）のその割合だけ詰める: かな・
  漢字のあいだは前の字のあとと次の字の前の空き、全角の約物は空いている側。**文字組み** は全角の約物（、。「」（）など）の
  幅を決める: **なし**、**約物半角**（すべて）、
  **行末約物半角**（行の終わりの約物だけ）、全角の 2 つ（フォントのまま）。縦書きの詰めは日本語フォントのふつうの空き
  （全角の 1 割ほど）による。**禁則処理** は、段落テキストの行を分けてはいけない場所を決める: **なし**、
  **強い禁則**（閉じ括弧・約物・小さいかな・長音で行を始めない。開き括弧で行を終えない）、**弱い禁則**（小さいかなと
  長音は行頭に来てもよい）。**禁則方法** は、行頭に来られない文字の避け方を決める: **追い込み優先**（初期値。
  全角の約物の空き半分に収まるなら前の行に入れる。句点・読点・閉じ括弧が行末から少しはみ出す。収まらなければ前の
  1 文字を連れて次の行に送る）、**追い出し優先**（前の 1 文字を連れて次の行に送る。行に分けられる場所がないときだけ
  前の行に入れる）、**追い出しのみ**（いつも前の 1 文字を連れて次の行に送る）。**ぶら下がり** をオンにすると、
  入りきらない全角の句読点（、。，．）が行末の外にぶら下がる。DiscCraft は行を詰めて場所を空けることはせず、
  ぶら下がった句読点も行揃えの幅に数える
- **段落テキスト**: テキストツール（縦書きテキストツール）でクリックの代わりにドラッグすると、ドラッグした幅
  （縦書きは高さ）の枠を持つテキストになり、その中で行が折り返す。プロパティの **折り返し: 幅で折り返す** でも
  同じで、幅もそこで決める。行は空白と日本語の文字のあいだで、禁則処理の設定に従って分かれる。自分で改行した
  ところはそのまま。枠は中身にかかわらず決めた幅で描かれ、行揃えはその中で効く。テキストを選んで枠の右の辺
  （縦書きは下の辺）の白いハンドルをドラッグすると、枠の幅が変わる。プロパティの幅でも変えられる。その下の
  **枠の高さ** か、横書きの枠の下の辺の真ん中（縦書きの枠は右の辺の真ん中。列が広がれる幅になる）の白いハンドルのドラッグで、
  枠に高さも付けられる。枠はその高さで描かれ、はみ出した行は描かれない（ディスクでも。縦書きは枠がその幅で描かれ、列は
  枠の右の辺から並び、その幅を超えた列は描かれない）。はみ出した行があると、プロパティに「テキストの一部が枠に入りきっていません」と出て、枠の角に
  赤い + が付く（Encore のオーバーセットテキスト）。枠を高くするか、テキストを短くする
- 行揃えの 4 つ目のボタン **≡**（**均等配置（最終行左揃え）**）は、段落テキストの各段落の最後の行を除いて、行を枠の
  端から端まで広げる。日本語は文字と文字のあいだ、日本語のない単語の行は空白で広げる。最後の行と、枠のないテキストは
  左揃え。縦書きのテキストも同じように列を枠の高さまで広げる（最後の列は上から始まる）
- **ウィンドウ ▸ スタイル**（Ctrl+F2）で、文字に決まった見た目を付けられる。セット（組み込みの **一般**、自分の
  **ユーザー**）を選び、メニュービューアでテキストかボタンを選んで **適用**（またはスタイルをダブルクリック）。
  スタイルはフォント・サイズ・色・文字の書式・ドロップシャドウの組み合わせで、ボタンでは文字の書式と影が変わる
  （ボタンの文字のサイズ・色・フォントはメニューのもの）。**新規** は選んだテキストかボタンの見た目をユーザーの
  セットのスタイルとして残し、**削除** で消す。Encore と同じく **画像** / **テキスト** / **シェイプ** のボタンで並べる
  スタイルを選ぶ。画像とシェイプのスタイルはレイヤー効果とドロップシャドウ（DiscCraft 独自の **効果なし**、**白い縁**、
  **黒い縁**、**やわらかい光**、**浮き出し**、**影付きの浮き出し**、**金**、**内側の光**）で、選んだ画像かシェイプに付く。
  **新規** は選んだものの効果を残す
- 画像とシェイプの **レイヤー効果**: プロパティの **レイヤー効果…**（横に付いている効果の名前が出る）で、**境界線**（外側の
  線）、**光彩（外側）** と **光彩（内側）**（周りや内側の縁のやわらかい光）、**ベベル**（指定した角度から光が当たる浮き
  出した縁）、**カラーオーバーレイ** を付けて調整する。メニュービューアでその場で確かめられる。ディスクのメニューと書き出す
  PSD に、見えるとおりに描かれる。テキストのプロパティにも同じ **レイヤー効果…** があり、ボタンの文字はボタンの **文字**
  タブにある。テキストをボタンに変換したとき（**ボタンに変換**）とその逆でも、効果は文字に付いたまま
- **オブジェクト ▸ サブピクチャを作成**（Alt+Ctrl+B）は、選んだボタンに自分のサブピクチャ（レイヤーパネルでは
  **(=1) サブピクチャ**）を付け、文字や枠の代わりにカラーセットの色 1 でハイライトする。PSD から作ったメニューの
  ボタンは、ボタンの絵（ボタンの `(+)` レイヤーセットが見せているもの）の形になる。レイヤーセットは位置で、動かしたり
  大きさを変えたりしたボタンは名前で探し、今のボタンに合わせて伸ばす。ほかのボタン（DiscCraft で作ったもの、絵のない
  もの）は、Encore が文字のボタンに `(=1)` レイヤーを作るのと同じく、自分の文字とビデオサムネールの形になる。どちらも
  ないボタンはそのまま。メニューを PhotoCraft で開くと（**メニューを PhotoCraft で編集**）、サブピクチャは Encore と
  同じく、ボタンのレイヤーセットの非表示の `(=1)` レイヤーとして PSD に入る
- **編集 ▸ サブピクチャとして貼り付け**（Shift+Ctrl+V）はどのボタンにも使える。画像かシェイプのレイヤーを選んで
  **コピー**（か **切り取り**）し、ボタンを 1 つ選んで貼り付ける。レイヤーの形が、そのボタンのサブピクチャの色 1 に
  なる（レイヤーパネルでは **(=1) サブピクチャ**。前からあったものに足される）。ボタンは文字や枠の代わりにその形で
  ハイライトされる。レイヤーの色と不透明度は関係なく、形だけを使う。ボタンからはみ出たレイヤーは、Encore と同じく
  ボタンを広げて取り込む（文字とビデオサムネールは元の場所のまま。画面の外に出たところは使わない）。ハイライトと
  リモコンの移動は広がったボタンで働く。回転したボタンも同じように、回転したまま広がる。サブピクチャを外すと、
  ボタンは中身に合わせた大きさに戻る

ボタンのプロパティ:

| 項目 | 内容 |
|---|---|
| リンク | 押したときに行く先 |
| 上書き | リンク先が終わったあとに行く先 |
| 種類 | 通常 / チャプター / 次へ / 前へ |
| 自動アクティベート | カーソルが乗ったボタンが Enter なしで決定される |
| オーディオ / 字幕 | そのボタンに切り替わる音声・字幕 |
| ルート | 矢印キーでどこへ動くか（自動 / 手動） |
| トランジション | ボタンを押したとき、リンク先の前に再生するビデオ（ディスクでは専用のタイトルになり、そのビデオの音声も入る） |

**表示 ▸ ボタンルートを表示**（Ctrl+7）で十字のルート図が出る。ルートの既定（上下左右の動き、折り返し方、
「次へ」「前へ」ボタンを除外するか）とボタンの名前の同期は [環境設定 ▸ メニュー](#15-環境設定) で決める
（プロジェクトに保存される）。自分で引くときは **ボタンのルートを自動設定** を外して矢印をドラッグする:
[ルートと番号を手で決める](#143-ルートと番号を手で決める)。

### 8.3 文字と図形

- **横書き文字ツール**（T）または **縦書き文字ツール**（Y）でクリックして入力。フォント、フォントスタイル、大きさ、
  行送り、字送り、ベースライン、上付き / 下付き、色、アンチエイリアスを設定できる。**行送り** は Encore と同じで、
  **自動** は大きさの 120 %、数値（入力するか **▾** の 6〜72 から選ぶ）は行のベースラインの間隔（縦書きでは列の間隔）の
  ピクセル数
- **一部の文字の書式**: プロパティのテキストの **テキスト** 欄で文字を選ぶと、そこと文字パネル（F3）の文字の行は、
  選んだ文字だけの値を映して設定する（大きさ、色、フォント、フォントスタイル、太字、斜体、下線、打ち消し線、大文字、
  トラッキング、ベースライン）。Encore で文字ツールで文字を選んで文字パネルで変えるのと同じ。**文字** の行に選んで
  いる文字が出て、**テキスト全体** で選択をやめると、設定はすべての文字にかかる。行揃え・行送りなど段落の設定は
  いつもテキスト全体のもの。大きい文字は行を高くし、段落テキストは設定どおりの文字の幅で折り返す（縦書きは列を
  文字の長さで）。入力した文字は前の文字の書式になる
- **ライブラリ** の **画像** と **シェイプ**（長方形 / 角丸長方形 / 楕円）を **配置** でメニューに置く。ライブラリから
  メニュービューアへドラッグしても置ける: ボタンは落とした位置を中心に、画像とシェイプは落とした位置を角に（画面から
  はみ出すときは内側へ寄せて）、背景はメニューの背景になる。**レイヤー** パネルで重なり順と目 / 鍵を扱う（背景は動かせない）
- **テキストアイテム**（Encore と同じ）: メニュービューアでテキストを選んでライブラリの **項目を追加** を押すと、文字・
  見た目・枠ごと **ユーザー** セットに入る（名前は 1 行目）。**テキストアイテム** の表示で並ぶ。**配置** で元の位置に
  複製を置き、メニュービューアへドラッグすると落とした位置が左上になる
- **レイヤーセット** と **置換レイヤー**（Encore のライブラリの種類。それぞれの表示の切り替えがある）: レイヤーセットは
  いくつかの画像・シェイプのレイヤーをまとめて置くもの（DiscCraft 独自の **見出しの帯**、**下の帯**、**細い枠**、
  **横のパネル**）、置換レイヤーは静止画をドロップすると置き換わる場所取り（**写真 4:3**、**写真 16:9**、**丸い写真**。
  レイヤーパネルでは **(!)**）。**配置** で描かれた位置に（HD の画面では中央に）、ドラッグで落とした位置を左上にして
  （画面に収めて）、1 回で置く。自分のものを残すには、メニュービューアで画像かシェイプを選んで **項目を追加**（置換
  レイヤーは置換レイヤーとして、ほかはレイヤーセットとして）、または **≡** の **メニューのレイヤーをレイヤーセットとして
  追加** で開いているメニューの画像とシェイプのレイヤーをまとめて。画像はファイルを覚えているので、別のプロジェクトでは
  そのアセットを使い、なければ読み込む
- **自分のセット**: ライブラリのセットの一覧の横の **≡** に **新規セット…**（名前を付ける。そのセットが表示され、
  **項目を追加** はそこに入る）、**セット名を変更…**、**セットを削除**（中の項目は **ユーザー** セットに移るので
  なくならない）。セットは項目と一緒に `library.json` に保存される
- **ファイルの項目**: **≡** の **ファイルから項目を追加…**（Encore の 項目を追加…）で、PSD・PSB・.pcraft と画像
  （PNG・JPEG・BMP・GIF・TIFF）を表示中のセットに足す（ファイルはライブラリのフォルダーの `items/` にコピーする）。
  Encore と同じく、ファイルの中身で種類が決まる: ボタンのセット（`(+)`）とほかのレイヤーがある PSD はメニュー、
  ボタンのセット 1 つだけの PSD はボタン、グループ 1 つだけの PSD はレイヤーセット、`(!)` のレイヤー 1 つだけの PSD は
  置換レイヤー、それ以外の PSD と画像は画像（大きさや名前は関係しない）。メニューは **新規メニュー** と **置き換え**
  で **ファイル ▸ 読み込み ▸ メニュー…** と同じに（`(#)` のページもそのまま）、画像は画像のレイヤーとして置く。
  ボタンは、PSD の絵の上に、そのセットの場所のボタンを重ねて置き、セットの `(=1)`〜`(=3)` のレイヤーがボタンの
  ハイライトになる（Encore と同じ）。レイヤーセットは中のレイヤーを 1 枚ずつ画像のレイヤーにして、セットの中の
  位置のまま置く（置換レイヤーは 1 枚の置換レイヤー）。どれも PSD の大きさのまま（画面より大きい PSD は画面に
  合わせて縮める）、落とした位置か画面の中央に置く。使うときにファイルを `<プロジェクト>.menus/` にコピー
  するので、ライブラリから消してもプロジェクトのメニューと画像は残る
- **フォルダーを読み込み…**（DiscCraft だけ）: 選んだフォルダーと、その下の PSD や画像のあるフォルダーごとに、
  フォルダーの名前のセットを作ってファイルの項目を足す（同じ名前のセットがあればそこに）。たくさんあっても裏で
  コピーし、ステータスバーに進み具合が出る。メニューやボタンの PSD を集めたフォルダーを、まとめてライブラリに
  できる
- **オブジェクト ▸ ドロップシャドウ…**（Shift+Ctrl+O）、**水平方向に反転 / 垂直方向に反転**（Alt+Ctrl+H /
  Alt+Ctrl+V）、**回転 ▸**（180°、90° 時計回り / 反時計回り）。自由な角度は回転ツール（R）
- **ガイド**: **表示 ▸ 新規ガイド…**（Shift+Alt+Ctrl+:）で位置を入力して打ち、**ガイドを表示**（Ctrl+:）、
  **ガイドにスナップ**（Shift+Ctrl+:）、**ガイドをロック**（Alt+Ctrl+:）、**ガイドを消去** で扱う

### 8.4 色とハイライト

**メニュー ▸ メニューカラーセットを編集…** で、標準 / 選択時 / アクティベート時の色を決める
（ハイライトの枠・文字・サブピクチャ）。**ハイライトグループ** を使うと複数のボタンがまとめて光る。
**名前** を入れて **新規** を押すと、そのセットをプロジェクトに持ち、どのメニューでも **カラーセット** の一覧から
選べる。**削除** で選んでいるセットを消す（取り込んだメニューの色はそのまま）。**書き出し…** でセットをファイル
（`.dcmenucolors`）に書き、**読み込み…** でファイルのセットをダイアログに読み込む（ほかのメニューやプロジェクトに）。
**表示 ▸ 標準サブピクチャを表示 / 選択時のサブピクチャを表示 / アクティベート時のサブピクチャを表示**
（Ctrl+3 / Ctrl+4 / Ctrl+5）で、キャンバスで見比べられる。ボタンごとグループを選ぶのと、透明なハイライトは
[ハイライトの色をボタンごとに決める](#145-ハイライトの色をボタンごとに決める) に書く。

### 8.5 背景とモーションメニュー

プロパティのメニューのシート（**基本 / モーション / ポップアップ**）で決める。

- 背景は色 / 画像 / 動画のアセット（タイムラインではない）。動画にするとモーションメニューになる
- PSD から作ったメニューに動画を付けると、Encore と同じく、動画は PSD の一番下のレイヤー（背景）の代わりになり、
  ほかのレイヤー（ボタン・文字・飾り）は動画の上に残る。モーション タブのビデオを **なし** に戻すと PSD の背景に戻る。
  PhotoCraft での編集やファイルへの書き出しでは PSD をそのまま使い、読み直しても動画はそのまま。
  複数ページのメニューでは、同じ背景のページ全部に動画が付く（Encore のページは背景が 1 つの 1 つのメニュー）
- ループ回数とループポイント、デュレーション（メニューは最大 254 秒）
- **エンドアクション**（時間切れで進む先。メニュー ▸ エンドアクションを設定… でも開ける）と **上書き**
- **ポップアップ** のシートでポップアップメニューに設定し（そのメニューの全ページが設定される）、背景のタイムライン / 背景フレームを決める（Blu-ray）

**メニュー ▸ EffectCraft コンポジションを作成…** でメニューのレイヤーから EffectCraft のプロジェクトを作り、
レンダーされたムービーをメニューの背景（モーションメニュー）にできる。ループと音声、あとで隠す層まで含めた
一通りは [モーションメニューに音と動きを](#146-モーションメニューに音と動きを) に書く。

### 8.6 PSD で作り直す

- **編集 ▸ メニューを PhotoCraft で編集**（Shift+Ctrl+M）: メニューをレイヤー付き PSD にして PhotoCraft
  （なければ既定のアプリ）で開く（PSD から作ったメニューで、テキストを足していなければ、その PSD をそのまま開く）。
  保存すると自動で読み直す。PSD は `<プロジェクト>.menus/` に置かれる。
  反映では、`(+)` のグループをボタンの名前で探し（名前を変えたグループは、Photoshop が変えずに持つレイヤー ID で。レイヤー ID のない PSD では、ボタンに重なっているグループ。複製したグループは新しいボタン）、ボタンを PSD の重なりの順に並べ直す。
  見つかったボタンはリンクと設定をそのまま持ち（初期設定のボタンとそのボタンへのリンクもついていく）、増えたグループは
  ボタンを足し、なくなったグループのボタンは消す。`(#)` のページのある PSD のメニューは、全部のページを読み直す
- **メニュー ▸ メニューをファイルとして保存…**: メニューを PSD で書き出す
- 上の 2 つの PSD では、Encore と同じく、テキストとボタンの文字を編集できる文字のレイヤーにする。Photoshop の
  文字ツールで打ち直せ、フォント・サイズ・色・行揃え・段落の枠・角度はそのまま、ドロップシャドウはレイヤースタイル。
  打ち直すまでは DiscCraft の描いた文字を表示する（Photoshop は文字をテキスト用のガンマで重ねるので、ふちが少し明るく
  見える）。ほかのレイヤー効果（境界線・光彩・ベベル・オーバーレイ）の付いたテキストはピクセルで書き出す
- PSD から作ったメニューや、PhotoCraft などの画像エディターで編集したメニューは、上の 2 つの PSD で元の PSD の
  レイヤーをそのまま残す（1 枚の絵に平らにしない）。そのあと DiscCraft で足したものはその上に重なり、ボタンの新しい
  文字はそのボタンの `(+)` のセットに、新しいボタンは新しいセットになる。`(#)` のページのあるメニューでは、足したものは
  そのページのグループに入る。元の PSD がディスクの画面と違う大きさ（PAL の DVD のプロジェクトの 1920x1080 の PSD
  など）でも、PSD はその大きさとレイヤーのまま書き出し、DiscCraft で足したものをその大きさに合わせる
- ページのあるメニューは、どのページから書き出しても全部のページを 1 つの PSD にする。最初のページは一番上の階層、
  2 ページ目からは `(#) ページ 1`、`(#) ページ 2`… のグループ（そのページのボタンのセット）。読み直すと、各ページが
  自分のグループに従い、エディターで足した `(#)` のグループは新しいページになる。ページのあるメニューのテキストと
  図形は PSD に書かず、DiscCraft に残る（PSD の一番上の階層の絵は全部のページに出て、`(#)` の中のボタンでない絵は
  Encore と同じく出ないため）
- **メニュー ▸ メニューを置き換え…**: 開いているメニューを PSD のデザインに置き換え、リンクは番号で残す
- **メニュー ▸ メニューをテンプレートとして保存…**（Ctrl+Alt+M）: ライブラリの **ユーザー** セットに保存する

### 8.7 ユーザー操作

**メニュー ▸ メニューのユーザー操作を設定…** と **ファイル ▸ ディスクのユーザー操作を設定…** で、
再生中にリモコンでできる操作 / できない操作を決める（DVD は 25 種類のユーザー操作、Blu-ray は UO マスク）。

## 9. ナビゲーションを組み立てる

### 9.1 ファーストプレイとタイトルボタン

ディスクを入れると最初に動くのが **ファーストプレイ**、タイトルボタンを押したときに行く先が **タイトルボタン**。
最初のタイムラインまたはメニューを作ったときに自動で設定される。変えたいときは、プロジェクトパネルかフローチャートの
項目を右クリックして **ファーストプレイに設定**（タイトルボタンはプロパティで決める）。

### 9.2 フローチャート

**ウィンドウ ▸ フローチャート**（F5）。項目の箱とリンクの矢印が図になる。

- 箱はドラッグで動かせる。**自動レイアウト** / **すべて自動レイアウト** で整頓できる
- ボタンやエンドアクションから、メニュー・タイムライン・スライドショー・再生リストへドラッグするとリンクする
- 右クリックに 開く / リンクの指定 / 名前の変更 / ファーストプレイに設定 など
- 下に **リンクされていない項目** の行が出る（孤立の発見に使える）
- **表示 ▸ すべてのサムネールを表示** で箱に絵を出す

ディスク全体をページで読む（ファーストプレイ、上の階層へ戻るメニュー、何もリンクしていない項目）のは
[フローチャートをディスクの地図として使う](#148-フローチャートをディスクの地図として使う) に書く。

### 9.3 リンクの種類

| 場所 | 決まるもの |
|---|---|
| ボタン | リンク（押した先）、上書き（リンク先が終わった先）、ルート（矢印キーの動き） |
| タイムライン | エンドアクション、上書き、リモートメニュー |
| メニュー | エンドアクション（時間切れの先）、上書き、デュレーション |
| ディスク | 上書き（ディスクの既定の行き先） |

## 10. 字幕

### 10.1 読み込み

- **タイムライン ▸ 字幕の読み込み ▸ テキストスクリプト…**（SRT / WebVTT / タイムコード付きテキスト。UTF-8 /
  UTF-16 / Shift_JIS）を選ぶと、選んでいるタイムラインに字幕トラックが 1 本増える
- **タイムライン ▸ 字幕の読み込み ▸ FAB 画像スクリプト… / 画像スクリプト…** で、Encore と同じく画像（JPG、GIF、
  PNG、TIF、BMP）の字幕を読み込める。FAB 画像スクリプトは 1 行に 1 枚（`ファイル 開始 終了 左 上 右 下`）で、
  画像のフォルダーを聞かれる。画像スクリプトは `Display_Area (左 上 右 下)` と `Directory <フォルダー>` のあとに
  `番号 開始 終了 ファイル`。**カラーをマップ** で 1 枚目の画像をクリックして **背景**（透明）、**塗り / カラー 1**
  （カラーグループの塗りで描く）、**輪郭 / カラー 2**（グループのストローク）の色を選ぶ。そのほかの色は透明になるので、
  縁のくっきりした 3 色の画像がきれいに出る。**相対** にすると、すべての字幕を入れたタイムコードだけずらす（前に
  ずらすときは頭に `-`）。画像の字幕はタイムラインにファイル名で出て、文字は直せない。移動とトリムはほかの字幕と同じ
- 字幕ファイルをアセットとして読み込んでから、タイムラインビューアに落としてクリップにする
- Encore が書き出した字幕のテキストスクリプト（UTF-16 LE）も読める。**タイムライン ▸ 字幕を書き出し ▸
  字幕トラック** で SRT / テキストスクリプトとして書き出せる
- **ファイル ▸ 新規 ▸ スライドショー** の **字幕を作成** で、スライドの名前と説明から字幕を作ることもできる

### 10.2 編集

タイムラインビューアの S1 トラックで、クリップの端をドラッグしてトリムし、ダブルクリックで文字を直せる
（Enter / Shift+Enter で改行、Esc で確定）。トリムは最短 0.4 秒（NTSC 13 フレーム、PAL 11 フレーム）。

モニターの字幕のボタンでも作れる（**前の字幕 / 次の字幕 / 字幕インポイントをここまでトリム /
字幕アウトポイントをここまでトリム / 字幕を追加**）。**字幕を追加** は再生ヘッドの位置に既定 2 秒のクリップを置く
（次の字幕まで 2 秒空いていないと置けない）。

タイムラインでは、字幕クリップをドラッグするとトラックに沿って動き、左右の端をドラッグするとトリムになる。
フレーム単位で動き、隣のクリップと先頭で止まり、13 フレームより短くはならない（もとから短いクリップはその長さのまま）。
動かす先は枠で示され、Ctrl+Z で戻る。**字幕クリップをスナップ**（環境設定 ▸ タイムライン。Encore と同じく初期値は
オフ）をオンにすると、動かす端が近くの字幕クリップの端、チャプターポイント、再生ヘッドに吸い付く。チャプターポイントの
線の上を押したときは、これまでどおりチャプターが動く。

### 10.3 見た目

字幕クリップを選ぶと、プロパティに **字幕クリップ** のシートが出る。

| 項目 | 内容 |
|---|---|
| テキスト / デュレーション / インポイント / アウトポイント | 文字と時刻 |
| ハイライト | グループ 1〜3（色の組）。**トラックの設定** にするとトラックのグループに従う |
| ストローク | なし / 細 / 中 / 太 / 極太 |
| 整列 | 上下の位置（100 % で下） |
| 揃え | 左 / 中央 / 右（初期値は中央。左と右はタイトルセーフの端に揃う） |

色はタイムライン（スライドの字幕はスライドショー）のプロパティの **カラーセット** で決める。

- グループ 1〜3 のそれぞれに、塗り・ストローク・アンチエイリアスのカラーと不透明度。初期設定の色は Encore と同じ
- **塗りおよびストロークからアンチエイリアスカラーを作成** を入れると、アンチエイリアス（文字の縁のなじませる色）は
  塗りとストロークの中間になる。外すと自分で決められる
- **名前** を入れて **新規** で、今の色をプロジェクトのカラーセットとして保存する。保存したセットは **カラーセット** の
  一覧から選べ、**削除** で消せる（タイムラインは色のコピーを持つので、後からセットを変えても変わらない）
- **書き出し… / 読み込み…** でカラーセットをファイル（`.dccolors`）にやり取りできる。**初期設定に戻す** で元の色に戻す

字幕の文字はタイトルセーフ（フレームの 80 %）の中に収める。**表示 ▸ セーフエリアを表示**（Ctrl+6）で範囲を確認できる。
収まらない字幕は [プロジェクトのチェック](#11-プロジェクトをチェックする) に出る。

## 11. プロジェクトをチェックする

**ファイル ▸ プロジェクトをチェック…**（Shift+Ctrl+L）、**ビルド** パネルの右の **プロジェクトをチェック** ボタン、
または F4。チェックウィンドウは **チェックする項目** に印を付けて **開始** を押すと走り、結果は **名前** と **問題** の
2 列に項目ごとにまとまって出る（1 項目に問題が複数あると「{n} 個のエラー」に折りたたまれる。文言は Encore と同じ）。

| 分類 | 見るもの |
|---|---|
| ボタンリンク | リンク先がない・リンクが設定されていないボタン、枠の外に出たボタン、存在しない初期設定ボタン |
| ファーストプレイ | ファーストプレイが設定されているか |
| 孤立 | どの項目からも辿れないタイムラインとメニュー |
| エンドアクション | エンドアクションが未設定の項目 |
| タイトルボタン | タイトルボタンがメニューになっているか |
| 再生リスト | 空の再生リストとスライドショー、エントリのないチャプター再生リスト、デュレーション不正なスライド |
| 上書き | 上書きの設定 |
| リモートメニュー | リモートメニューがメニューになっているか |
| 重なったボタン | ハイライトが重なるボタン、ボタンが多すぎるメニュー |
| メニューの合計サイズ | ボタンのないメニュー、デュレーション、4:3 と 16:9 の混在 |
| ディスク容量 | 容量を超えていないか、ビットレートが低すぎないか |
| チャプターおよびトリム | 99 チャプター超、最初のチャプターが先頭にない、順序が不正 |
| 高すぎるタイムラインビットレート | DVD で、そのまま使うビデオとオーディオトラックの合計が 9.8 Mbps を超えるタイムライン |
| 字幕テキストのオーバーフロー | 文字がタイトルセーフの枠に収まらない字幕（NTSC の標準の大きさで 11 行以上、または折り返せない長い行）。字幕トラックとイン / アウトの時刻が出る |
| 字幕の間隔 | Blu-ray（HD か PAL）で、同じトラックの前の字幕とのすき間が 5 フレーム未満の字幕。DVD では見ない |
| 再生の種類 | DVD で、**ランダム** か **シャッフル** にしたチャプター再生リストのエントリが 65 以上のもの: DVD は最初の 64 個からしか選ばない。（Encore は DVD ではランダムとシャッフルのチャプター再生リストを順番どおりに再生させる。DiscCraft は設定どおりに書く） |
| トラックとタイトルの数 | オーディオ 8 本、字幕 32 本、DVD のタイトル 99 本など |
| メディアファイル | オフライン・存在しない・扱えない形式の素材 |
| その他 | 上のどれにも入らないもの |

**ビルド** ボタンはビルドの前に必ずチェックを走らせ、問題があると **表示**（チェックウィンドウを開く）／
**無視して続行** ／ **取り消し** のダイアログが出る。

## 12. プレビューする

### 12.1 プロジェクトプレビュー（ビルドしないプレビュー）

**ファイル ▸ プレビュー**（Alt+Ctrl+Space）、ツールバーの再生ボタン。ビルドせずに、今のプロジェクトを
自前の VM で再生する窓が開く。

- 下のコントロールバーに 拡大率、オーディオトラックと字幕トラック、今の項目（名前、ボタン番号かチャプター番号、
  静止画 / モーション か再生時刻）、**タイトル** / **メニュー**（Blu-ray では **ポップアップメニュー**）、十字キーと決定、
  前のチャプター / 停止 / 一時停止 / 再生 / 次のチャプター、**エンドアクションを実行**、**チャプターへ移動**
- **ここで終了**（見ている項目を開いて終了）と **終了して戻る**（開く前に戻る）。窓を × で閉じるのも同じ
- タイトルは映像と音つきで再生し、終わるとエンドアクションへ進む。矢印キーと Enter でリモコン、Space で一時停止
- チャプター再生リストは、エントリーを順に再生する（タイムラインの各チャプターを次のチャプターポイントまで）。
  スライドショーは、スライドをそれぞれの長さだけ、オーディオクリップを鳴らしながら映す。チャプター番号は画面に
  出ているものに付いていくので、前 / 次のチャプターはそこから動く。「手動で進める」のスライドは、次のチャプター
  （または Enter）まで出たままになる。出たままの間はディスクと同じく音も止まり、次のチャプターで止まったところから
  続く。スライドはディスクと同じくパンとズームで動き、「スケールしてクロップ」は画面いっぱいに
  映る。スライドの間のトランジション（クロスディゾルブ、黒へのディップ、ワイプ）も、ビルドと同じく切れ目をまたいで
  かかる。字幕ストリームをオンにすると、**字幕を作成** のスライドは名前（と説明）がディスクと同じく字幕で出る。**シャッフル** のチャプター再生リストは全部の項目を 1 回ずつランダムな順に、**ランダム** は毎回ランダムな項目を（ここでは 99 回まで）、プレーヤーと同じように再生する
- レンダリングしたモーションメニュー（**ファイル ▸ レンダリング ▸ モーションメニュー**）は、ディスクと同じく
  背景の動画とモーションボタンが動き、ループポイントからくり返す。レンダリングする前と、プロジェクトを変えた
  あとは、Encore と同じくそのままのメニュー（背景の最初のフレーム）を映す。HD の Blu-ray のモーションメニューも、
  レンダリングしたあと（または同じキャッシュでディスクをビルドしたあと）はここで動く

### 12.2 モニター（ビルド結果の再生）

**ウィンドウ ▸ モニター**（F9）。モニターの **ビルド結果を開く** で、書き出したフォルダの `VIDEO_TS` / `BDMV` を
読んで再生できる。リモコンの十字キー、タイトル / メニュー、チャプター、オーディオ / 字幕が使える。
ビルドしていないときは、選んでいるタイムラインの映像と音をそのまま映す（Space で再生、音つき。字幕もカラーセットの色で出る）。
DTS のトラックは鳴らない。

## 13. ビルドする

**ウィンドウ ▸ ビルド**（F2）、または **ファイル ▸ ビルド ▸ フォルダー…** / **イメージ…**。

| 欄 | 内容 |
|---|---|
| 形式 / 出力 | DVD / Blu-ray、**ディスク**（レコーダーのディスクに書き込む）、フォルダー（`VIDEO_TS` / `BDMV`）、ISO イメージ、DVD では **DDP イメージ**（プレス用）も |
| ビルド | ビルドを開始する。押すと先にプロジェクトを保存し、チェックする |
| ソース | 現在のプロジェクト（ビルドパネルは今のプロジェクトだけ書き出す） |
| 保存先 | 空だと薄い文字で示す場所（プロジェクトの横の `<プロジェクト名>_DVD` / `_BD`、イメージは `<プロジェクト名>.iso`、DDP イメージは `<プロジェクト名>_DDP`）。フォルダーと DDP イメージは、既存のフォルダーを指定するとその中の `<ディスク名>` フォルダーに作る（すでに `VIDEO_TS` / `BDMV`、DDP イメージの `DDPID` がある場所ならそこを再ビルド）。イメージはフォルダーを指定できない |
| ディスク情報 | 使用量のバー（**容量を更新** で計算）、ディスクの名前（ISO のボリュームラベルにもなる）、サイズ（一覧の最後の **カスタム** では、横の欄に自分で決めたサイズを GB で入れる。1 GB = 1,000,000,000 バイトで、0.001 GB から 1 層の DVD の 4.7 GB まで、Blu-ray は BDXL の 128 GB まで。それより大きな DVD は DVD9。使用量のバーとプロジェクトのチェックはそのサイズで測る）、**DVD-ROM コンテンツ** / **BD-ROM コンテンツ**（**参照…** でフォルダーを選ぶと、その中のファイルとフォルダーがディスクのルートに、`VIDEO_TS` / `BDMV` と並んで入る。パソコンで読むための説明書や写真など。フォルダーのビルドではコピーされ、イメージには中に入る。その分だけ映像に使える容量が減り、バーの下に使っている大きさが出る。**消去** で外す。1 つのファイルは 4 GB 未満、フォルダーは 7 段まで） |
| レイヤーブレーク | DVD-9 のときだけ。自動 / 手動。手動はタイムラインと位置（タイムコード / フレーム / 秒、**再生ヘッド**）で決める |
| リージョンコード | DVD のときだけ。すべてのリージョン / カスタム（1〜8 のチェック）。**視聴制限レベル**: なし、または 1〜8（8 がもっとも厳しい）。視聴制限レベルをこれより低く設定したプレーヤーは、再生の前（ディスクの始まりと、リモコンからタイトルを始めたとき）にパスワードを求め、入力されなければ止まる。レベルを設定していないプレーヤーは今までどおり再生する。タイムライン・スライドショー・チャプター再生リストは、プロパティの **視聴制限レベル** で自分のレベルを持てる（ディスクのレベル、なし、1〜8）。タイムラインは、レベルが上げられなかったときに代わりに再生するもの（**制限で再生しないとき**: 別のタイトルかメニュー。未設定なら止まる）を指定できる。タイムラインのチャプターには、あるレベルより低いプレーヤーが代わりに見るビデオを持たせられる（DVD 規格のパレンタルブロック。チャプターのプロパティの **視聴制限の代わり** と **このレベル未満**（2〜8）。コマンドは `timeline.setParentalChapter`）: タイトルはレベルごとの版になり、プレーヤーが自分のレベルで選ぶ（パスワードは求めない。代わりのビデオは自分の音とともにディスクに入る。プロジェクトプレビューは、環境設定 ▸ プレビューのプレーヤーの視聴制限レベルの版を映し、代わりのチャプターでは代わりのビデオを流す。モニターは元のタイムラインを映す）。どの国にも同じレベルを書く。実機のプレーヤーでは未確認 |
| プロジェクトのチェック | チェック結果（チェックウィンドウと同じ行） |
| 結果 | エラー、タイトル数 / チャプター数 / サイズ、**シミュレート**（フォルダーにビルドした後で VM を走らせる） |

ビルド中は進み具合と経過時間がバーで出る（パネルがどこにあってもステータスバーにも出る）。

- 変換した素材は出力先の `disccraft-cache` に残る（2 回目から変換を飛ばす）。コマンドラインの `--cache` で
  別の場所に置いて共有できる
- ISO は UDF + ISO 9660。Windows ではエクスプローラーでダブルクリックするとマウントできる
- DVD-9 のイメージでレイヤーブレークを指定すると、同じ場所に `<名前>.layerbreak.txt` に記録が残る。2 層のディスクに
  合わせて、ブレークは 16 セクターのブロックの頭に置く: ブレークのセルがそれ以外で始まるときは、そのタイトルセットを
  イメージの中で数セクター後ろへずらす（VIDEO_TS フォルダーのビルドはずらさない）
- **DDP イメージ**（DVD だけ。Encore と同じ）は、プレス工場にマスターディスクの代わりに渡すもの。フォルダーの中に
  `MAIN.DAT`（ディスクのイメージ）、`CONTROL.DAT`（ディスクの制御データ: 大きさと構成）、`DDPID`（2 つのファイルが
  何で、ディスクのどこに入るか）ができる。同じイメージから Encore CS6 が書くものと同じファイル。`VIDEO_TS` の
  フォルダーは横（`<名前>.files`）に作る。2 層（DVD-9）のディスクの DDP イメージは、Encore と同じく層ごとのフォルダーに
  分かれる: `Layer 1`（イメージの層 0 の分、`CONTROL.DAT`、`DDPID`）と `Layer 2`（イメージの残りとその `DDPID`）
- 出力を **DVD ディスク** / **Blu-ray ディスク** にすると、保存先の代わりに **レコーダー**（書き込めるドライブ。**更新** で探し直す）、
  **書き込み速度**（入っているディスクで使える速度。**最大** は一番速いもの）、**コピー数**（1〜99）、
  **書き換え可能ディスクのデータを自動消去**（DVD-RW などは消去してから、DVD+RW・BD-RE は上書きして書く。オフなら空きのディスクだけ）、
  **書き込み後にディスクをベリファイ**（最初はオン。DiscCraft だけの項目: 取り出す前にディスクを読み戻し、イメージとセクターごとに比べる）
  が出て、その下に入っているディスクの種類と空きが出る。**ビルド** でプロジェクトの横にイメージを作り、それをディスクに書き込んで
  閉じ、ベリファイしてからトレイを開ける。イメージと違うディスクは、違う最初のセクターとともに知らせる。2 枚目からは空きのディスクを入れて **書き込み** を押す。書き込めなかったときは **やり直す** で同じイメージを
  もう一度書ける。終わるか **キャンセル** でイメージは消える。書き込み中はビルドパネルに進み具合と **停止** が出る
  （途中で止めた 1 回だけ書き込めるディスクは使えない）。書き込み中はウィンドウを閉じられない。Windows の書き込みの機能（IMAPI2）を
  使い、レコーダーのない PC では「見つかりません」になる。Encore の **書き込み前にテストを実行** は、IMAPI2 にテストの書き込みが
  ないので使えない。コマンドラインでは `disccraft-cli recorders` でレコーダーと入っているディスクを、`disccraft-cli burn <イメージ>`
  （`--recorder E:`、`--speed 8`、`--erase`、`--no-verify`）でイメージを書き込んでベリファイし、`disccraft-cli verify <イメージ>`
  （`--recorder E:`）で書き込み済みのディスクをイメージと比べられる。macOS と Linux はまだ書き込めない
- 残り容量の読み方と、収まらないときの手当ては
  [作業しながらディスクの大きさを読む](#149-作業しながらディスクの大きさを読む)

## 14. 上級テクニック

これまでの章は作業の流れどおりに書いた。この章は、ディスクを「オーサリングした」ものにする部分:
絵入りのシーン選択メニュー、ライブラリから組み立てるメニュー、手で引くルート、
隠しボタン、ボタンごとに決めるハイライトの色、音つきのモーションメニュー、
作業しながらディスクの大きさを読む。それぞれ手順どおりにたどれるように書き、上限はそばに添えた。

> スクリーンショットはいまのところ仮の場所です。`docs/images/user-guide/` に後で入れる。
> 入るまではリンクが切れた絵として表示され、下の文章だけが出る。

### 14.1 絵入りのシーン選択メニュー

チャプターポイントは、シーンの始まる所に置く印。ボタンにリンクすれば、観る人はスクラブせずに
目当てのシーンへ飛べて、リモコンの次・前のチャプターキーでチャプターを順にたどれる。

1. **ファイル ▸ 読み込み ▸ タイムライン…**（Shift+Ctrl+T）で、選んだビデオ 1 本ごとに
   アセットとタイムラインをまとめて作れる（1 本ずつ作らなくていい）。1 本目のビデオが
   **ファーストプレイ** になる。
2. プロジェクトパネルのタイムラインをダブルクリックしてタイムラインビューアに開き、
   モニターも出しておく（**ウィンドウ ▸ モニター**、F9）。
3. はっきり場面が変わる所に再生ヘッドを置いて **タイムライン ▸ チャプターポイントを追加**
   （テンキーの `*`）。チャプターは順に番号が付くので、間に 1 つ足しても番号は自動で
   振り直される。
4. プロパティでチャプターに名前を付ける。チャプターの名前は、通常はその先へ導くボタンの
   名前と同じにする。**表示 ▸ チャプター名を表示**（Ctrl+8）でタイムラインに名前が出る。
5. これを映像の最後まで繰り返す。シーンが等間隔なら **一定間隔でチャプターポイントを追加…**
   （既定 5 分）。
6. ボタンには、シーンの 1 フレーム目よりそのシーンらしい絵を置く。その絵のフレームへ
   再生ヘッドを動かしてモニターの **ポスターフレーム** を押すか、チャプターのプロパティの
   **ポスターフレーム** にタイムコードを打つ。ポスターフレームにはチャプターと同じ番号の
   旗が立ち、ドラッグで動かせる。欄を空にするとチャプター自身のフレームに戻る。
7. メニューを作る。チャプターごとにボタンを並べるなら **メニュー ▸ チャプターインデックスを
   作成**、絵のボタンを並べるならライブラリの **サムネールの一覧** プリセット。チャプターに
   リンクしたボタンは、そのチャプターのポスターフレーム（なければチャプター自身のフレーム）を
   出す。

知っておくこと:

- チャプター 1 は常にタイムラインの 1 フレーム目。動かすことも消すこともできず、
  新しいタイムラインには必ず付いてくる。
- そのままディスクに載る MPEG-2 では、チャプターポイントは GOP の頭にしか置けない。
  置きたい所に置けば DiscCraft が近くの空いている GOP の頭へ寄せるので、GOP の中に
  置いたポイントはそこには残らない。トリムも同じ吸着をする。
- ポスターフレームのない静止のサムネールは、チャプターの最初の明るい（黒でない）フレームを出す。
  黒からフェードインするシーンでも、ボタンに何も映らないでいることはない。
- DVD は 1 タイトル 99 チャプター。チャプターインデックスの 1 ページにはチャプターボタンを 18 個
  （複数ページで作る場合は 1 ページ 6 個）置ける。
- **モーションボタン** を入れると、サムネールのボタンは 1 枚の絵ではなく動画を再生する。
  動きの始まりは、リンクしたチャプターの頭（またはポスターフレーム）。

![チャプターポイントとポスターフレームの入ったタイムラインビューア](images/user-guide/chapter-poster.png)

### 14.2 ライブラリからメニューを組み立てる

ライブラリには DiscCraft 独自のメニュー・ボタン・画像・背景・シェイプのプリセットと、
自分で保存した項目が入っている。この方法で作ったメニューも、完成してしまえば普通のメニューで、
どこから来たかの印は残らない。

1. **ライブラリ** パネルで種類（**メニュー**）とセット（**一般**、自分のものは **ユーザー**）を
   選び、プリセットを選んで **新規メニュー** を押す。メニュービューアに開き、
   プロジェクトパネルとメニューパネルにも出る。
2. 名前は **Alt+Ctrl+R** で付ける（「メニュー #1」「シーン選択」など、後で分かる名前に）。
3. 種類を **ボタン** に替えて、メニューに入れる数だけ **配置** を押す。ボタンはキャンバスに
   置かれる。
4. **選択ツール**（V）で大まかな位置へ動かす。複数選んで（Shift+クリック、または囲って）
   **オブジェクト ▸ 均等配置** と **オブジェクト ▸ 整列** で間隔と揃えを直す。
   **セーフエリアに相対的に整列** を入れると、キャンバスではなくセーフエリアの枠が基準になる。
5. ボタンと同じ書式の見出し文字はこう作る。ボタンを選んで **Ctrl+C** → **Ctrl+V** →
   **オブジェクト ▸ オブジェクトに変換**。ボタンは消えて、文字だけが同じ場所に同じ大きさ・
   同じ書体で残るので、**横書き文字ツール**（T）で打ち替える。メニュー間でも同じように
   コピー＆ペーストすれば、見た目をそのまま持ち込める。
6. 見出しを選んで **オブジェクト ▸ ドロップシャドウ…**（Shift+Ctrl+O）。**ドロップシャドウ** と
   **プレビュー** に印を付け、色・不透明度・角度・距離・サイズ・スプレッドを決めて **OK**。
   同じダイアログはボタン・画像・シェイプにも使える。
7. 戻るボタンも作る。文字をもう一度貼り付けて「メインメニュー」に直し、**Ctrl+B**
   （**オブジェクト ▸ ボタンに変換**）。これがボタンの一番素直な作り方。
8. 各ボタンをリンクし（[14.7](#147-ボタンへのリンクの入れ方-5-とおり)）、メニューの
   **エンドアクション** と **初期設定ボタン** も決める。
9. 残しておきたいメニューなら、**メニュー ▸ メニューをテンプレートとして保存…**（Ctrl+Alt+M）
   でライブラリの **ユーザー** セットに入れておき、次のプロジェクトでも使う。

背景はいつでも変えられる。ライブラリで背景を選んで **配置** か **背景を設定**。**置き換え** は、
開いているメニューのデザインを別のプリセットに差し替え、リンクは番号のまま残す。

![ライブラリパネルと、そのボタンで作ったメニュー](images/user-guide/library-menu.png)

### 14.3 ルートと番号を手で決める

ルートは、観る人が矢印キーを押したときにハイライトがたどる道。DiscCraft はそれらしい道を自動で引く
（規則は [環境設定 ▸ メニュー](#15-環境設定) にあり、プロジェクトに保存されるので、
どのパソコンでビルドしても同じルートになる）。ボタンの並びが変なとき、行を折り返したくないとき、
誰も思いつかない道へ導きたいときは手で引く。

自動のルートは Adobe Encore CS6 と同じ規則で引く。左（上）の端か中心が 9 px 以内にそろったボタンは列（行）になり、
上下（左右）はその中を進んで端で折り返す。少しだけずれたボタン（行と重なって 10〜18 px ずれたもの）があると
その行は全体が行でなくなり、ボタンどうしが一部だけ重なっているとき、行のボタンから 10〜18 px 離れたボタン（すぐ下の帯など）が
あるときも同じ。ほかのボタンを中に含むボタン
（項目の並びの後ろの帯など）は行にも列にも入らず、中のボタンへ進む。行も列もない向きは、その向きの一番近い
ボタンへ（上下はまっすぐから約 68° まで、または横に 400 px 未満）、なければ横のボタンへ（同じ高さのものを先に、すき間の近いもの、
同じなら時計回りの側: 上は右、下は左）。「次へ」「前へ」を除くときは、一番左のボタンの
上と左が「前へ」、一番右のボタンの下と右が「次へ」になる。

1. メニューの背景をクリックして（ボタンでも文字でもない所）プロパティにメニューのシートを
   出し、**基本** タブの **ボタンのルートを自動設定** を外す。
2. **表示 ▸ ボタンルートを表示**（Ctrl+7）すると、ボタンごとに十字の図が出る。
   真ん中の数字がボタンの番号、矢印の数字はその矢印キーで行き着くボタン（0 は行き先なし）。
3. 先に番号を決める。ボタンのシートの **番号** は一覧での位置を入れ替える欄で、
   矢印は番号を指すので、左から右・上から下に振っておくと後の作業が楽になる。メニューの
   **オフセット** は、リモコンの数字キーがどこから数え始めるか。
4. 十字の矢印を、導きたいボタンへドラッグする。キャンバスの何もない所で離すとそのルートは消える。
   触っていない向きは自動のまま。
5. ルートの表示を消して試す。**ファイル ▸ プレビュー**（Alt+Ctrl+Space）で矢印キーを押す。

![ボタンのルートの十字](images/user-guide/routing.png)

### 14.4 隠しボタンとイースターエッグ

イースターエッグは、偶然には見付からない場所にある項目のこと。ディスクでは、
描かれないボタン（またはハイライトが乗るまで描かれないボタン）と、
ふつう誰も歩かないルートでできている。型は 2 つあって、違いはどちらのハイライトを見せるかだけ。

- カーソルが乗ったときにハイライトが出るもの。ていねいにたどる人なら見付けられる。
- ハイライトも透明なもの。見付けたかどうかは Enter を押すまで分からない。

作り方は次のとおり。

1. メニューを作る（**ファイル ▸ 新規 ▸ メニュー**、Ctrl+M、またはライブラリのプリセット）。
   普通のボタンを 2〜3 個と、画像を 1 つ置く（**ライブラリ ▸ 画像 ▸ 配置**）。重ねないで置く。
2. 画像を選んで **Ctrl+B**。これが隠しボタンになる。リンクは先に付けておく（タイムライン、
   再生リスト、スライドショー）。リンクのないボタンはチェックに出る。
3. 背景をクリックして **ボタンのルートを自動設定** を外し、ルートは自分で引く。
4. **レイヤー** パネルで、通り道に使う 2 つのボタンのセットを開いて、目のアイコンをクリックして
   非表示にする。文字と絵は消えるが、ボタンとしては残るので、ハイライトもリンクも効いたまま。
5. その 2 つのボタンを選んで **ハイライト** を **グループ 2** にする。見えるボタンと画像のボタンは
   **グループ 1** のままにする。
6. **メニュー ▸ メニューカラーセットを編集…** で **メニューの初期設定** を選び、**プレビュー** に
   印を付けて、ハイライトグループ 2 の不透明度を 0 % にする（色 1・2・3、選択時とアクティベート時の
   両方）。グループ 2 のボタンは完全に消える。
7. 同じダイアログで、ハイライトグループ 1 には気づく色を付ける（定番は明るい緑）。
   観る人が辿り着けた合図になる。見付かっても暗いままでいいなら、そちらの不透明度も 0 にして、
   選択されても透明にしておく。
8. ルートの表示を入れて番号を振る。見えるボタンが 1、透明なボタンが 2 と 3、隠しボタンが最後。
   それから矢印をドラッグして、隠しボタンへ行く道だけ変な順（左、上、左）にしておき、
   間違ったキーは全部ボタン 1 に戻すようにする。
9. マウスではなく矢印キーでプレビューする。

注意:

- 隠したボタンもボタンには違いない。場所は取り、ハイライトはほかと重なってはいけないし、
  1 メニュー 36 個にも数えられる。
- 枠の中に収める。枠の外に出たボタンはチェックに出て、リモコンで辿り着けない。
- リンクのない透明なボタンは、画面では決して見えないエラー。ビルドの前に
  **プロジェクトをチェック…**（Shift+Ctrl+L）を通す。
- エッグのあと観る人に元のメニューへ戻ってもらうには、リンク先を
  **エンドアクションが 前のメニューに戻る** のタイムラインにするか、来たメニューを
  エンドアクションに設定する。
- ほかにも覚えておくと便利な技: ボタンはメニューの**ボタンまで指定して**リンクできる。
  メニューを開いた時点で、そのボタンがハイライトされた状態になる。

![透明なボタンと、その間のルート](images/user-guide/hidden-button.png)

### 14.5 ハイライトの色をボタンごとに決める

メニューのハイライトはサブピクチャ、つまりボタンにカーソルが乗ったとき（選択時）と押したとき
（アクティベート時）に、ボタンの上かそばに重ねて描かれる絵。メニューはカラーセットを持つ
（標準グループとハイライトグループ 1〜3）。グループには色が 3 つずつあり、それぞれに選択時と
アクティベート時のカラーと不透明度がある。ボタンはどのグループを使うかを選ぶ。

1. メニューを選んで **カラーセット** を **自動** ではなく **メニューの初期設定** にする。
   自動はメニューごとに色を作るので、メニューが 1 つならそれでもいいが、6 個並ぶとバラバラになる。
2. **表示 ▸ 標準サブピクチャを表示 / 選択時のサブピクチャを表示 /
   アクティベート時のサブピクチャを表示**（Ctrl+3 / Ctrl+4 / Ctrl+5）で、キャンバスの上で
   各状態が見られる。
3. ボタンを選んで（枠の中、十字の図以外をクリック）、**ハイライト** を別のグループに変える。
   同じグループのボタンはまとめてハイライトされるので、「チャプター 1 / 2 / 3」の列が
   ひとつのまとまりに見える。
4. 色を決めるのは **メニュー ▸ メニューカラーセットを編集…**。**プレビュー** に印を付けて、
   ボタンが見える部分を残すようにダイアログを横にどけると、色や不透明度を変えた瞬間にメニューが
   変化する。**選択時のカラーをアクティベート時のカラーとして使用** を入れると、押したときの
   見た目が乗ったときと同じになる。
5. たいていのディスクでは全体で 1 つの配色を使う。メニューの初期設定を 1 回変えれば、
   それを使っているメニューは全部ついてくる。

色を別のプロジェクトへ持ち込むには、メニューをテンプレートに保存して（Ctrl+Alt+M）
そちらで開く。メニューのカラーセットにはファイルがない。字幕のカラーセットにはある
（`.dccolors`、[10.3](#103-見た目)）。

![メニューカラーセットのダイアログ](images/user-guide/color-set.png)

### 14.6 モーションメニューに音と動きを

メニューは、背景が動画になった瞬間にモーションメニューになる。作り方は手間が少ない順に 3 とおり。

**普通のメニューの後ろに動画を置く**

1. 動画をアセットとして読み込む（**ファイル ▸ 読み込み ▸ アセット…**、Ctrl+I）。
   メニューの後ろに置くのはタイムラインではなく動画。
2. メニューを選んでシートの **モーション** タブを開き、**背景** で動画を選ぶ。
   ボタンのうしろに最初のフレームが映り、ボタンも図形もそのまま残る。PSD から作ったメニューでは、
   動画は PSD の一番下のレイヤーの代わりになり、ほかのレイヤーは動画の上に残る。
3. **ループ**（メニューに使う動画の秒数）、**ループ回数**（1 回だけにする **なし**、数字、または
   **無限**）、最初から回したくないときは **ループポイント** を決める。
4. **デュレーション**（メニューは最大 254 秒）と、時間切れの行き先である **エンドアクション**
   を決める。エンドアクションがないとモーションメニューはくり返し、静止メニューは最後の絵で止まる。
5. **オーディオ** は、メニューが出ている間に鳴り続ける音。静止メニューは音声の長さで
   くり返す。

**EffectCraft で動きを付ける**

**メニュー ▸ EffectCraft コンポジションを作成…** は、メニューをレイヤー付きの PSD に
書き出し、ディスクのフレームレートと画素の形で EffectCraft のプロジェクトを作り、
`<メニュー名> モーション.mp4` のレンダーをキューに入れて開く。そこでレイヤーを動かす
（タイトルを滑り込ませる、背景をゆっくり揺らす）と、レンダーされたムービーを
DiscCraft が読み取って、自動的にメニューの背景に設定する。そのあと:

- 動かしたレイヤーは **レイヤー** パネルで非表示にする。ディスクではレイヤーが空の状態で
  始まり、ムービーと一緒に現れるので、二重に描かれない。
- **ループ回数** を **なし** にする。メニューを開いたときに 1 回流れて、最後の絵で止まる
  （くり返さない）。
- **ファイル ▸ レンダリング ▸ モーションメニュー** のあとプロジェクトプレビューで見るか、ビルドしてから見る
  （**ウィンドウ ▸ モニター**、F9、**ビルド結果を開く**）。レンダリングするまでと、メニュービューアでは
  いつも、モーションメニューは背景の最初のフレームを映す。Encore と同じ。

**ボタンを動かす**

**モーション** タブの **モーションボタン** を入れると、メニューのサムネールボタンが動画を
再生する。ビットレートがかかる上、古いプレーヤーがいちばん嫌がる種類のモーションメニューなので、
量産する前に実機のプレーヤーで確かめる。**ファイル ▸ レンダリング ▸ モーションメニュー** のあとは
プロジェクトプレビューでボタンの動画が動く。スライドショーにリンクしたボタンは、Encore と同じく
最初のスライドのまま止まっている。

![メニューのモーションのタブ](images/user-guide/motion-tab.png)

### 14.7 ボタンへのリンクの入れ方 5 とおり

| 入れ方 | やり方 | 向いている場面 |
|---|---|---|
| プロジェクトパネルからドラッグ | タイムライン・スライドショー・再生リスト・チャプター再生リストをキャンバスに落とすと、その場にボタンが増え、名前とリンクが付く | メニューを作りながら、項目が手近にあるとき |
| **リンク** 欄 | ボタンを選んでシートで行き先を選ぶ。ボタンの一覧にはタイムラインそのものと、そのチャプターが並ぶ | 複数のボタンを順に決めていくとき |
| ピックウィップ | 欄の右の **▶** を押してから、プロジェクトパネルの項目をクリック | 長い一覧のずいぶん下に行き先があるとき |
| **オブジェクト ▸ リンクの指定…**（Ctrl+L） | 種類の順に並んだ全項目のダイアログ。ボタンのときは、切り替わるオーディオと字幕も決められる | プロジェクト全体を 1 つの一覧で見たいとき、トラックも一緒に決めたいとき |
| フローチャート | ボタンのポートから別のノードへドラッグ、またはノードの右クリックの **リンクの指定…** | ナビゲーションを描きながら、行き先を見たいとき |

エンドアクション・上書き・リモートメニューも同じ 5 とおりで入れられる。行き先のうち
2 つは覚えておくといい: **停止** は再生を終え、**前のメニューに戻る** は観てきたメニューへ
戻る。「全編再生」らしく動くのは後者。

### 14.8 フローチャートをディスクの地図として使う

フローチャート（**ウィンドウ ▸ フローチャート**、F5）は、ナビゲーションを探すのではなく読む場所。
上にディスクのノードがあり、そこに **ファーストプレイ**・**タイトルボタン**・ディスクの
**上書き** が付き、その下にメニュー・タイムライン・スライドショー・再生リストが箱となり、
リンクが線になる。

- 下の **リンクされていない項目** の行から箱をドラッグして、ディスクのノードの **ファーストプレイ**
  のポートに落とすと、ディスクを入れると最初に再生されるものになる。
- ボタンのポートからメニュー・タイムライン・スライドショー・再生リストへドラッグすると
  リンクする。エンドアクションのポートから引けば、その項目が終わったあとの行き先になる。
  線はすべて行き先に矢印の頭が付くので、上の階層のメニューへ戻るメニューもループとして
  読めて、線の入っていない箱は孤立だと分かる。
- **自動レイアウト** / **すべて自動レイアウト** で箱の並びを整えられる。手で置いた箱は、その箱の
  **自動レイアウト** を押すまで動かした場所に留まる。
- ノードの右クリックに **開く** / **リンクの指定…** / **名前の変更…** / **ファーストプレイに設定** /
  **ここからプレビューする**（その項目からプレビューが始まる）。
- **表示 ▸ すべてのサムネールを表示** で箱に絵を出す。どれがどのメニューだったか分かる
  いちばん早い方法。

再生がおかしくなるディスクは、たいていエンドアクションの抜けか孤立が原因。両方ともチェックに出る
（[11](#11-プロジェクトをチェックする)）し、フローチャートでは線の入っていない箱として見える。

![リンクしたメニューとタイムラインのフローチャート](images/user-guide/flowchart.png)

### 14.9 作業しながらディスクの大きさを読む

ビットバジェッティングとは、ディスクに収まる画質を決めること。ディスクの容量は決まっていて、
動かせるのは映像のビットレートだけ。

- **ビルド** パネルの **ディスク情報** のバーが今の合計（**容量を更新** で計算し直す）。
  小さいプロジェクトなら、ときどき見るだけで十分。
- DVD は全部いっしょに数える: ビデオ、オーディオ、字幕、モーションメニューの動画。
  1 本のタイトルの上限は 9.8 Mbps で、ビデオをそのまま使うタイムラインが超えると
  チェックに出る（**高すぎるタイムラインビットレート**）。
- 変換する映像は、既定ではディスクの容量に合わせて 9.8 Mbps まででビットレートを決める。
  長いと低くなり、低くなった影響はまず動きの速い所とフィルムの粒子に出る。
- 収まらないときの選択肢は昔から 3 つしかない: 内容を減らす、レートを下げる、大きいディスクに
  する（DVD9、BD50…）。DVD-9 はレイヤーブレークが加わるので、場面変わりに置くのがいちばん
  自然。**レイヤーブレーク** でタイムラインとタイムコードを決める（[13](#13-ビルドする)）。
- 音声の分もきちんと数える。変換すると AC-3 192 kbps だが、AC-3・WAV・DTS はそのまま載るので、
  1.5 Mbps の WAV や DTS のトラックは、その分だけ映像から減る。
- DVD5 のざっくりした目安: 上限のレートで 1 時間弱、多くの人が文句を言わないレートで 2 時間くらい。
  動きの激しい映像を 1 枚に 2 時間入れると、画質の劣化が目立ち始める。

### 14.10 Blu-ray

同じプロジェクトを Blu-ray としてもビルドできる。**ファイル ▸ プロジェクト設定…** か
**ディスク** パネルでオーサリングモードを切り替え、**ディスク** パネルで映像の大きさ SD（MPEG-2）/
HD（H.264）も決める。

- Blu-ray は HDMV のみ（BD-J なし）で、メニューの作り方は DVD と同じ。
- **ポップアップメニュー** は Blu-ray のリモートメニュー。メニューの
  **ポップアップ** タブで作り、タイムラインの **リモートメニュー** に設定する。
  再生の最中にリモコンで呼び出せる。メニューが描くもの（文字、画像、デザインどおりのボタン）が映像の上に出る
  （メニューの背景は出ない）。PSD から作ったポップアップメニューは、Encore と同じく、ボタンのセットと `(#)` のページの
  ボタンだけが出て、その外のボタンでないレイヤー（白い Background など）は出ない。メニューのビューアも、背景タイムラインを
  決めていなければ透明（市松模様）の上に、ディスクで出るものだけを表示する。ページのあるポップアップメニュー（**メニュー ▸ 新規ページを追加**）は、全ページが
  まとめて出て、最初のページから始まる。別のページへのボタンは、タイトルの再生を続けたままページを替える
  （ページは 254 まで、ボタンは 1 ページに 254 まで。それを超えると、そのボタンは今までどおりタイトルを離れて
  そのページのメニューへ行く）
- HD（1080p、720p）は H.264 で、クリップは IDR 画像でつながるので、トリムした位置どおりに
  出る（DVD で変換するクリップも同じ。そのまま入る MPEG-2 は GOP の頭で切れる）。
- DTS のファイルは、DVD と同じく Blu-ray にもそのまま（コアを）入れられる。
- HD か PAL の Blu-ray の字幕は、同じトラックで前の字幕から 5 フレーム以上空ける
  必要がある。チェックに出る（**字幕の間隔**）。
- ビルドは同じ（**ファイル ▸ ビルド ▸ フォルダー…** / **イメージ…**）。フォルダーは `VIDEO_TS`
  ではなく `BDMV` になる。プロジェクトプレビューとモニターは、ビルドした Blu-ray
  をポップアップメニュー込みで再生する。

|---|---|
| macOS と Linux でのディスクへの書き込み | ない（Windows はレコーダーのディスクに書き込める）。フォルダー、ISO、DVD の DDP イメージを書く |
| コピーガード（CSS、AACS） | ない。リージョンコードのフラグだけ |
| BD-J メニュー | ない。Blu-ray は HDMV |
| 目盛りに出る GOP ヘッダーの印と、Alt での GOP 送り | ない。そのまま入る MPEG-2 では、チャプターポイントとトリムは自動的に GOP の頭へ吸着する（変換する映像はどのフレームでも切れる） |

## 15. 環境設定

**編集 ▸ 環境設定…**（Ctrl+K）。左に分類、右に設定。

| 分類 | 内容 |
|---|---|
| 一般 | テレビ方式の初期設定（新規プロジェクトの既定）。**再生画質**（Encore と同じ 高 / ドラフト / 自動）: モニターでタイトルを再生するときの絵の大きさ。高はディスクのフレームの大きさ、ドラフトは半分、自動（初期値）は 1280 × 720 より大きい HD だけ半分（1080 ラインのタイトルがなめらかに再生される）。`workspace.json` に保存 |
| オーディオ・ビデオ出力 | **オーディオ出力デバイス**: システムの既定、または出力デバイスのどれか。モニターとプレビューの再生の音を出す（次に再生を始めたときから。なくなったデバイスのときは既定のデバイスで鳴る）。**ビデオ出力**: オフ、**専用のウィンドウ**、または（Windows では）つないであるディスプレイのどれか — モニターやプレビューが再生しているタイトルの絵を、そのディスプレイに全画面で、または好きな場所に置けるウィンドウにも映す。そのウィンドウで Esc を押すとオフになる。メニューは出さず、タイトルの絵だけ。**バックグラウンド動作時のビデオ出力を無効**（初期値オン）は、DiscCraft のウィンドウがどれも前面にないあいだ出力のウィンドウを消す。`workspace.json` に保存 |
| タイムライン | 静止画デュレーション（新しいスライドショーのスライドの長さ。初期値 6 秒）、字幕デュレーション（モニターで足す字幕の長さ。初期値 2 秒）、オーディオの言語 / 字幕の言語（新しいトラックの言語。空ならディスクのオーディオの言語）、字幕クリップをスナップ（初期値オフ）。`workspace.json` に保存 |
| プレビュー | プロジェクトプレビューとモニターが再現するプレーヤーの設定。**テレビモード**: 16:9 ワイドスクリーン、4:3 レターボックス（16:9 のタイトルを 4:3 の画面に上下の帯つきで映す）、または 4:3 パン&スキャン（16:9 のタイトルの真ん中を 4:3 の画面いっぱいに映し、左右は切れる）。**プレーヤーリージョンコード**: すべてのリージョン、または 1〜8 のどれか — ほかのリージョンに限った DVD はプレビューで開かない（理由はステータスバーに出る）。**オーディオの言語**: ディスクがオーディオトラックを選ばないとき、タイトルのこの言語の最初のトラックを鳴らす。**字幕の言語**: 字幕を出していないとき、タイトルのこの言語の最初の字幕トラックを出す。プレビューで開いたビルド済みの Blu-ray も、ディスクがストリームを選んでいない間は、プレーヤーと同じくこれらの言語の最初の音声・字幕を選ぶ。**プレーヤーの視聴制限レベル**: なし、または 1〜8 — 視聴制限レベル（ビルドパネル）がこれより高いディスクは、ロックされたプレーヤーと同じく再生されない（プレビューにはパスワードを入れる相手がいない）。初期値（ワイドスクリーン、すべてのリージョン、言語なし、レベルなし）では、どのディスクもそのまま再生される。**再生画質をプレビュー**: プロジェクトプレビューのタイトルでの同じ選択（初期値は高）。`workspace.json` に保存 |
| メディア | **ライブラリコンテンツ**（自分のライブラリの項目）と **メディアキャッシュデータベース**（メディアファイルについて覚えておいた長さ・寸法・サムネールと、MKV とトランスポートストリーム（`.m2ts` / `.ts` / `.mpg` / `.vob`）の索引。大きなファイルも次に起動したときはすぐ開く）の場所。それぞれ **参照…**（別のフォルダーに置く）、**初期設定**（設定の隣に戻す）、**エクスプローラーで表示** がある。ライブラリのあるフォルダーを選ぶとそのライブラリを開き、空のフォルダーなら今の項目をそこに書く。キャッシュは選んだときから新しいフォルダーを使い、前のフォルダーはそのまま残る。**消去** はメディアキャッシュを空にする: ファイルは次に必要になったときに読み直す（ビルドの変換はビルドの出力先にあり、消えない）。素材のファイルの中にも隣にも、何も書かない |
| メニュー | ボタンのルート（上下左右の動き、折り返し方と折り返しの方式、「次へ」「前へ」ボタンを除外）、ボタンの名前の同期の既定。**プロジェクトに保存される**（どのパソコンでビルドしても同じルートになる） |
| メモリ | **搭載されている RAM** と、**同時にトランスコードする数**: 自動（プロセッサーのコアの数）、または数。ビルドと「今すぐトランスコード」は複数のタイトルを同時に変換し、変換ごとにメモリを使うので、ほかのアプリケーションに残したいときは数を減らす。**HD の H.264 にハードウェアエンコーダーを使う**（Windows。グラフィックスカードのエンコーダーが見つかったときだけ選べる。初期値はオフ）: Blu-ray の 1080p と 720p の H.264 を 1 パス（VBR か CBR）で変換するとき、プロセッサーの代わりにハードウェアで符号化する。1080i・SD・2 パスと、エンコーダーが開けない・途中で失敗したビデオはプロセッサーで変換する。CLI では環境変数 `DISCCRAFT_HARDWARE_ENCODER=1`。`workspace.json` に保存 |
| 表示方法 | 表示言語（日本語 / English）。**ウィンドウ ▸ 言語** でも切り替えられる。自分で選ぶまでは、起動のたびに OS の表示言語に従う（日本語の OS は日本語、英語とそれ以外の言語の OS は英語） |

## 17. コマンドラインとスクリプト

GUI と同じ操作は `disccraft-cli` からでもできる（ビルド、プロジェクトの検査、スクリプトの実行）。

```
cargo run -p disccraft-cli -- commands [--json]
cargo run -p disccraft-cli -- exec <project.dcproj> <command> [params-json]
cargo run -p disccraft-cli -- run <project.dcproj> <script.jsonl>
cargo run -p disccraft-cli -- inspect <project.dcproj> [--json]
cargo run -p disccraft-cli -- build <project.dcproj> --out <dir>
cargo run -p disccraft-cli -- build <project.dcproj> --iso <file> [--cache <dir>] [--audio-language ja]
cargo run -p disccraft-cli -- build <project.dcproj> --ddp <dir>
```

- `commands` はエンジンのコマンドの一覧（ID、表示名、メニューの場所、ショートカット、パラメータ）。`--json` で JSON
- `exec` はコマンド 1 つを実行して結果を JSON で出す。プロジェクトが未保存なら保存する
- `run` は JSON Lines のスクリプトを実行する。1 行が 1 コマンドで `{"command": "...", "params": {...}}`。
  `#` と `//` で始まる行は無視。スクリプトは 16 MB まで
- `inspect` はプロジェクトの要約（`--json` で `project.inspect` の JSON）
- `build` は `--out` でフォルダー、`--iso` でイメージ、`--ddp` で DVD の DDP イメージ（そのフォルダーに）を作る。
  `--cache` で変換した素材の置き場所を、
  `--audio-language` で言語の付いていない音声の言語（ISO 639-1）を指定する

## 18. AI エージェントから使う（MCP）

`disccraft-cli mcp` は MCP サーバー（標準入出力の JSON-RPC）として動く。ツールは 3 つ。

| ツール | 内容 |
|---|---|
| `disccraft_commands` | コマンドの一覧（ID、表示名、メニュー、ショートカット、パラメータ） |
| `disccraft_execute` | コマンド 1 つとパラメータを実行 |
| `disccraft_inspect` | 今のプロジェクトの検査とチェック結果 |

MCP クライアントには、コマンドに `<リポジトリのパス>/target/release/disccraft-cli`、引数に `mcp` を登録する
（標準入出力でつなぐ）。

## 19. 上限と決まり

| 項目 | 上限 |
|---|---|
| ボタン | 1 メニュー 36 個 |
| メニューのデュレーション | 254 秒 |
| タイムラインのビデオクリップ | 99 本 |
| チャプター | 1 タイトル 99 個（DVD） |
| DVD のタイトル | 99 本 |
| オーディオトラック | 8 本 |
| 字幕トラック | 32 本 |
| チャプターインデックス | 1 ページ 18 ボタン（複数ページは 1 ページ 6 ボタン） |
| スライドのデュレーション | 既定 6 秒。トランジション 0.1〜10 秒（既定 2 秒） |
| 字幕のトリム | 最短 0.4 秒（NTSC 13 / PAL 11 フレーム） |
| 字幕の文字 | タイトルセーフの枠に、NTSC の標準の大きさで 10 行まで |
| 字幕のすき間 | Blu-ray（HD / PAL）は 5 フレーム以上（DVD は制限なし） |
| DVD のビットレート | ビデオ・オーディオ・字幕を合わせて 9.8 Mbps |
| 容量 | DVD5 4.7 GB、DVD9 8.5 GB、BD25 / BD50 / BD100 / BD128、カスタムのサイズ |
| ドロップ | 1 回 500 ファイル |
| 最近使用したプロジェクト | 10 件 |
| ワークスペース | 32 個（名前は 64 文字） |

ほかの決まり:

- ボタンのハイライトはディスクに載せると重ならない（編集画面では重ねられる）
- タイムラインはビデオを 1 本目に持つ
- そのままディスクに入る MPEG-2 は GOP の頭で切れる（トリムとチャプターはいちばん近い GOP の頭へ）。変換する映像は
  フレームの位置で切れる
- 16:9 のメニューも SD では同じ 720×480 の枠を使い、横に引き伸ばして映す（HD の Blu-ray は 1920×1080 の枠）。
  DVD のメニューの縦横比はディスク全体で共通
- 音声は変換すると Dolby Digital（AC-3）192 kbps。AC-3 と WAV の素材はそのまま使える。DTS（`.dts`）もそのまま使える
- DVD に合った MPEG-2 の映像（720 / 704 / 352 幅）は変換しない。1 本のタイトルのクリップは同じ幅にそろえる
- MPEG-1 の映像（VCD の `.mpg`、`.m1v`）は、352x240（NTSC）か 352x288（PAL）で、ストリームの示すビットレートが 1.856 Mbps
  までなら、DVD にそのまま 4:3 で入れる。可変ビットレートと示すものはファイル全体を測り、どの 1 秒も 1.856 Mbps を
  超えなければそのまま、超えれば変換する。MPEG オーディオは Dolby Digital に変換する。
  MPEG-1 と MPEG-2 のクリップは 1 本のタイトルにつながない。Blu-ray では MPEG-1 は変換する

## 20. うまく動かないとき

| 症状 | しかた |
|---|---|
| 素材が「オフライン」 | プロジェクトパネルの右クリック ▸ **アセットを置き換え…** で新しい場所を教える |
| ビルドが「問題があります」で止まる | **プロジェクトをチェック…** を開いて **名前** と **問題** を見る。直せないときはダイアログで **無視して続行** |
| メニューが再生されない | ファーストプレイとボタンのリンク、エンドアクションをフローチャートで確認する |
| ボタンが効かない | ハイライトが重なっていないか（赤枠）、**表示 ▸ ボタンルートを表示** で矢印の行き先を見る |
| 隠しボタンに辿り着けない | 辿れるボタンからルートが伸びているか: [隠しボタンとイースターエッグ](#144-隠しボタンとイースターエッグ) |
| 音が出ない | モニターの見出しのスピーカーボタンで聞くトラックを選ぶ。DTS のトラックはモニターとプレビューでは鳴らない（ディスクには入る）。Linux では ALSA の開発パッケージ（`libasound2-dev` など）が要る |
| EffectCraft のプロジェクトが思った絵にならない | アセットのプロパティの **コンポジション** で使うコンポジションを選ぶ |
| 文字化けする | **ウィンドウ ▸ 言語** で表示言語を切り替える。字幕は UTF-8 / UTF-16 / Shift_JIS を読む |
| 画面の並びがバラバラになった | **ウィンドウ ▸ ワークスペース ▸ 「名前」をリセット** |
| 書き出したディスクが再生できない | 書き出したフォルダーやイメージをソフトウェアのプレーヤー（VLC など）で開き、ffprobe でストリームが読めるかを見て、どこで止まるかを確かめる |
| 問題を報告したい | **ヘルプ ▸ システム互換性レポート…** の **コピー** で環境を、**ヘルプ ▸ ログファイルを表示…** でこの起動からの操作の記録（ログ）を取り出し、**ヘルプ ▸ 問題を報告…** に添える。DiscCraft が異常終了したときも、ログのフォルダーにその時のログが残る |
| 新しい版があるか知りたい | **ヘルプ ▸ アップデートを確認…** でこの版を確かめ、GitHub のリリースを開く（DiscCraft は自分では通信しない） |
| パネルが見つからない | **ウィンドウ** メニューにすべてのパネルの名前がある（× で閉じてもここから開き直せる） |
