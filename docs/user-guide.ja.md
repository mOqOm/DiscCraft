## 1. DiscCraft について

DiscCraft は映像・音声・静止画から DVD-Video と Blu-ray（BDMV）を作るオーサリングソフト。
メニュー、チャプター、複数の音声・字幕、ナビゲーションを組み立て、規格に合わない素材を自動で変換して、
フォルダか ISO イメージに書き出す。

できること:

- DVD-Video（`VIDEO_TS` フォルダ、ISO）と Blu-ray（`BDMV` フォルダ、ISO）
- 静止メニューとモーションメニュー、ボタンとハイライト、PSD からのメニュー作成
- 複数のビデオクリップをつないだ 1 本のタイトル、チャプター、オーディオ / 字幕トラック
- DVD に合った MPEG-2 の映像と、AC-3 / WAV / DTS の音声は、変換せずにそのまま収録
- スライドショー、再生リスト、チャプター再生リスト、ファーストプレイ、タイトルボタン
- ビルドしないプレビュー（プロジェクトプレビュー）と、ビルド結果のモニター再生
- GUI・コマンドライン・MCP で同じ操作（すべての操作はエンジンのコマンド）

できないこと（いまのところ）:

- ディスクへの書き込み。フォルダと ISO を作るだけで、焼くのは別のソフトに任せる
- コピーガード（CSS、AACS など）。リージョンコードのフラグ設定だけ
- BD-J メニュー（Blu-ray は HDMV のみ）、DTS / Dolby TrueHD / DTS-HD のエンコード（DTS のファイルを DVD にそのまま入れることはできる）
- 動画の編集そのもの（編集は FilmCraft で作り、DiscCraft でディスクにする）
- 1080i と MPEG-2 の HD、4K（Ultra HD Blu-ray）

Blu-ray の映像は SD（720×480 / 720×576）の MPEG-2 か、HD（1080p、720p）の H.264。
HD の 1080p の 25 / 29.97 / 50 / 59.94 は Blu-ray の規格外で、今後削除する予定。

## 2. はじめに

### 2.1 ようこそ画面

起動するとようこそ画面が開く。

- **最近使用したプロジェクト**: 開いたことのあるファイル（最大 10 件）。行をクリックすると開く。
  右クリックの **一覧から削除** で一覧から外す（ファイルは消えない）。なくなったファイルは灰色になり、開けない
- **新規プロジェクト**: 新規プロジェクトダイアログを開く
- **プロジェクトを開く…**: `.dcproj` を選ぶ
- **終了**: アプリを終了する

ようこそ画面を閉じたあとは、**ファイル ▸ 新規 ▸ プロジェクト**（Ctrl+N）と
**ファイル ▸ プロジェクトを開く…**（Ctrl+O）で同じことができる。

### 2.2 新規プロジェクト

**新規プロジェクト** ダイアログは **基本** と **詳細設定** の 2 タブ。

| タブ | 項目 |
|---|---|
| 基本 | 名前、場所、オーサリングモード（DVD / Blu-ray）、テレビ方式（NTSC / PAL）、トランスコードの設定の要約 |
| 詳細設定 | 縦横比（4:3 / 16:9）、ディスク容量（DVD5 / DVD9、BD25 / BD50 / BD100 / BD128） |

- 場所を空にすると、保存のときに場所を聞く
- テレビ方式の初期設定は [環境設定](#14-環境設定) で変えられる
- **OK** を押すと `<場所>/<名前>.dcproj` がその場で作られ、編集が始まる

あとから変えられるもの: **ファイル ▸ プロジェクト設定…** でオーサリングモード・縦横比・容量、
**ビルド** パネルの **ディスク情報** でディスクの名前と容量、**ディスク** パネルでディスクの設定全般
（Blu-ray の映像の大きさ SD（MPEG-2）/ HD（H.264）もここ）。

### 2.3 保存

- **ファイル ▸ 保存**（Ctrl+S）。ビルドするときも先に保存される
- **ファイル ▸ 別名で保存…**（Shift+Ctrl+S）
- 未保存の変更がある状態でプロジェクトを閉じる・開き直す・終了しようとすると確認が出る

プロジェクト（`.dcproj`）は JSON のテキストファイル。素材はコピーせず、パスで参照する。
素材を別の場所に動かすと「オフライン」になるので、**アセットを置き換え…** で新しい場所を教える。
プロジェクトの横に `<プロジェクト>.menus` フォルダができることがある（メニューを PhotoCraft などで編集するときの
PSD を入れる場所）。

### 2.4 設定の保存場所

ワークスペースの並び、表示言語、最近使用したプロジェクト、表の列の幅は設定ファイルに保存する。

| 場所 | 内容 |
|---|---|
| Windows: `%APPDATA%\disccraft\workspace.json`<br>ほか: `~/.config/disccraft/workspace.json` | ワークスペース、パネルの並び、表示言語、最近使用したプロジェクト、既定のテレビ方式 |
| 同じフォルダの `library.json` | ライブラリに足した自分のメニューとボタン |

## 3. 画面の構成

メニューバーの下にツールバー、いちばん下にステータスバー、その間をパネル（ドッキングするタブグループ）が埋める。
ステータスバーには直前の操作の結果と、ビルド中の進み具合が出る（Encore にない DiscCraft だけの部分）。

### 3.1 メニューバー

**ファイル / 編集 / オブジェクト / メニュー / タイムライン / 表示 / ウィンドウ / ヘルプ** の 8 つ。
項目とショートカットは Encore の既定に寄せている。よく使うもの:

- **ファイル ▸ 新規 ▸**（プロジェクト / メニュー / タイムライン / スライドショー / 再生リスト / チャプター再生リスト）
- **ファイル ▸ 読み込み ▸**（アセット… / メニュー… / ポップアップメニュー… / メニューページ… / タイムライン… / スライドショー…）
- **ファイル ▸ プレビュー / プロジェクトをチェック… / ビルド ▸ フォルダー…・イメージ…**
- **編集 ▸ 環境設定…**、**編集 ▸ ヒストリー ▸**（取り消せる操作の一覧からまとめて巻き戻す）
- **オブジェクト ▸**（ボタンに変換 / オブジェクトに変換、リンクの指定…、ドロップシャドウ…、反転、回転、アレンジ、整列、均等配置）
- **メニュー ▸**（新規メニュー、チャプターインデックスを作成、メニューを置き換え…、新規ページを追加、カラーセットを編集…、
  ユーザー操作を設定…、メニューをファイルとして保存…、メニューをテンプレートとして保存…、エンドアクションを設定…）
- **タイムライン ▸**（新規タイムライン / 新規スライドショー / 新規チャプター再生リスト、トラックの追加と削除、
  字幕の読み込みと書き出し、チャプターポイントの追加）
- **表示 ▸**（ズーム、サブピクチャの 3 状態、セーフエリア、ボタンルート、ガイド、チャプター名）
- **ウィンドウ ▸**（ワークスペース、パネルの出し入れ、表示言語）

### 3.2 ツールバー

左にメニュー編集のツール、右端にワークスペースの選択。

| ツール | キー |
|---|---|
| 選択ツール | V |
| ダイレクト選択ツール | A |
| 移動ツール | M |
| 回転ツール | R |
| 横書き文字ツール | T |
| 縦書き文字ツール | Y |
| ズームツール | Z |

その右に **メニューを PhotoCraft で編集**（Shift+Ctrl+M）と **プレビュー**（Alt+Ctrl+Space）のボタンがある。

### 3.3 パネル

初期設定のワークスペースの並びは Encore と同じ。

| 場所 | タブ |
|---|---|
| 左 | プロジェクト / メニュー / タイムライン / ビルド |
| 中央 | モニター / メニュービューア / フローチャート |
| 右上 | プロパティ / ディスク |
| 右下 | ライブラリ / レイヤー |
| 下 | タイムラインビューア / スライドショービューア |

- **プロジェクト**: すべての項目（アセット、タイムライン、メニュー、スライドショー、再生リスト、チャプター再生リスト、
  フォルダー）の一覧。列は並べ替え・表示 / 非表示・幅の調整ができる。右クリックに 開く / 名前の変更… /
  ファーストプレイに設定 / アセットを置き換え… / エクスプローラーで表示 / 削除 など
- **メニュー**: メニューの一覧と、選んだメニューのボタン一覧
- **タイムライン**: タイムラインの一覧
- **ビルド**: [ビルドパネル](#13-ビルドする)
- **モニター**: ビルドしたディスクの再生と、タイムラインのプレビュー。下の操作バーにタイムコードとズーム、
  チャプターの旗付きのスクラブバー、再生 / 停止 / 前・次のチャプター / 前後 1 フレーム / チャプターポイントを追加 /
  ポスターフレーム、セーフエリアと字幕のボタン、**ビルド結果を開く** がある
- **メニュービューア**: メニューのキャンバス。タブの名前は開いているメニューの名前になる
- **フローチャート**: 項目とリンクの図。ノードはドラッグで動かせる
- **プロパティ**: 選んでいる項目のシート。何も選んでいないときはディスクの設定
- **ディスク**: ディスクの名前・説明・縦横比・オーディオ / 字幕・ユーザー操作
- **レイヤー**: メニューの層（目と鍵、`(+)` ボタンセット、`(=1)`〜`(=3)` のハイライト、T のテキスト、% の図形、背景は固定）
- **ライブラリ**: DiscCraft 独自のプリセット（メニュー / ボタン / 画像 / 背景 / シェイプ）と、自分の項目
- **タイムラインビューア**: FilmCraft と同じ形のタイムライン（V1 / A1 / S1 の見出し、波形、チャプターの旗）
- **スライドショービューア**: スライドの一覧と並べ替え、スケールとトランジション

### 3.4 パネルの並べ替えとワークスペース

タブはドラッグで並べ替え、ほかのグループへ移動、分割、フローティングができる。中クリックか × で閉じ、
**ウィンドウ** メニューから開き直すと閉じる前の場所に戻る。並びはワークスペースごとに自動で保存される。

**ウィンドウ ▸ ワークスペース** に組み込みの 4 つと、自分で保存したものが並ぶ。

| 名前 | 前面に出すもの |
|---|---|
| 初期設定 | Encore の既定の配置（すべてのグループ） |
| メニュー | メニューの一覧、メニュービューア、レイヤー |
| ナビゲーション | フローチャート |
| ビルド | ビルドパネルとディスク |

**新規ワークスペース…** で現在の並びに名前を付けて保存する（最大 32 個、名前は 64 文字）。
**ワークスペースを削除**、**「名前」をリセット** もここ。ツールバー右端の **ワークスペース** のコンボでも切り替えられる。

## 4. 素材を読み込む

### 4.1 読み込み方

- **ファイル ▸ 読み込み ▸ アセット…**（Ctrl+I）
- ウィンドウにファイルをドラッグ＆ドロップ（フォルダを落とすと中のメディアファイルを取り出す。1 回に最大 500 件）
- **ファイル ▸ 読み込み ▸ タイムライン…**（Shift+Ctrl+T）: 選んだビデオ 1 本ごとにアセットとタイムラインを作る
- **ファイル ▸ 読み込み ▸ スライドショー…**（Shift+Ctrl+G）: 選んだ画像をスライドにしたスライドショーを 1 つ作る
- **ファイル ▸ 読み込み ▸ メニュー… / ポップアップメニュー… / メニューページ…**（Shift+Ctrl+I / Shift+Ctrl+K /
  Shift+Ctrl+U）: 階層 PSD（または PhotoCraft の `.pcraft`）をメニューにする

### 4.2 読めるファイル

| 種類 | 拡張子 |
|---|---|
| アセットとして読み込めるもの | mp4、mov、m4v、avi、mkv、m2v、wav、ac3、dts、mp3、aac、flac、png、jpg、jpeg、bmp、tif、tiff、psd、pcraft、svg、srt |
| タイムラインにできる映像 | mp4、mov、m4v、avi、mkv、mxf、m2v、mpg、mpeg、vob、m2ts、ts |
| 字幕 | srt、vtt、txt |
| メニューのデザイン | psd、pcraft |
| Craft の書類 | `.scraft`（SoundCraft のセッション → 音声）、`.ecproj`（EffectCraft のプロジェクト → ビデオ）、`.fcproj`（FilmCraft のシーケンス → タイムライン） |

SVG は表示する大きさで描くのでぼけない。字幕のテキストは UTF-8 / UTF-16 / Shift_JIS を読む。

EffectCraft のプロジェクト（`.ecproj`）にコンポジションがいくつもあるときは、アセットのプロパティの **コンポジション** で
使うものを選ぶ（選ばなければ、EffectCraft で開いていたコンポジション）。同じファイルをもう一度読み込めば、
アセットごとに別のコンポジションを使える。

DTS のファイル（`.dts`）は、DVD のオーディオトラックにデコードせずにそのまま入る（48 kHz、1509.75 kbps まで）。
Blu-ray にはまだ入れられず、モニターとプレビューでは鳴らない。

### 4.3 素材について

- プロジェクトパネルの行に、寸法・フレームレート・長さ・変換が必要かどうかが出る
- 規格に合わない素材はビルドのときに自動で変換する（音声は Dolby Digital（AC-3）192 kbps、
  ビデオのビットレートは容量に合わせて決める。既定では 9.8 Mbps まで）
- すでに DVD に合っている MPEG-2 の映像は変換しない: エレメンタリーストリーム（`.m2v`）も、映像と音が一緒に入った
  プログラムストリーム（`.mpg` / `.vob`。AC-3 の音もそのまま）も、704×480・352×480・352×240（PAL は 576 / 288 ライン）の
  映像もそのまま使う。HD の Blu-ray では DVD 用の変換は走らない
- **編集 ▸ オリジナルを編集**（Ctrl+E）で、その素材を作ったアプリ（画像は PhotoCraft、音声は SoundCraft、
  ビデオは FilmCraft または EffectCraft）で開く。保存すると自動で読み直す
- プロジェクトパネルの右クリックに **アセットを置き換え…**（offline になった素材の場所を教える）と
  **エクスプローラーで表示** がある
- 使用中の素材は削除できない。使っている項目から外すと、その項目へのリンクは未設定に戻る

## 5. タイムラインを作る

### 5.1 作成

ビデオのアセットを選んで **ファイル ▸ 新規 ▸ タイムライン**（Ctrl+T）、または **タイムライン ▸ 新規タイムライン**。
選んでいるビデオがないときは、**新規タイムライン** のサブメニューのビデオの一覧から選ぶ。
DiscCraft のタイムラインは必ずビデオを 1 本目に持つ。

FilmCraft で編集した作品からは **タイムライン ▸ FilmCraft のシーケンスからタイムラインを作成…** が使える。
**タイムライン ▸ FilmCraft のマーカーを読み込み…** で、開いているタイムラインにシーケンスのマーカーを
チャプターポイントとして追加することもできる。

### 5.2 複数のビデオクリップ

タイムラインビューアに別のビデオをドラッグすると、前のクリップの直後に詰めて置かれ、つなぎ目にチャプターができる
（1 本のタイトルに最大 99 本のクリップ）。クリップの端をドラッグしてトリムすると、切り口は MPEG-2 の GOP の頭へ
吸着する。

- 変換が要らない MPEG-2 のクリップは、トリムしたままパススルーできる
- 変換が要るクリップ（H.264 など）もつないでビルドできるが、DVD ではトリムした位置では切れない
- HD の Blu-ray はクリップごとに H.264 をエンコードして IDR でつなぐので、トリムどおりに出る
- 1 本目のクリップも消せる（2 本目が新しい 1 本目になる）
- クリップの本体を左右にドラッグすると動かせる。前のクリップとの間にできた空きは、ディスクでは黒で再生される
  （モニターの再生は空きを飛ばす）。となりのクリップには重ねられない
- プログラムストリーム（`.mpg` / `.vob`）のクリップも、チャプターとトリムが GOP の頭に吸着する

音声と字幕の素材をタイムラインビューアに落とすと、A1 / S1 にはいる。

### 5.3 チャプターポイント

- 再生ヘッドの位置に **タイムライン ▸ チャプターポイントを追加**（テンキーの `*`）
- タイムラインビューアの目盛りの下の旗をドラッグしても動かせる
- **一定間隔でチャプターポイントを追加…**（既定 5 分）でまとめて打つ
- 旗を選んで **編集 ▸ 消去**（Delete）でそのチャプターを消す
- チャプターの名前はプロパティで付ける（空なら「チャプター N」と表示）。**表示 ▸ チャプター名を表示**（Ctrl+8）で
  タイムラインに名前を出す
- ポスターフレームはモニターの **ポスターフレーム** ボタンで、再生ヘッドの絵をセットする

DVD は 1 タイトル 99 チャプターまで。

### 5.4 トラック

**タイムライン ▸ オーディオトラックを追加… / 字幕トラックを追加…** は下から 1 本ずつ、
**オーディオトラックを削除 / 字幕トラックを削除** は一番下のトラックから。**ディスク** パネル（何も選んでいないときの
プロパティと同じ）で、既定で聞くオーディオトラックと表示する字幕を決める。モニターでは見出しのスピーカーボタンで
聞くトラックを選ぶ。

上限はオーディオ 8 本、字幕 32 本。

### 5.5 エンドアクション、上書き、リモートメニュー

プロパティのタイムラインのシートに、Encore と同じ 3 つのリンク欄がある。

| 欄 | 意味 |
|---|---|
| エンドアクション | 最後まで再生したあとに行く先（メニュー、別のタイムライン、スライドショー、再生リスト、何もしない） |
| 上書き | エンドアクションの先が終わったあとに行く先（警告 → 本編 → 特典メニューのような流れ） |
| リモートメニュー | リモコンのメニューボタンで出るメニュー（Blu-ray ではポップアップメニュー） |

リンクの入れ方は 3 とおりある。

- 欄の右の **▶** を押してから、プロジェクトパネルの項目をクリック（ピックウィップ）
- **オブジェクト ▸ リンクの指定…**（Ctrl+L）でダイアログから選ぶ
- フローチャートでノードからノードへドラッグする

## 6. スライドショーを作る

**ファイル ▸ 新規 ▸ スライドショー**（Ctrl+G）で空のスライドショーを作り、スライドショービューアに画像をドラッグする。
画像を複数選んで **ファイル ▸ 読み込み ▸ スライドショー…**（Shift+Ctrl+G）でも作れる（名前は最初の画像の名前、
スライドの長さは既定の 6 秒）。

| 設定 | 内容 |
|---|---|
| スライドのデュレーション | 既定 6 秒。タイムコードで入力する（NTSC の 00;00;06;00） |
| スケール | 全体表示 / はみ出し / 拡大縮小なし |
| トランジション | なし / クロスディゾルブ / 黒にディップ / ワイプ。長さは 0.1〜10 秒（既定 2 秒）。スライドごとに上書きできる |
| 手動で進める | オンにすると、リモコンで進むまで各スライドで止まる |
| 字幕を作成 | 各スライドの名前と説明を字幕にする（**次を含む** で次のスライドの名前も入れる）。スライドごとにハイライト（グループ）・ストローク・整列を選べ、色はスライドショーのカラーセットで決める |

スライドはドラッグで並べ替え、**編集 ▸ 消去**（Delete）で消す。オーディオを足すと長さを合わせられる。
スライドの名前と説明はプロパティで書く（字幕にするとディスクのチャプター名にもなる）。

## 7. 再生リストとチャプター再生リスト

### 7.1 再生リスト

**ファイル ▸ 新規 ▸ 再生リスト…** で名前を付けて作り、プロパティに項目（タイムライン、スライドショー）を
ドラッグして入れる。上へ / 下へ、削除、ダブルクリックで開ける。メニューのボタンから再生リストへリンクできる。

### 7.2 チャプター再生リスト

タイムラインを選んで **タイムライン ▸ 新規チャプター再生リスト**。選んだタイムラインのチャプターを、
再生する順のリストにする（おまけを好きな順で観られる）。

- **連続 / ランダム / シャッフル** を選べる（Blu-ray のランダム / シャッフルも対応）
- 項目のリンク先を変えたり、別のタイムラインのチャプターも入れられる
- チャプター再生リストビューアでプレビューできる

### 7.3 チャプターインデックス

**メニュー ▸ チャプターインデックスを作成** は、チャプターごとにボタンを並べたメニューを作る。

- ビューアに開いているメニューにチャプターボタンがあるときは、リンク済みのボタンに続けて残りのチャプターを割り当てる
  （この場合、少なくとも 1 つのチャプターボタンがタイムラインにリンクしていないと作れない）
- そうでないときは、選んでいるタイムラインのチャプターごとにボタンを並べたメニューを作る（DiscCraft 独自）
- **複数ページのチャプターインデックスを作成** は 1 ページ 6 ボタンで分割し、**前へ / 次へ** ボタンを付ける
- 1 ページに置けるチャプターボタンは最大 18 個

## 8. メニューを作る

### 8.1 作り方

| 方法 | 結果 |
|---|---|
| **ファイル ▸ 新規 ▸ メニュー**（Ctrl+M） | 空のメニュー。Encore と同じガイドが入る |
| **ファイル ▸ 読み込み ▸ メニュー…**（Shift+Ctrl+I） | PSD / `.pcraft` をメニューにする。`(+)` で始まるグループがボタンになる |
| **ライブラリ** のプリセットで **新規メニュー** | DiscCraft 独自のテンプレートから作る |
| **メニュー ▸ 新規ページを追加** | 開いているメニューの次のページ（背景と設定は同じ） |

最初に作ったメニューは、自動的に **ファーストプレイ** と **タイトルボタン** になる。

PSD のレイヤー名の決まり: `(+)` で始まるグループがボタン、`(=1)` / `(=2)` / `(=3)` が標準 / 選択時 /
アクティベート時のハイライトの絵、`(%)` がビデオサムネールのボタン、`(^)` が自動アクティベート。

### 8.2 ボタン

- **メニュー ▸ ボタンを追加**、または既存のテキスト / 画像 / シェイプを選んで **オブジェクト ▸ ボタンに変換**（Ctrl+B）
- ドラッグで移動、ハンドルで大きさ変更、Shift で複数選択
- **オブジェクト ▸ 整列 / 均等配置 / アレンジ**（前面へ Ctrl+]、最前面へ Shift+Ctrl+]、背面へ Ctrl+[、
  最背面へ Shift+Ctrl+[）。**セーフエリアに相対的に整列** をオンにすると、キャンバスではなくセーフエリアの枠を基準にする
- **切り取り / コピー / 貼り付け / 複製**（Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D）、**消去**（Delete）
- ボタンは 1 メニューに最大 36 個。**初期設定ボタン**（リモコンの矢印で最初にハイライトされるボタン）は
  プロパティか右クリックで決める
- ボタンを重ねて編集できるが、**ディスクに載せるときハイライトは重ならない**（重なると赤枠が出て、チェックに
  「ボタンが重なっています。」が出る）
- **オブジェクト ▸ オブジェクトに変換** でボタンをテキストに戻す

ボタンのプロパティ:

| 項目 | 内容 |
|---|---|
| リンク | 押したときに行く先 |
| 上書き | リンク先が終わったあとに行く先 |
| 種類 | 通常 / チャプター / 次へ / 前へ |
| 自動アクティベート | カーソルが乗ったボタンが Enter なしで決定される |
| オーディオ / 字幕 | そのボタンに切り替わる音声・字幕 |
| ルート | 矢印キーでどこへ動くか（自動 / 手動） |
| トランジション | モーションメニューでボタンに合わせるモーション |

**表示 ▸ ボタンルートを表示**（Ctrl+7）で十字のルート図が出る。ルートの既定（上下左右の動き、折り返し方、
「次へ」「前へ」ボタンを除外するか）とボタンの名前の同期は [環境設定 ▸ メニュー](#14-環境設定) で決める
（プロジェクトに保存される）。

### 8.3 文字と図形

- **横書き文字ツール**（T）または **縦書き文字ツール**（Y）でクリックして入力。フォント、フォントスタイル、大きさ、
  行送り、字送り、ベースライン、上付き / 下付き、色、アンチエイリアスを設定できる
- **ライブラリ** の **画像** と **シェイプ**（長方形 / 角丸長方形 / 楕円）を **配置** でメニューに置く。ドラッグでも
  置ける。**レイヤー** パネルで重なり順と目 / 鍵を扱う（背景は動かせない）
- **オブジェクト ▸ ドロップシャドウ…**（Shift+Ctrl+O）、**水平方向に反転 / 垂直方向に反転**（Alt+Ctrl+H /
  Alt+Ctrl+V）、**回転 ▸**（180°、90° 時計回り / 反時計回り）。自由な角度は回転ツール（R）
- **ガイド**: **表示 ▸ 新規ガイド…**（Shift+Alt+Ctrl+:）で位置を入力して打ち、**ガイドを表示**（Ctrl+:）、
  **ガイドにスナップ**（Shift+Ctrl+:）、**ガイドをロック**（Alt+Ctrl+:）、**ガイドを消去** で扱う

### 8.4 色とハイライト

**メニュー ▸ メニューカラーセットを編集…** で、標準 / 選択時 / アクティベート時の色を決める
（ハイライトの枠・文字・サブピクチャ）。**ハイライトグループ** を使うと複数のボタンがまとめて光る。
**表示 ▸ 標準サブピクチャを表示 / 選択時のサブピクチャを表示 / アクティベート時のサブピクチャを表示**
（Ctrl+3 / Ctrl+4 / Ctrl+5）で、キャンバスで見比べられる。

### 8.5 背景とモーションメニュー

プロパティのメニューのシート（**基本 / モーション / ポップアップ**）で決める。

- 背景は色 / 画像 / タイムライン（ビデオ）。ビデオにするとモーションメニューになる
- ループ回数とループポイント、デュレーション（メニューは最大 254 秒）
- **エンドアクション**（時間切れで進む先。メニュー ▸ エンドアクションを設定… でも開ける）と **上書き**
- **ポップアップ** のシートでポップアップメニューに設定し、背景のタイムライン / 背景フレームを決める（Blu-ray）

**メニュー ▸ EffectCraft コンポジションを作成…** でメニューのレイヤーから EffectCraft のプロジェクトを作り、
レンダーされたムービーをメニューの背景（モーションメニュー）にできる。

### 8.6 PSD で作り直す

- **編集 ▸ メニューを PhotoCraft で編集**（Shift+Ctrl+M）: メニューをレイヤー付き PSD にして PhotoCraft
  （なければ既定のアプリ）で開く。保存すると自動で読み直す。PSD は `<プロジェクト>.menus/` に置かれる。
  反映後もボタンのリンクはそのまま、増えたグループはボタンを足し、なくなったグループのボタンは消す
- **メニュー ▸ メニューをファイルとして保存…**: メニューを PSD で書き出す
- **メニュー ▸ メニューを置き換え…**: 開いているメニューを PSD のデザインに置き換え、リンクは番号で残す
- **メニュー ▸ メニューをテンプレートとして保存…**（Ctrl+Alt+M）: ライブラリの **ユーザー** セットに保存する

### 8.7 ユーザー操作

**メニュー ▸ メニューのユーザー操作を設定…** と **ファイル ▸ ディスクのユーザー操作を設定…** で、
再生中にリモコンでできる操作 / できない操作を決める（DVD は 25 種類のユーザー操作、Blu-ray は UO マスク）。

## 9. ナビゲーションを組み立てる

### 9.1 ファーストプレイとタイトルボタン

ディスクを入れると最初に動くのが **ファーストプレイ**、タイトルボタンを押したときに行く先が **タイトルボタン**。
最初のタイムラインまたはメニューを作ったときに自動で設定される。変えたいときは、プロジェクトパネルかフローチャートの
項目を右クリックして **ファーストプレイに設定**（タイトルボタンはプロパティで決める）。

### 9.2 フローチャート

**ウィンドウ ▸ フローチャート**（F5）。項目の箱とリンクの矢印が図になる。

- 箱はドラッグで動かせる。**自動レイアウト** / **すべて自動レイアウト** で整頓できる
- ボタンやエンドアクションから、メニュー・タイムライン・スライドショー・再生リストへドラッグするとリンクする
- 右クリックに 開く / リンクの指定 / 名前の変更 / ファーストプレイに設定 など
- 下に **リンクされていない項目** の行が出る（孤立の発見に使える）
- **表示 ▸ すべてのサムネールを表示** で箱に絵を出す

### 9.3 リンクの種類

| 場所 | 決まるもの |
|---|---|
| ボタン | リンク（押した先）、上書き（リンク先が終わった先）、ルート（矢印キーの動き） |
| タイムライン | エンドアクション、上書き、リモートメニュー |
| メニュー | エンドアクション（時間切れの先）、上書き、デュレーション |
| ディスク | 上書き（ディスクの既定の行き先） |

## 10. 字幕

### 10.1 読み込み

- **タイムライン ▸ 字幕を読み込み…**（SRT / WebVTT / タイムコード付きテキスト。UTF-8 / UTF-16 / Shift_JIS）
  を選ぶと、選んでいるタイムラインに字幕トラックが 1 本増える
- 字幕ファイルをアセットとして読み込んでから、タイムラインビューアに落としてクリップにする
- Encore が書き出した字幕のテキストスクリプト（UTF-16 LE）も読める。**タイムライン ▸ 字幕を書き出し ▸
  字幕トラック** で SRT / テキストスクリプトとして書き出せる
- **ファイル ▸ 新規 ▸ スライドショー** の **字幕を作成** で、スライドの名前と説明から字幕を作ることもできる

### 10.2 編集

タイムラインビューアの S1 トラックで、クリップの端をドラッグしてトリムし、ダブルクリックで文字を直せる
（Enter / Shift+Enter で改行、Esc で確定）。トリムは最短 0.4 秒（NTSC 13 フレーム、PAL 11 フレーム）。

モニターの字幕のボタンでも作れる（**前の字幕 / 次の字幕 / 字幕インポイントをここまでトリム /
字幕アウトポイントをここまでトリム / 字幕を追加**）。**字幕を追加** は再生ヘッドの位置に既定 2 秒のクリップを置く
（次の字幕まで 2 秒空いていないと置けない）。

### 10.3 見た目

字幕クリップを選ぶと、プロパティに **字幕クリップ** のシートが出る。

| 項目 | 内容 |
|---|---|
| テキスト / デュレーション / インポイント / アウトポイント | 文字と時刻 |
| ハイライト | グループ 1〜3（色の組）。**トラックの設定** にするとトラックのグループに従う |
| ストローク | なし / 細 / 中 / 太 / 極太 |
| 整列 | 上下の位置（100 % で下） |
| 揃え | 左 / 中央 / 右（初期値は中央。左と右はタイトルセーフの端に揃う） |

色はタイムライン（スライドの字幕はスライドショー）のプロパティの **カラーセット** で決める。

- グループ 1〜3 のそれぞれに、塗り・ストローク・アンチエイリアスのカラーと不透明度。初期設定の色は Encore と同じ
- **塗りおよびストロークからアンチエイリアスカラーを作成** を入れると、アンチエイリアス（文字の縁のなじませる色）は
  塗りとストロークの中間になる。外すと自分で決められる
- **名前** を入れて **新規** で、今の色をプロジェクトのカラーセットとして保存する。保存したセットは **カラーセット** の
  一覧から選べ、**削除** で消せる（タイムラインは色のコピーを持つので、後からセットを変えても変わらない）
- **書き出し… / 読み込み…** でカラーセットをファイル（`.dccolors`）にやり取りできる。**初期設定に戻す** で元の色に戻す

字幕の文字はタイトルセーフ（フレームの 80 %）の中に収める。**表示 ▸ セーフエリアを表示**（Ctrl+6）で範囲を確認できる。
収まらない字幕は [プロジェクトのチェック](#11-プロジェクトをチェックする) に出る。

## 11. プロジェクトをチェックする

**ファイル ▸ プロジェクトをチェック…**（Shift+Ctrl+L）、**ビルド** パネルの右の **プロジェクトをチェック** ボタン、
または F4。チェックウィンドウは **チェックする項目** に印を付けて **開始** を押すと走り、結果は **名前** と **問題** の
2 列に項目ごとにまとまって出る（1 項目に問題が複数あると「{n} 個のエラー」に折りたたまれる。文言は Encore と同じ）。

| 分類 | 見るもの |
|---|---|
| ボタンリンク | リンク先がない・リンクが設定されていないボタン、枠の外に出たボタン、存在しない初期設定ボタン |
| ファーストプレイ | ファーストプレイが設定されているか |
| 孤立 | どの項目からも辿れないタイムラインとメニュー |
| エンドアクション | エンドアクションが未設定の項目 |
| タイトルボタン | タイトルボタンがメニューになっているか |
| 再生リスト | 空の再生リストとスライドショー、エントリのないチャプター再生リスト、デュレーション不正なスライド |
| 上書き | 上書きの設定 |
| リモートメニュー | リモートメニューがメニューになっているか |
| 重なったボタン | ハイライトが重なるボタン、ボタンが多すぎるメニュー |
| メニューの合計サイズ | ボタンのないメニュー、デュレーション、4:3 と 16:9 の混在 |
| ディスク容量 | 容量を超えていないか、ビットレートが低すぎないか |
| チャプターおよびトリム | 99 チャプター超、最初のチャプターが先頭にない、順序が不正 |
| 高すぎるタイムラインビットレート | DVD で、そのまま使うビデオとオーディオトラックの合計が 9.8 Mbps を超えるタイムライン |
| 字幕テキストのオーバーフロー | 文字がタイトルセーフの枠に収まらない字幕（NTSC の標準の大きさで 11 行以上、または折り返せない長い行）。字幕トラックとイン / アウトの時刻が出る |
| 字幕の間隔 | Blu-ray（HD か PAL）で、同じトラックの前の字幕とのすき間が 5 フレーム未満の字幕。DVD では見ない |
| トラックとタイトルの数 | オーディオ 8 本、字幕 32 本、DVD のタイトル 99 本など |
| メディアファイル | オフライン・存在しない・扱えない形式の素材 |
| その他 | 上のどれにも入らないもの |

**ビルド** ボタンはビルドの前に必ずチェックを走らせ、問題があると **表示**（チェックウィンドウを開く）／
**無視して続行** ／ **取り消し** のダイアログが出る。

## 12. プレビューする

### 12.1 プロジェクトプレビュー（ビルドしないプレビュー）

**ファイル ▸ プレビュー**（Alt+Ctrl+Space）、ツールバーの再生ボタン。ビルドせずに、今のプロジェクトを
自前の VM で再生する窓が開く。

- 下のコントロールバーに 拡大率、オーディオトラックと字幕トラック、今の項目（名前、ボタン番号かチャプター番号、
  静止画 / モーション か再生時刻）、**タイトル** / **メニュー**（Blu-ray では **ポップアップメニュー**）、十字キーと決定、
  前のチャプター / 停止 / 一時停止 / 再生 / 次のチャプター、**エンドアクションを実行**、**チャプターへ移動**
- **ここで終了**（見ている項目を開いて終了）と **終了して戻る**（開く前に戻る）。窓を × で閉じるのも同じ
- タイトルは映像と音つきで再生し、終わるとエンドアクションへ進む。矢印キーと Enter でリモコン、Space で一時停止

### 12.2 モニター（ビルド結果の再生）

**ウィンドウ ▸ モニター**（F9）。モニターの **ビルド結果を開く** で、書き出したフォルダの `VIDEO_TS` / `BDMV` を
読んで再生できる。リモコンの十字キー、タイトル / メニュー、チャプター、オーディオ / 字幕が使える。
ビルドしていないときは、選んでいるタイムラインの映像と音をそのまま映す（Space で再生、音つき。字幕もカラーセットの色で出る）。
DTS のトラックは鳴らない。

## 13. ビルドする

**ウィンドウ ▸ ビルド**（F2）、または **ファイル ▸ ビルド ▸ フォルダー…** / **イメージ…**。

| 欄 | 内容 |
|---|---|
| 形式 / 出力 | DVD / Blu-ray、フォルダー（`VIDEO_TS` / `BDMV`）か ISO イメージ |
| ビルド | ビルドを開始する。押すと先にプロジェクトを保存し、チェックする |
| ソース | 現在のプロジェクト（ビルドパネルは今のプロジェクトだけ書き出す） |
| 保存先 | 空だと薄い文字で示す場所（プロジェクトの横の `<プロジェクト名>_DVD` / `_BD`、イメージは `<プロジェクト名>.iso`）。フォルダーは、既存のフォルダーを指定するとその中の `<ディスク名>` フォルダーに作る（すでに `VIDEO_TS` / `BDMV` がある場所ならそこを再ビルド）。イメージはフォルダーを指定できない |
| ディスク情報 | 使用量のバー（**容量を更新** で計算）、ディスクの名前（ISO のボリュームラベルにもなる）、サイズ |
| レイヤーブレーク | DVD-9 のときだけ。自動 / 手動。手動はタイムラインと位置（タイムコード / フレーム / 秒、**再生ヘッド**）で決める |
| リージョンコード | DVD のときだけ。すべてのリージョン / カスタム（1〜8 のチェック） |
| プロジェクトのチェック | チェック結果（チェックウィンドウと同じ行） |
| 結果 | エラー、タイトル数 / チャプター数 / サイズ、**シミュレート**（フォルダーにビルドした後で VM を走らせる） |

ビルド中は進み具合と経過時間がバーで出る（パネルがどこにあってもステータスバーにも出る）。

- 変換した素材は出力先の `disccraft-cache` に残る（2 回目から変換を飛ばす）。コマンドラインの `--cache` で
  別の場所に置いて共有できる
- ISO は UDF + ISO 9660。Windows ではエクスプローラーでダブルクリックするとマウントできる
- DVD-9 のイメージでレイヤーブレークを指定すると、同じ場所に `<名前>.layerbreak.txt` に記録が残る
- ディスクへの書き込みはしない。焼くときは別のソフトを使う

## 16. コマンドラインとスクリプト

GUI と同じ操作は `disccraft-cli` からでもできる（ビルド、プロジェクトの検査、スクリプトの実行）。

```
cargo run -p disccraft-cli -- commands [--json]
cargo run -p disccraft-cli -- exec <project.dcproj> <command> [params-json]
cargo run -p disccraft-cli -- run <project.dcproj> <script.jsonl>
cargo run -p disccraft-cli -- inspect <project.dcproj> [--json]
cargo run -p disccraft-cli -- build <project.dcproj> --out <dir>
cargo run -p disccraft-cli -- build <project.dcproj> --iso <file> [--cache <dir>] [--audio-language ja]
```

- `commands` はエンジンのコマンドの一覧（ID、表示名、メニューの場所、ショートカット、パラメータ）。`--json` で JSON
- `exec` はコマンド 1 つを実行して結果を JSON で出す。プロジェクトが未保存なら保存する
- `run` は JSON Lines のスクリプトを実行する。1 行が 1 コマンドで `{"command": "...", "params": {...}}`。
  `#` と `//` で始まる行は無視。スクリプトは 16 MB まで
- `inspect` はプロジェクトの要約（`--json` で `project.inspect` の JSON）
- `build` は `--out` でフォルダー、`--iso` でイメージを作る。`--cache` で変換した素材の置き場所を、
  `--audio-language` で言語の付いていない音声の言語（ISO 639-1）を指定する

## 17. AI エージェントから使う（MCP）

`disccraft-cli mcp` は MCP サーバー（標準入出力の JSON-RPC）として動く。ツールは 3 つ。

| ツール | 内容 |
|---|---|
| `disccraft_commands` | コマンドの一覧（ID、表示名、メニュー、ショートカット、パラメータ） |
| `disccraft_execute` | コマンド 1 つとパラメータを実行 |
| `disccraft_inspect` | 今のプロジェクトの検査とチェック結果 |

MCP クライアントには、コマンドに `<リポジトリのパス>/target/release/disccraft-cli`、引数に `mcp` を登録する
（標準入出力でつなぐ）。

## 18. 上限と決まり

| 項目 | 上限 |
|---|---|
| ボタン | 1 メニュー 36 個 |
| メニューのデュレーション | 254 秒 |
| タイムラインのビデオクリップ | 99 本 |
| チャプター | 1 タイトル 99 個（DVD） |
| DVD のタイトル | 99 本 |
| オーディオトラック | 8 本 |
| 字幕トラック | 32 本 |
| チャプターインデックス | 1 ページ 18 ボタン（複数ページは 1 ページ 6 ボタン） |
| スライドのデュレーション | 既定 6 秒。トランジション 0.1〜10 秒（既定 2 秒） |
| 字幕のトリム | 最短 0.4 秒（NTSC 13 / PAL 11 フレーム） |
| 字幕の文字 | タイトルセーフの枠に、NTSC の標準の大きさで 10 行まで |
| 字幕のすき間 | Blu-ray（HD / PAL）は 5 フレーム以上（DVD は制限なし） |
| DVD のビットレート | ビデオ・オーディオ・字幕を合わせて 9.8 Mbps |
| 容量 | DVD5 4.7 GB、DVD9 8.5 GB、BD25 / BD50 / BD100 / BD128 |
| ドロップ | 1 回 500 ファイル |
| 最近使用したプロジェクト | 10 件 |
| ワークスペース | 32 個（名前は 64 文字） |

ほかの決まり:

- ボタンのハイライトはディスクに載せると重ならない（編集画面では重ねられる）
- タイムラインはビデオを 1 本目に持つ
- 変換が要るビデオのクリップは、DVD ではトリムした位置で切れない（GOP の頭で切れる）
- 16:9 のメニューも SD では同じ 720×480 の枠を使い、横に引き伸ばして映す（HD の Blu-ray は 1920×1080 の枠）。
  DVD のメニューの縦横比はディスク全体で共通
- 音声は変換すると Dolby Digital（AC-3）192 kbps。AC-3 と WAV の素材はそのまま使える。DTS（`.dts`）は DVD だけ、そのまま使える
- DVD に合った MPEG-2 の映像（720 / 704 / 352 幅）は変換しない。1 本のタイトルのクリップは同じ幅にそろえる

## 19. うまく動かないとき

| 症状 | しかた |
|---|---|
| 素材が「オフライン」 | プロジェクトパネルの右クリック ▸ **アセットを置き換え…** で新しい場所を教える |
| ビルドが「問題があります」で止まる | **プロジェクトをチェック…** を開いて **名前** と **問題** を見る。直せないときはダイアログで **無視して続行** |
| メニューが再生されない | ファーストプレイとボタンのリンク、エンドアクションをフローチャートで確認する |
| ボタンが効かない | ハイライトが重なっていないか（赤枠）、**表示 ▸ ボタンルートを表示** で矢印の行き先を見る |
| 音が出ない | モニターの見出しのスピーカーボタンで聞くトラックを選ぶ。DTS のトラックはモニターとプレビューでは鳴らない（ディスクには入る）。Linux では ALSA の開発パッケージ（`libasound2-dev` など）が要る |
| EffectCraft のプロジェクトが思った絵にならない | アセットのプロパティの **コンポジション** で使うコンポジションを選ぶ |
| 文字化けする | **ウィンドウ ▸ 言語** で表示言語を切り替える。字幕は UTF-8 / UTF-16 / Shift_JIS を読む |
| 画面の並びがバラバラになった | **ウィンドウ ▸ ワークスペース ▸ 「名前」をリセット** |
| 書き出したディスクが再生できない | 書き出したフォルダーやイメージをソフトウェアのプレーヤー（VLC など）で開き、ffprobe でストリームが読めるかを見て、どこで止まるかを確かめる |
| パネルが見つからない | **ウィンドウ** メニューにすべてのパネルの名前がある（× で閉じてもここから開き直せる） |
