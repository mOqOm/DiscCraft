# 再生互換性チェックリスト

DiscCraft が書き出したディスクを、ソフトウェアプレーヤーと家庭用プレーヤーで確かめた記録。
自動で確かめられるものは `cargo test` に入れ、人の目が必要なものをここに残す。

## 確認用ディスクの作り方

```
cargo test -p disccraft-dvd            # ffmpeg があれば target/fixtures に素材を作る
cargo run -p disccraft-dvd --example fixture_dvd
# → target/fixtures/dvd_out/VIDEO_TS（20 秒、チャプター 0 / 5 / 10 秒、AC-3 ステレオ）
```

CLI からは `disccraft-cli build <project.dcproj> --out <dir>`（M2.5 以降）。

## メニュー付きディスクの作り方（M3）

README の「試し方」のとおり、`docs/examples/menu-demo.jsonl` から CLI でプロジェクトを作って書き出す。

## VLC で手動確認する手順

1. VLC の「メディア」→「ディスクを開く」→「DVD」→「ディスクメニューなし」のチェックを外したまま、
   `target/fixtures/dvd_out` フォルダを選ぶ。
2. 再生が始まり、約 20 秒のテストパターンと 1 kHz の音が出ること。
3. 「再生」→「チャプター」で 3 つあること、次 / 前のチャプターに移動できること。
4. 最後まで再生すると停止すること（M2 ではメニューがないため）。
