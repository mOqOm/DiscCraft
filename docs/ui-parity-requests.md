## 5. 具体的に知りたい挙動

> **2026-11-12 更新**: 2〜5 は Encore CS6 を直接操作して確かめ、反映した（[ui-parity.md](ui-parity.md) の
> フローチャート / タイムラインの右クリック / ビルドパネルの行）。2: リンクされていない項目はフローチャートの下の段に
> サムネールで並ぶ。3: チャプターポイントは再生ヘッドの位置に、目盛りの右クリック（チャプターポイントを追加 / 削除 /
> ポスターフレームを設定 / 一定間隔で… / チャプター名を表示 / ここからプレビューする）か `*` で打ち、マーカーはドラッグで動く。
> 4: `(+)` ボタン、`(=1)`〜`(=3)` ハイライト、`(%)` ビデオサムネール、`(^)` 自動アクティベート（PSD の規約）。
> 5: ビルドパネルは 形式 / 出力 → ソース → 保存先 → ディスク情報（使用量・名前・サイズ）→ リージョンコード の順。
> 残りは 1（ピックウィップの位置の手の記憶）と 6。

分かるものだけ「はい / いいえ / 説明」で。

1. ピックウィップ（渦巻きをドラッグしてリンク先を決める）は、プロパティパネルのどの項目にあったか。フローチャート上でも
   ドラッグでリンクできたか。
2. フローチャートで、どこからもリンクされていない項目はどう表示されたか（別の場所にまとまる / 薄く表示 / 表示しない）。
3. タイムラインでチャプターマーカーを打つ操作（キー / ボタン / 再生ヘッドの位置に打つ、など）と、マーカーのドラッグ。
4. メニューのボタンを PSD のレイヤーから作るとき、`(+)` と `(=1)`〜`(=3)` 以外に使っていた名前の決まり（例: `(%)` の
   ビデオサムネール）。
5. ビルドパネルで最初に見る項目（出力先の種類、容量、ディスクの名前、リージョン、コピー防止 など）。
6. モニターでプレビューしたとき、リモコンのどのボタンを主に使ったか。
