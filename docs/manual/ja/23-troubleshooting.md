# 23. うまく動かないとき

[目次](README.md) ・ 前の章: [22. 上限と決まり](22-limits.md#22-上限と決まり) ・ 次の章: [24. 用語集](24-glossary.md#24-用語集)

> **この章でできること**
>
> - うまく動かないときに、まず確かめることを知る
> - 問題を報告するときに添えるものを知る

困りごとの種類ごとにまとめた。見つからないときは [1.3 やりたいことから探す](01-about.md#13-やりたいことから探す) と
[用語集](24-glossary.md#24-用語集) も引いてみる。

## 23.1 画面と素材

| 困っていること | まずすること |
|---|---|
| パネルが見つからない | **ウィンドウ** メニューにすべてのパネルの名前がある（× で閉じてもここから開き直せる） |
| 画面の並びがバラバラになった | **ウィンドウ ▸ ワークスペース ▸ 「名前」をリセット** |
| 素材が「オフライン」 | 素材のファイルを動かしたか、名前を変えた。プロジェクトパネルの右クリック ▸ **アセットを置換…** で新しい場所を教える |
| 音が出ない | モニターの見出しのスピーカーボタンで聞くトラックを選ぶ。DTS のトラックはモニターとプレビューでは鳴らない（ディスクには入る）。Linux では ALSA の開発パッケージ（`libasound2-dev` など）が要る |
| 文字化けする | **編集 ▸ 環境設定…** の **インターフェイス** の **言語** で表示言語を切り替える。字幕は UTF-8 / UTF-16 / Shift_JIS を読む |
| EffectCraft のプロジェクトが思った絵にならない | アセットのプロパティの **コンポジション** で使うコンポジションを選ぶ |

## 23.2 メニューとディスクの動き

| 困っていること | まずすること |
|---|---|
| ディスクの動きを確かめたい | ビルドする前に **ファイル ▸ プレビュー**（Alt+Ctrl+Space）で試す（[13.1](13-preview.md#131-プロジェクトプレビュービルドしないプレビュー)） |
| メニューが出ない | ファーストプレイとボタンのリンク、終了時の動作をフローチャートで確かめる（[10.2](10-navigation.md#102-フローチャート)） |
| ボタンが効かない | ハイライトが重なっていないか（赤枠）、**表示 ▸ ボタンのルートを表示** で矢印の行き先を見る |
| 隠しボタンにたどり着けない | たどれるボタンからルートが伸びているか: [17.4 隠しボタンとイースターエッグ](17-advanced.md#174-隠しボタンとイースターエッグ) |

## 23.3 ビルドとディスク

| 困っていること | まずすること |
|---|---|
| ビルドが「問題があります」で止まる | **ファイル ▸ プロジェクトをチェック…** を開いて **名前** と **問題** を見る（[12 章](12-check.md#12-プロジェクトをチェックする)）。直せないときはダイアログで **無視して続行** |
| ディスクに入りきらない | ビルドパネルの使用量のバー（**使用状況を更新**）で中身の大きさを見る。手当ては、内容を減らす、ビットレートを下げる、大きいディスクにする、の 3 つ（[17.9](17-advanced.md#179-作業しながらディスクの大きさを読む)） |
| ビルドに時間がかかる | 合わない素材の変換に時間がかかる。**今すぐトランスコード** でビルドの前に済ませておける（[5.3](05-assets.md#53-素材について)）。同時に変換する数と、Windows のハードウェアエンコーダーは環境設定の [18.7](18-preferences.md#187-メモリー) |
| ディスクに書き込めない | レコーダーが出ないときは、書き込めるドライブがつながっているかを確かめ、**更新** で探し直す。2 層の DVD は空の DVD+R DL に書く。macOS と Linux ではまだ書き込めないので、ISO イメージを作ってほかのソフトで書く（[14.7](14-build.md#147-ディスクに書き込む)） |
| 書いたディスクがプレーヤーで再生できない | まずプロジェクトプレビューで動くかを確かめる。プレーヤーがそのディスクの種類（DVD-R、DVD+R、BD-R など）を読めるかを、プレーヤーの説明書で確かめる。ISO イメージをパソコンのプレーヤーで開いて試すと、ディスクのせいかイメージのせいかが分かる |

## 23.4 報告と新しい版

| 困っていること | まずすること |
|---|---|
| 問題を報告したい | **ヘルプ ▸ システム互換性レポート…** の **コピー** で環境を、**ヘルプ ▸ ログファイルを表示…** でこの起動からの操作の記録（ログ）を取り出し、**ヘルプ ▸ 問題を報告…** に添える。DiscCraft が異常終了したときも、ログフォルダーにその時のログが残る |
| プレーヤーでの再生の具合を詳しく調べたい | 書き出したフォルダーやイメージをパソコンのプレーヤー（VLC など）で開き、どこで止まるかを確かめる |
| 新しい版があるか知りたい | **ヘルプ ▸ 更新を確認…** でこの版を確かめ、GitHub のリリースを開く（DiscCraft は自分では通信しない） |
