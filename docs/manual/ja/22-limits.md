# 22. 上限と決まり

[目次](README.md) ・ 前の章: [21. AI エージェントから使う（MCP）](21-mcp.md#21-ai-エージェントから使うmcp) ・ 次の章: [23. うまく動かないとき](23-troubleshooting.md#23-うまく動かないとき)

> **この章でできること**
>
> - DVD と Blu-ray の上限（タイトルやボタンの数、大きさ）を知る

| 項目 | 上限 |
|---|---|
| ボタン | 1 メニュー 36 個 |
| 16:9 の DVD のメニューのボタン（4:3 のテレビのハイライトも入る） | 18 個 |
| メニューの継続時間 | 254 秒 |
| タイムラインのビデオクリップ | 99 本 |
| チャプター | 1 タイトル 99 個（DVD） |
| DVD のタイトル | 99 本 |
| オーディオトラック | 8 本 |
| 字幕トラック | 32 本 |
| チャプターインデックス | 1 ページ 18 ボタン（複数ページは 1 ページ 6 ボタン） |
| スライドの継続時間 | 既定 6 秒。トランジション 0.1〜10 秒（既定 2 秒） |
| 字幕のトリム | 最短 0.4 秒（NTSC 13 / PAL 11 フレーム） |
| 字幕の文字 | タイトルセーフの枠に、NTSC の標準の大きさで 10 行まで |
| 字幕のすき間 | Blu-ray（HD / PAL）は 5 フレーム以上（DVD は制限なし） |
| DVD のビットレート | ビデオ・オーディオ・字幕を合わせて 9.8 Mbps |
| 容量 | DVD5 4.7 GB、DVD9 8.5 GB、BD25 / BD50 / BD100 / BD128、カスタムのサイズ |
| ドロップ | 1 回 500 ファイル |
| 最近使ったプロジェクト | 10 件 |
| ワークスペース | 32 個（名前は 64 文字） |

ほかの決まり:

- ボタンのハイライトはディスクに載せると重ならない（編集画面では重ねられる）
- タイムラインはビデオを 1 本目に持つ
- そのままディスクに入る MPEG-2 は GOP の頭で切れる（トリムとチャプターはいちばん近い GOP の頭へ）。変換する映像は
  フレームの位置で切れる
- 16:9 のメニューも SD では同じ 720×480 の枠を使い、横に引き伸ばして映す（HD の Blu-ray は 1920×1080 の枠）。
  DVD のメニューの縦横比はディスク全体で共通
- 音声は変換すると Dolby Digital（AC-3）192 kbps。AC-3 と WAV の素材はそのまま使える。DTS（`.dts`）もそのまま使える
- DVD に合った MPEG-2 の映像（720 / 704 / 352 幅）は変換しない。1 本のタイトルのクリップは同じ幅にそろえる
- MPEG-1 の映像（VCD の `.mpg`、`.m1v`）は、352x240（NTSC）か 352x288（PAL）で、ストリームの示すビットレートが 1.856 Mbps
  までなら、DVD にそのまま 4:3 で入れる。可変ビットレートと示すものはファイル全体を測り、どの 1 秒も 1.856 Mbps を
  超えなければそのまま、超えれば変換する。MPEG オーディオは Dolby Digital に変換する。
  MPEG-1 と MPEG-2 のクリップは 1 本のタイトルにつながない。Blu-ray では MPEG-1 は変換する
