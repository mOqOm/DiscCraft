# 19. キーボードショートカット

[目次](README.md) ・ 前の章: [18. 環境設定](18-preferences.md#18-環境設定) ・ 次の章: [20. コマンドラインとスクリプト](20-command-line.md#20-コマンドラインとスクリプト)

> **この章でできること**
>
> - キーボードショートカットを引く

`Ctrl` は macOS では `Cmd`。テキスト入力中に効かないもの（Ctrl+Z など）がある。

## 19.1 ファイルとプロジェクト

| キー | 操作 |
|---|---|
| Ctrl+N / Ctrl+O / Ctrl+S / Shift+Ctrl+S | 新規プロジェクト / 開く / 保存 / 別名で保存 |
| Shift+Ctrl+W | プロジェクトを閉じる |
| Ctrl+I | 読み込み ▸ アセット… |
| Shift+Ctrl+I / Shift+Ctrl+K / Shift+Ctrl+U | 読み込み ▸ メニュー… / ポップアップメニュー… / メニューページ… |
| Shift+Ctrl+T / Shift+Ctrl+G | 読み込み ▸ タイムライン… / スライドショー… |
| Shift+Ctrl+L | プロジェクトをチェック… |
| Alt+Ctrl+Space | プレビュー |
| Ctrl+Q | 終了 |

## 19.2 作成と編集

| キー | 操作 |
|---|---|
| Ctrl+M / Ctrl+T / Ctrl+G | 新規メニュー / 新規タイムライン / 新規スライドショー |
| Ctrl+Z / Shift+Ctrl+Z | 取り消し / やり直し |
| Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D | 切り取り / コピー / 貼り付け / 複製 |
| Delete | 消去 |
| Ctrl+A / Shift+Ctrl+A | すべて選択 / すべて選択解除 |
| Alt+Ctrl+R | 名前を変更… |
| Ctrl+E | オリジナルを編集 |
| Ctrl+W | 閉じる（選んでいるメニュー / タイムライン / スライドショー / チャプタープレイリストをビューアーから閉じる。そのビューアーで前に開いたものがあれば、それが出る。項目は残る） |
| Shift+Delete | リップル削除（タイムラインビューアーの再生ヘッドの下のビデオクリップを消して、後ろを詰める） |
| Alt+Shift+Ctrl+R / Alt+Shift+Ctrl+H | アセットを置換… / アセットの場所を指定…（プロジェクトパネルで選んだアセット） |
| Shift+テンキーの * | ポスターフレームを設定（再生ヘッドのあるチャプター。テンキーの * だけ、またはメインキーの * はチャプターポイントを追加） |
| Alt+Ctrl+T | トラックを見える位置に移動（聞いているオーディオトラックまでタイムラインをスクロール） |
| Shift+Ctrl+F | フレームをファイルとして保存…（タイムラインビューアーの再生ヘッドのフレームを、正方形ピクセルの PNG で） |
| Shift+Ctrl+M | PhotoCraft でメニューを編集 |
| Ctrl+K | 環境設定… |

## 19.3 オブジェクト

| キー | 操作 |
|---|---|
| Ctrl+B | ボタンに変換 |
| Ctrl+L | リンクを指定… |
| Shift+Ctrl+O | ドロップシャドウ… |
| Alt+Ctrl+H / Alt+Ctrl+V | 左右反転 / 上下反転 |
| Ctrl+] / Shift+Ctrl+] | 前面へ / 最前面へ |
| Ctrl+[ / Shift+Ctrl+[ | 背面へ / 最背面へ |
| Ctrl+Alt+M | メニューをテンプレートとして保存… |
| V / A / M / R / T / Y / Z | 選択 / ダイレクト選択 / 移動 / 回転 / テキスト / 縦書き文字 / ズームツール |

## 19.4 表示と再生

| キー | 操作 |
|---|---|
| Space | 再生 / 停止 |
| L / J / K | 速く再生（止まっているときは等速で）/ 遅く再生（止まっているときは 0.5× で）/ 停止 |
| + / - / \\ | ズームイン / ズームアウト / ウィンドウに合わせる |
| ← / → | 1 フレーム戻る / 進む |
| Home / End | タイムラインの頭 / 終わりへ |
| `*`（テンキー） | チャプターポイントを追加 |
| Ctrl+3 / Ctrl+4 / Ctrl+5 | 標準 / 選択時 / 決定時のサブピクチャを表示 |
| Ctrl+6 / Ctrl+7 / Ctrl+8 | セーフエリア / ボタンルート / チャプター名を表示 |
| Ctrl+: / Shift+Ctrl+: / Alt+Ctrl+: | ガイドを表示 / ガイドにスナップ / ガイドをロック |
| Shift+Alt+Ctrl+: | 新規ガイド… |

## 19.5 ウィンドウ

| キー | 操作 |
|---|---|
| F1 | DiscCraft ヘルプ…（このマニュアル） |
| F2 / F3 / F4 / F5 | ビルド / 文字 / チェック / フローチャート |
| F6 / F7 / F8 / F9 / F10 | レイヤー / ライブラリ / メニュー / モニター / 進行状況 |
| F11 / F12 / Ctrl+F2 / Ctrl+F3 | プロジェクト / プロパティ / スタイル / タイムライン |
| Ctrl+F4 | ツール: メニューバーの下のツールバーを出す / 隠す（次の起動にも残る） |
