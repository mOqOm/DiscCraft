## 24.2 英字・数字

### 1080i / 1080p / 720p

HD の映像の形式。数字は縦の画素の数（1920 × 1080、1280 × 720）、i はインターレース、p はプログレッシブを表す。Blu-ray に
はそのまま入り、DVD に入れるときは SD に変換される。

→ [16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る) ・ 関連: [インターレース](#インターレース)、[プログレッシブ](#プログレッシブ)、[SD / HD](#sd--hd)

### 16:9 / 4:3

*Aspect ratio*

画面の横と縦の比（縦横比）。16:9 はワイド、4:3 は昔ながらのテレビの形。DVD はどちらにもでき、新規プロジェクトの **詳細
設定** か、あとからディスクパネルで決める。

→ [2.2 新規プロジェクト](02-getting-started.md#22-新規プロジェクト) ・ 関連: [テレビモード](#テレビモード)

### AC-3（Dolby Digital）

*Dolby Digital*

DVD と Blu-ray の標準の、圧縮した音声。ディスクに合わない音声は、ビルドのときに AC-3 の 192 kbps ステレオに変換される。AC-3 の
ファイルは変換せずにそのまま入る。

→ [5.3 素材について](05-assets.md#53-素材について)、[22. 上限と決まり](22-limits.md#22-上限と決まり) ・ 関連: [LPCM](#lpcm)、[DTS](#dts)、[トランスコード](#トランスコード)

### BD-25 / BD-50

1 層（25 GB）と 2 層（50 GB）の Blu-ray のディスク。新規プロジェクトの **詳細設定** か、ビルドパネルの **サイズ** で選
び、使用量のバーはこの容量に対して出る。

→ [2.2 新規プロジェクト](02-getting-started.md#22-新規プロジェクト)、[22. 上限と決まり](22-limits.md#22-上限と決まり) ・ 関連: [DVD-5 / DVD-9](#dvd-5--dvd-9)

### BDMV

Blu-ray のディスクの中身のフォルダー。ビルドでフォルダーを出力先にすると作られる。

→ [14.2 保存先](14-build.md#142-保存先)、[16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る) ・ 関連: [VIDEO_TS](#video_ts)、[ISO イメージ](#iso-イメージ)

### DDP イメージ

プレス工場にマスターのディスクの代わりに渡す、ディスクの中身と説明のファイルの組（Disc Description Protocol）。DVD のと
きだけ作れる。

→ [14.2 保存先](14-build.md#142-保存先) ・ 関連: [ISO イメージ](#iso-イメージ)、[レイヤーブレーク](#レイヤーブレーク)

### DTS

映画などで使われる、圧縮した音声の形式。DTS のファイル（`.dts`）は、変換せずに DVD と Blu-ray のオーディオトラックにそ
のまま入る（48 kHz、1509.75 kbps まで）。DiscCraft で DTS に変換することはできない。

→ [5.2 読めるファイル](05-assets.md#52-読めるファイル) ・ 関連: [AC-3（Dolby Digital）](#ac-3dolby-digital)、[オーディオトラック](#オーディオトラック)

### DVD+R DL

書き込み用の 2 層の DVD。DVD-9 のイメージを書く。

→ [14.7 ディスクに書き込む](14-build.md#147-ディスクに書き込む) ・ 関連: [DVD-5 / DVD-9](#dvd-5--dvd-9)

### DVD-5 / DVD-9

1 層（4.7 GB）と 2 層（8.5 GB）の DVD。DVD-9 では、1 層目から 2 層目に移る位置（レイヤーブレーク）を DiscCraft が決める。
手で決めることもできる。

→ [14.3 ディスク情報](14-build.md#143-ディスク情報) ・ 関連: [レイヤーブレーク](#レイヤーブレーク)、[DVD+R DL](#dvdr-dl)、[BD-25 / BD-50](#bd-25--bd-50)

### GOP

*Group of Pictures*

圧縮した映像で、まとめて符号化された何枚かの絵の組。そのままディスクに入る MPEG-2 では、チャプターポイントやトリムの切
れ目は GOP の頭にしか置けないので、DiscCraft が近くの GOP の頭へ寄せる。

→ [6.2 複数のビデオクリップ](06-timelines.md#62-複数のビデオクリップ) ・ 関連: [MPEG-2](#mpeg-2)、[チャプター](#チャプター)

### H.264

映像の圧縮方式（AVC）。Blu-ray の HD の映像に使う。同じ画質なら MPEG-2 より小さくなる。Windows では、グラフィックスカー
ドのエンコーダーで変換することもできる。

→ [16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る)、[18.7 メモリ](18-preferences.md#187-メモリ) ・ 関連: [MPEG-2](#mpeg-2)、[SD / HD](#sd--hd)

### HDMV / BD-J

Blu-ray のメニューの 2 つの方式。HDMV はボタンとナビゲーションのコマンドで作るメニュー、BD-J は Java のプログラムで作る
メニュー。DiscCraft の Blu-ray は HDMV で、メニューの作り方は DVD と同じ。

→ [16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る) ・ 関連: [ポップアップメニュー](#ポップアップメニュー)

### ISO イメージ

ディスクの中身をそのまま 1 つのファイル（`.iso`）にしたもの。ディスクに書き込んだり、マウントしてプレーヤーで確かめたり
できる。

→ [14.2 保存先](14-build.md#142-保存先)、[14.7 ディスクに書き込む](14-build.md#147-ディスクに書き込む) ・ 関連: [VIDEO_TS](#video_ts)、[BDMV](#bdmv)、[DDP イメージ](#ddp-イメージ)

### LPCM

圧縮しない音声（リニア PCM）。WAV の音はそのまま LPCM としてディスクに入る。音はよいが、AC-3 よりずっと大きい。

→ [5.2 読めるファイル](05-assets.md#52-読めるファイル) ・ 関連: [AC-3（Dolby Digital）](#ac-3dolby-digital)

### MCP

*Model Context Protocol*

AI エージェントから DiscCraft を操作するための仕組み。`disccraft-cli mcp` が MCP サーバーとして動き、エージェントがコマ
ンドを実行したり、プロジェクトをチェックしたりできる。

→ [21. AI エージェントから使う（MCP）](21-mcp.md#21-ai-エージェントから使うmcp) ・ 関連: [プロジェクト](#プロジェクト)

### MPEG-2

映像の圧縮方式。DVD の映像はすべて MPEG-2 で、Blu-ray の SD の映像にも使える。規格に合う MPEG-2 のファイルは、変換せず
にそのまま入る。

→ [5.3 素材について](05-assets.md#53-素材について) ・ 関連: [GOP](#gop)、[H.264](#h264)、[トランスコード](#トランスコード)

### NTSC / PAL

*TV standard*

テレビ方式。日本と北米は NTSC（720 × 480、1 秒 29.97 フレーム）、ヨーロッパなどは PAL（720 × 576、25 フレーム）。新規プ
ロジェクトで選び、DVD の映像の大きさとフレームレートが決まる。

→ [2.2 新規プロジェクト](02-getting-started.md#22-新規プロジェクト)、[18.1 一般](18-preferences.md#181-一般) ・ 関連: [フレームレート](#フレームレート)

### PSD

Photoshop 形式の画像。レイヤーの名前の決まり（`(+)` で始まるグループがボタンなど）に沿ったものは、そのままメニューにで
きる。

→ [9.6 PSD で作り直す](09-menus.md#96-psd-で作り直す) ・ 関連: [レイヤーセット](#レイヤーセット)、[メニュー](#メニュー)

### ROM コンテンツ

*DVD-ROM / BD-ROM Content*

ディスクに一緒に入れる、パソコンで読むためのファイル（説明書の PDF、写真など）。ビルドパネルの **DVD-ROM コンテンツ** / **BD-ROM コ
ンテンツ** でフォルダーを選ぶ。

→ [14.3 ディスク情報](14-build.md#143-ディスク情報)

### SD / HD

標準の画質（DVD の 720 × 480 など）と、高い画質（1920 × 1080、1280 × 720）。DVD は SD だけ、Blu-ray は SD と HD のどち
らにもできる。

→ [16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る) ・ 関連: [1080i / 1080p / 720p](#1080i--1080p--720p)

### VBR / CBR

ビットレートの決め方。VBR（可変）は場面の難しさに合わせてデータの量を上下させ、CBR（固定）はいつも同じ量にする。VBR の 2 パ
スは、まず映像全体を一度調べてから変換するので、時間は 2 倍かかるが、難しい場面にデータを多く回せる。

→ [5.3 素材について](05-assets.md#53-素材について) ・ 関連: [ビットレート](#ビットレート)、[トランスコード](#トランスコード)

### VIDEO_TS

DVD のディスクの中身のフォルダー。ビルドでフォルダーを出力先にすると作られる。

→ [14.2 保存先](14-build.md#142-保存先) ・ 関連: [BDMV](#bdmv)、[ISO イメージ](#iso-イメージ)

### VM

*Virtual Machine*

プレーヤーの中で、ディスクのナビゲーション（ボタンやエンドアクションのコマンド）を動かす仕組み。プロジェクトプレビュー
は、ディスクと同じ動きを DiscCraft の VM で再現する。

→ [13.1 プロジェクトプレビュー（ビルドしないプレビュー）](13-preview.md#131-プロジェクトプレビュービルドしないプレビュー) ・ 関連: [ナビゲーション](#ナビゲーション)、[プロジェクトプレビュー](#プロジェクトプレビュー)

## 24.3 あ行

### アクティベート

*Activated*

メニューのボタンを決定する（リモコンの決定ボタンを押す）こと。押したときのボタンの色を「アクティベート時の色」といい、
カーソルが乗っているときの「選択時の色」と別に決められる。

→ [9.4 色とハイライト](09-menus.md#94-色とハイライト) ・ 関連: [ハイライト](#ハイライト)、[サブピクチャ](#サブピクチャ)

### アセット

*Asset*

読み込んだ素材のファイル（動画、音声、画像、字幕）。プロジェクトパネルに並び、タイムラインやメニュー、スライドショーに
使う。ファイルはコピーされず、元の場所のまま使われる。

→ [5. 素材を読み込む](05-assets.md#5-素材を読み込む) ・ 関連: [オフライン](#オフライン)、[トランスコード](#トランスコード)

### インターレース

*Interlaced*

1 枚の絵を 2 つのフィールド（奇数の行と偶数の行）に分けて、交互に送る映像。テレビやビデオカメラの映像に多い。DVD と同じ
フレームレートのものは、2 つのフィールドを分けたままディスクに入る。

→ [5.1 読み込み方](05-assets.md#51-読み込み方) ・ 関連: [プログレッシブ](#プログレッシブ)、[1080i / 1080p / 720p](#1080i--1080p--720p)

### 上書き

*Override*

エンドアクションで行った先が終わったあとに行く先。行った先のもともとのエンドアクションの代わりに使われ、「警告 → 本編 → 特
典メニュー」のような流れを作れる。

→ [6.5 エンドアクション、上書き、リモートメニュー](06-timelines.md#65-エンドアクション上書きリモートメニュー) ・ 関連: [エンドアクション](#エンドアクション)、[リンク](#リンク)

### エンドアクション

*End Action*

タイムライン、スライドショー、再生リストなどを最後まで再生したあとに行く先。たとえば本編が終わったらメインメニューに戻
す。プロパティの **エンドアクション** で決める。

→ [6.5 エンドアクション、上書き、リモートメニュー](06-timelines.md#65-エンドアクション上書きリモートメニュー) ・ 関連: [上書き](#上書き)、[リモートメニュー](#リモートメニュー)、[リンク](#リンク)

### オーサリング

*Authoring*

映像、メニュー、ナビゲーションを組み立てて、ディスクにする作業。DiscCraft はそのためのアプリケーション。

→ [1. DiscCraft について](01-about.md#1-disccraft-について)

### オーサリングモード

*Authoring mode*

作るディスクの種類（DVD か Blu-ray か）。新規プロジェクトで選び、あとからディスクパネルで切り替えられるので、同じプロジ
ェクトを両方でビルドできる。

→ [2.2 新規プロジェクト](02-getting-started.md#22-新規プロジェクト)、[16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る)

### オーディオトラック

*Audio Track*

タイムラインの音声の段。1 つのタイトルに、言語違いや解説などの音声を何本も入れられ、観る人がリモコンで切り替える。

→ [6.4 トラック](06-timelines.md#64-トラック) ・ 関連: [字幕トラック](#字幕トラック)、[タイムライン](#タイムライン)

### オフライン

*Offline*

素材のファイルが元の場所に見つからない状態。ファイルを動かしたり名前を変えたりするとなる。プロジェクトパネルの右クリッ
ク ▸ **アセットを置き換え…** で新しい場所を教える。

→ [2.3 保存](02-getting-started.md#23-保存)、[23. うまく動かないとき](23-troubleshooting.md#23-うまく動かないとき) ・ 関連: [アセット](#アセット)

## 24.4 か行

### カラーセット

*Color Set*

メニューのボタンのハイライトや字幕に使う色の組。DVD のハイライトは色数が限られるので、使う色を組にして決めておく。**自
動** では、ボタンのレイヤーから色を取る。

→ [9.4 色とハイライト](09-menus.md#94-色とハイライト)、[11.3 見た目](11-subtitles.md#113-見た目) ・ 関連: [ハイライト](#ハイライト)、[サブピクチャ](#サブピクチャ)

### キャッシュ

作業を速くするために残しておくデータ。メディアキャッシュには素材の長さ・サムネール・索引などを覚え、ビルドのキャッシュ
には変換した映像や音を残して、次のビルドで変換を飛ばす。

→ [18.5 メディア](18-preferences.md#185-メディア) ・ 関連: [トランスコード](#トランスコード)

### クリップ

*Clips*

タイムラインに並べた、動画・音声・字幕のひとかたまり。始めと終わりを詰める（トリムする）こともできる。

→ [6.2 複数のビデオクリップ](06-timelines.md#62-複数のビデオクリップ) ・ 関連: [タイムライン](#タイムライン)

### コピーガード

市販のディスクの複製を防ぐ仕組み（DVD の CSS、Blu-ray の AACS）。DiscCraft は入れない。DVD のリージョンコードのフラグだ
けは設定できる。

→ [17.10 まだないもの](17-advanced.md#1710-まだないもの) ・ 関連: [リージョンコード](#リージョンコード)

## 24.5 さ行

### 再生ヘッド

*Playhead*

タイムラインやモニターで、今の位置を示す縦の線。チャプターポイントやポスターフレームは、再生ヘッドの位置に置ける。

→ [6.3 チャプターポイント](06-timelines.md#63-チャプターポイント) ・ 関連: [チャプター](#チャプター)、[ポスターフレーム](#ポスターフレーム)

### 再生リスト

*Playlist*

いくつかのタイムラインやスライドショーを、決めた順に続けて再生する項目。本編と特典をまとめて再生するボタンなどに使う。

→ [8.1 再生リスト](08-playlists.md#81-再生リスト) ・ 関連: [チャプター再生リスト](#チャプター再生リスト)

### サブピクチャ

*Subpicture*

DVD で映像に重ねる、色数の少ない絵。メニューのボタンのハイライトと字幕に使う。標準・選択時・アクティベート時の 3 つの状
態の色を、カラーセットから選ぶ。

→ [9.4 色とハイライト](09-menus.md#94-色とハイライト) ・ 関連: [ハイライト](#ハイライト)、[カラーセット](#カラーセット)、[アクティベート](#アクティベート)

### 視聴制限

*Parental level*

年齢などに合わせて、ディスクを再生させない設定（パレンタルロック）。DVD のビルドパネルで視聴制限レベル（なし、または 1〜8。8 が
もっとも厳しい）を決める。プレーヤーのレベルより高いディスクは再生されない。

→ [14.4 リージョンと視聴制限](14-build.md#144-リージョンと視聴制限)、[18.4 プレビュー](18-preferences.md#184-プレビュー) ・ 関連: [リージョンコード](#リージョンコード)

### 字幕トラック

*Subtitle Track*

タイムラインの字幕の段。1 本が 1 つの言語の字幕になり、観る人がリモコンで切り替えたり消したりできる。字幕のファイルを読
み込むか、モニターで打ち込んで作る。

→ [11. 字幕](11-subtitles.md#11-字幕) ・ 関連: [オーディオトラック](#オーディオトラック)、[カラーセット](#カラーセット)

### スライドショー

*Slideshow*

静止画を順に見せるタイトル。スライドごとに長さ（初期値 6 秒）とトランジションを決め、音楽を付けられる。

→ [7. スライドショーを作る](07-slideshows.md#7-スライドショーを作る) ・ 関連: [トランジション](#トランジション)、[デュレーション](#デュレーション)

### セーフエリア

テレビの縁で切れずに見える範囲の目安。メニューの文字やボタン、字幕はこの中に置く（字幕の文字はフレームの 80 % のタイト
ルセーフの中）。**表示 ▸ セーフエリアを表示**（Ctrl+6）で枠が出る。

→ [4.3 パネル](04-screen.md#43-パネル)、[11.3 見た目](11-subtitles.md#113-見た目) ・ 関連: [メニュービューア](#メニュービューア)

## 24.6 た行

### タイトル

*Title*

ディスクに入る 1 本の映像。DiscCraft では、タイムライン、スライドショー、チャプター再生リストがそれぞれ 1 つのタイトル
になる。

→ [6. タイムラインを作る](06-timelines.md#6-タイムラインを作る) ・ 関連: [タイムライン](#タイムライン)、[スライドショー](#スライドショー)、[チャプター再生リスト](#チャプター再生リスト)

### タイトルボタン

*Title Button*

リモコンのタイトルボタン（トップメニューボタン）を押したときの行き先。ディスクのプロパティで決め、ふつうはメインメニュ
ーにする。

→ [10.1 ファーストプレイとタイトルボタン](10-navigation.md#101-ファーストプレイとタイトルボタン) ・ 関連: [ファーストプレイ](#ファーストプレイ)、[リモートメニュー](#リモートメニュー)

### タイムライン

*Timeline*

動画・音声・字幕を時間に沿って並べたもの。ディスクの 1 つのタイトルになり、チャプターポイントで区切る。

→ [6. タイムラインを作る](06-timelines.md#6-タイムラインを作る) ・ 関連: [タイムラインビューア](#タイムラインビューア)、[クリップ](#クリップ)、[チャプター](#チャプター)

### タイムラインビューア

*Timeline Viewer*

タイムラインを編集するパネル。ビデオ・オーディオ・字幕のトラックが段になって並び、クリップやチャプターポイントを置く。

→ [4.3 パネル](04-screen.md#43-パネル)、[6. タイムラインを作る](06-timelines.md#6-タイムラインを作る) ・ 関連: [タイムライン](#タイムライン)

### 多重化

*Multiplexing*

映像・音声・字幕を、ディスクのひとつながりのデータにまとめること。ビルドの一部で、ディスクの使用量には多重化で増える分
（2 % ほど）も入る。

→ [14.3 ディスク情報](14-build.md#143-ディスク情報) ・ 関連: [ビルド](#ビルド)

### チャプター

*Chapter*

タイトルの中の区切り。リモコンの「次」「前」でここへ飛び、メニューのボタンから直接再生できる。タイムラインにチャプター
ポイントを置いて作る。

→ [6.3 チャプターポイント](06-timelines.md#63-チャプターポイント) ・ 関連: [チャプターインデックス](#チャプターインデックス)、[GOP](#gop)、[再生ヘッド](#再生ヘッド)

### チャプターインデックス

メニューの、チャプターごとのボタンの並び（シーン選択）。**メニュー ▸ チャプターインデックスを作成** で、ボタンとリンク
ごと作れる。ボタンが多いときはページに分かれる。

→ [8.3 チャプターインデックス](08-playlists.md#83-チャプターインデックス)、[17.1 絵入りのシーン選択メニュー](17-advanced.md#171-絵入りのシーン選択メニュー) ・ 関連: [チャプター](#チャプター)、[メニュー](#メニュー)

### チャプター再生リスト

*Chapter Playlist*

1 つのタイムラインのチャプターを、好きな順に選んで再生する項目。ダイジェスト版などを、映像を複製せずに作れる。

→ [8.2 チャプター再生リスト](08-playlists.md#82-チャプター再生リスト) ・ 関連: [再生リスト](#再生リスト)、[チャプター](#チャプター)

### テレビモード

ワイドの映像を、プレーヤーにつないだテレビの形に合わせる映し方。16:9 ワイドスクリーン、4:3 レターボックス（上下に帯）、4:3 パ
ン&スキャン（左右が切れる）がある。プレビューで試すときは環境設定で選ぶ。

→ [18.4 プレビュー](18-preferences.md#184-プレビュー) ・ 関連: [16:9 / 4:3](#169--43)

### デュレーション

長さ。新しいスライドの長さ（初期値 6 秒）と、モニターで足す字幕の長さ（初期値 2 秒）を環境設定で決める。

→ [7. スライドショーを作る](07-slideshows.md#7-スライドショーを作る)、[18.3 タイムライン](18-preferences.md#183-タイムライン) ・ 関連: [スライドショー](#スライドショー)

### トランジション

*Transition*

スライドの切り替えの効果（クロスディゾルブなど）。

→ [7. スライドショーを作る](07-slideshows.md#7-スライドショーを作る) ・ 関連: [スライドショー](#スライドショー)

### トランスコード

*Transcode*

規格に合わない素材を、ディスクに入る形（DVD では MPEG-2 と AC-3 など）に変換すること。ビルドのときに自動で行い、**今す
ぐトランスコード** で先に済ませることもできる。変換したものはキャッシュに残る。

→ [5.3 素材について](05-assets.md#53-素材について) ・ 関連: [ビットレート](#ビットレート)、[VBR / CBR](#vbr--cbr)、[キャッシュ](#キャッシュ)

## 24.7 な行・は行

### ナビゲーション

*Navigation*

ボタン、エンドアクション、リモコンのボタンでつながる、ディスクの中の行き来。フローチャートで全体を見て、プロジェクトプ
レビューで試す。

→ [10. ナビゲーションを組み立てる](10-navigation.md#10-ナビゲーションを組み立てる) ・ 関連: [リンク](#リンク)、[フローチャート](#フローチャート)、[VM](#vm)

### ハイライト

*Highlight*

メニューで、選んでいるボタンを示す色や形。DVD ではサブピクチャで描き、選択時とアクティベート時で色を変えられる。

→ [9.4 色とハイライト](09-menus.md#94-色とハイライト) ・ 関連: [サブピクチャ](#サブピクチャ)、[カラーセット](#カラーセット)、[ルート](#ルート)

### ビットレート

*Bitrate*

1 秒あたりのデータの量（Mbps）。高いほど画質がよく、ディスクの容量を多く使う。DVD の映像は最大 9.8 Mbps で、初期設定で
はディスクの容量に合わせて自動で決まる。

→ [5.3 素材について](05-assets.md#53-素材について) ・ 関連: [VBR / CBR](#vbr--cbr)、[トランスコード](#トランスコード)

### ビルド

*Build*

プロジェクトから、ディスクの中身（`VIDEO_TS` / `BDMV` のフォルダー、ISO イメージ、DDP イメージ）を作ること。素材の変換、
メニューの描画、多重化をまとめて行い、ディスクに書き込むこともできる。

→ [14. ビルドする](14-build.md#14-ビルドする) ・ 関連: [多重化](#多重化)、[ISO イメージ](#iso-イメージ)

### ピックウィップ

プロパティの欄の左の丸をドラッグして、リンクの行き先（プロジェクトパネルの項目、フローチャートの箱、チャプターマーカー
など）に落とす操作。長い一覧から選ぶより速い。

→ [17.7 ボタンへのリンクの入れ方 5 とおり](17-advanced.md#177-ボタンへのリンクの入れ方-5-とおり) ・ 関連: [リンク](#リンク)

### ファーストプレイ

*First Play*

ディスクを入れたときに最初に再生されるもの。警告の映像やメインメニューにすることが多い。ディスクのプロパティで決める。

→ [10.1 ファーストプレイとタイトルボタン](10-navigation.md#101-ファーストプレイとタイトルボタン) ・ 関連: [タイトルボタン](#タイトルボタン)

### フレームレート

1 秒あたりのフレーム（絵）の数。NTSC は 29.97、PAL は 25。テレビ方式に合わない素材は、ビルドのときに変換される。

→ [5.3 素材について](05-assets.md#53-素材について) ・ 関連: [NTSC / PAL](#ntsc--pal)、[インターレース](#インターレース)

### フローチャート

*Flowchart*

ディスクの項目（メニュー、タイムラインなど）を箱で、つながりを矢印で描いた図。リンクのない項目や行き止まりを見つけるの
に使う。

→ [10.2 フローチャート](10-navigation.md#102-フローチャート)、[17.8 フローチャートをディスクの地図として使う](17-advanced.md#178-フローチャートをディスクの地図として使う) ・ 関連: [ナビゲーション](#ナビゲーション)

### プログレッシブ

*Progressive*

1 枚の絵を一度に描く映像。パソコンやスマートフォンの動画に多い。

→ [5.1 読み込み方](05-assets.md#51-読み込み方) ・ 関連: [インターレース](#インターレース)

### プロジェクト

*Project*

DiscCraft の作業のファイル（`.dcproj`）。素材そのものは入れず、ファイルの場所（パス）を覚える。メニュー、タイムライン、
ナビゲーション、ビルドの設定などが入る。

→ [2. はじめに](02-getting-started.md#2-はじめに)、[2.3 保存](02-getting-started.md#23-保存) ・ 関連: [アセット](#アセット)

### プロジェクトプレビュー

*Project Preview*

ビルドせずにディスクを試す窓。リモコンの操作で、メニューやナビゲーションを確かめられる。

→ [13.1 プロジェクトプレビュー（ビルドしないプレビュー）](13-preview.md#131-プロジェクトプレビュービルドしないプレビュー) ・ 関連: [VM](#vm)、[モニター](#モニター)

### プロパティ

*Properties*

選んでいるもの（ディスク、タイムライン、メニュー、ボタンなど）の設定を並べたパネル。何も選んでいないときは、ディスクの
設定が出る。

→ [4.3 パネル](04-screen.md#43-パネル)

### ボタン

*Button*

メニューで観る人が選ぶもの。リンク（押したときの行き先）とハイライトを持つ。PSD では `(+)` で始まるレイヤーセットがボタ
ンになる。

→ [9.2 ボタン](09-menus.md#92-ボタン) ・ 関連: [リンク](#リンク)、[ハイライト](#ハイライト)、[レイヤーセット](#レイヤーセット)

### ポスターフレーム

タイムラインやチャプターの代表の絵。メニューのボタンの絵やフローチャートの箱に使う。**タイムライン ▸ ポスターフレームを
設定** で、再生ヘッドの位置の絵にする。

→ [6.3 チャプターポイント](06-timelines.md#63-チャプターポイント)、[17.1 絵入りのシーン選択メニュー](17-advanced.md#171-絵入りのシーン選択メニュー) ・ 関連: [再生ヘッド](#再生ヘッド)

### ポップアップメニュー

*Pop-up Menu*

Blu-ray で、再生中の映像に重ねて出すメニュー。映像を止めずにチャプターなどを選べる。メニューの **ポップアップ** タブで
作り、タイムラインのリモートメニューにする。

→ [16. Blu-ray を作る](16-bluray.md#16-blu-ray-を作る) ・ 関連: [リモートメニュー](#リモートメニュー)、[HDMV / BD-J](#hdmv--bd-j)

## 24.8 ま行

### メニュー

*Menu*

ボタンの並んだ画面。背景の絵や動画、文字、ボタンでできていて、ボタンからタイトルやほかのメニューへ行く。ライブラリのテ
ンプレートや PSD から作れる。

→ [9. メニューを作る](09-menus.md#9-メニューを作る) ・ 関連: [ボタン](#ボタン)、[ライブラリ](#ライブラリ)、[PSD](#psd)

### メニュービューア

*Menu Viewer*

メニューを編集するパネル。ボタンや文字を置き、セーフエリアやボタンのルートを表示できる。

→ [4.3 パネル](04-screen.md#43-パネル)、[9.1 作り方](09-menus.md#91-作り方) ・ 関連: [メニュー](#メニュー)

### モーションメニュー

*Motion Menu*

背景が動いたり、音が鳴ったりするメニュー。背景に動画や音声を置いて作り、ビルドのときに動きのある絵を作る（**ファイル ▸ レ
ンダリング** で先に作っておける）。

→ [9.5 背景とモーションメニュー](09-menus.md#95-背景とモーションメニュー)、[17.6 モーションメニューに音と動きを](17-advanced.md#176-モーションメニューに音と動きを) ・ 関連: [メニュー](#メニュー)

### モニター

*Monitor*

タイムラインの映像や、ビルドしたディスクを映すパネル。ビルドしていないときは、選んでいるタイムラインを音と字幕つきで再
生する。

→ [13.2 モニター（ビルド結果の再生）](13-preview.md#132-モニタービルド結果の再生) ・ 関連: [プロジェクトプレビュー](#プロジェクトプレビュー)

## 24.9 や行・ら行・わ行

### ユーザー操作

*User Operations*

観る人のリモコンの操作（早送り、チャプター送り、メニューへの移動など）を、場面ごとに許すか禁じるか。警告の映像を飛ばせ
ないようにする、などに使う。

→ [9.7 ユーザー操作](09-menus.md#97-ユーザー操作)

### ライブラリ

*Library*

メニュー、ボタン、背景などのテンプレートの棚。ドラッグしてメニューを組み立てる。自分の項目を足すこともできる。

→ [17.2 ライブラリからメニューを組み立てる](17-advanced.md#172-ライブラリからメニューを組み立てる)、[18.5 メディア](18-preferences.md#185-メディア) ・ 関連: [メニュー](#メニュー)

### リージョンコード

*Region Code*

DVD を再生できる地域の指定。すべてのリージョン、または 1〜8 から選ぶ（DVD のときだけ）。ほかのリージョンのプレーヤーで
は再生されない。

→ [14.4 リージョンと視聴制限](14-build.md#144-リージョンと視聴制限)、[18.4 プレビュー](18-preferences.md#184-プレビュー) ・ 関連: [視聴制限](#視聴制限)、[コピーガード](#コピーガード)

### リモートメニュー

*Remote Menu*

再生中にリモコンのメニューボタンを押したときに出るメニュー。タイムラインごとに決める。Blu-ray ではポップアップメニュー
になる。

→ [6.5 エンドアクション、上書き、リモートメニュー](06-timelines.md#65-エンドアクション上書きリモートメニュー) ・ 関連: [ポップアップメニュー](#ポップアップメニュー)、[タイトルボタン](#タイトルボタン)

### リンク

*Link*

ボタンやエンドアクションの行き先。メニュー、タイムライン（のチャプター）、スライドショー、再生リストなどを指せる。プロ
パティの欄から選ぶか、ピックウィップでつなぐ。

→ [10.3 リンクの種類](10-navigation.md#103-リンクの種類)、[17.7 ボタンへのリンクの入れ方 5 とおり](17-advanced.md#177-ボタンへのリンクの入れ方-5-とおり) ・ 関連: [ピックウィップ](#ピックウィップ)、[エンドアクション](#エンドアクション)

### ルート

観る人が矢印キーを押したときに、ハイライトがボタンからボタンへたどる道。DiscCraft が自動で引き、手で引き直すこともでき
る。

→ [17.3 ルートと番号を手で決める](17-advanced.md#173-ルートと番号を手で決める) ・ 関連: [ハイライト](#ハイライト)、[ボタン](#ボタン)

### レイヤー

*Layers*

メニューの絵の重なり（背景、ボタン、文字など）。レイヤーパネルに並び、表示や順番を変えられる。

→ [4.3 パネル](04-screen.md#43-パネル) ・ 関連: [レイヤーセット](#レイヤーセット)

### レイヤーセット

PSD のレイヤーのグループ。名前が `(+)` で始まるものがメニューのボタンになり、その中の `(=1)` などで始まるレイヤーがハイ
ライトになる。

→ [9.2 ボタン](09-menus.md#92-ボタン) ・ 関連: [PSD](#psd)、[ボタン](#ボタン)

### レイヤーブレーク

*Layer Break*

2 層のディスクで、1 層目から 2 層目に移る位置。移るときに一瞬止まるプレーヤーがあるので、場面の変わり目に置くのがよい。DiscCraft が
自動で決めるか、タイムコードで手で決める。

→ [14.1 ビルドパネル](14-build.md#141-ビルドパネル) ・ 関連: [DVD-5 / DVD-9](#dvd-5--dvd-9)、[DVD+R DL](#dvdr-dl)

### レーベル

*Disc Label*

印刷できるディスクの面に刷る絵。ディスクの名前などを入れて DesignCraft で作り、プロジェクトに紐づけて保存する。

→ [15. ディスクのレーベルを作る](15-labels.md#15-ディスクのレーベルを作る) ・ 関連: [プロジェクト](#プロジェクト)

### ワークスペース

*Workspace*

パネルの並び。名前を付けて残し、**ウィンドウ ▸ ワークスペース** で切り替える。並びがくずれたら、そこからリセットできる。

→ [4.4 パネルの並べ替えとワークスペース](04-screen.md#44-パネルの並べ替えとワークスペース)
