[目次](README.md) ・ 次の章: [2. はじめに](02-getting-started.md#2-はじめに)

> **この章でできること**
>
> - DiscCraft で作れるディスク（DVD と Blu-ray）を知る

## 1.1 DiscCraft でできること

DiscCraft は映像・音声・静止画から DVD-Video と Blu-ray（BDMV）を作るオーサリングソフト。
メニュー、チャプター、複数の音声・字幕、ナビゲーションを組み立て、規格に合わない素材を自動で変換して、
フォルダか ISO イメージに書き出す。

できること:

- DVD と Blu-ray のディスクを作る。ディスクに書き込むほか、フォルダー（`VIDEO_TS` / `BDMV`）や ISO イメージにも書き出せる
- メニューを作る。止まった絵のメニュー、背景が動くメニュー、Photoshop（PSD）で作ったメニュー
- 動画をつないで 1 本の映像にし、チャプター、言語違いの音声と字幕を付ける
- 写真のスライドショー、何本かを続けて再生するプレイリスト
- ディスクを入れたときに流すもの、ボタンの行き先、再生が終わったあとの行き先を決める
- ビルドする前に、できあがるディスクと同じように動かして試す（プロジェクトプレビュー）
- 形式の合わない素材を自動で変換する。DVD に合った映像（MPEG-2）と音（AC-3 / WAV / DTS）は変換せずにそのまま入れる
- 画面からだけでなく、コマンドラインや AI エージェント（MCP）からも同じ操作をする

できないこと（いまのところ）:

- macOS と Linux でのディスクへの書き込み（フォルダーと ISO イメージは作れるので、書き込みはほかのソフトで）。
  Windows ではビルドパネルからそのままディスクに書き込める
- コピーガード（CSS、AACS など）。リージョンコードの設定だけはできる
- Java のプログラムで動く Blu-ray のメニュー（BD-J）。DiscCraft の Blu-ray のメニューは DVD と同じ作りのもの（HDMV）
- DTS / Dolby TrueHD / DTS-HD の音への変換（DTS のファイルをそのまま入れることはできる）
- 動画の編集そのもの（編集は FilmCraft などで行い、DiscCraft でディスクにする）
- 4K（Ultra HD Blu-ray）

Blu-ray の映像の形式（SD と HD、コーデック）は [16 章](16-bluray.md#16-blu-ray-を作る) にまとめてある。

画面の名前と操作は、Adobe Encore（DVD と Blu-ray のオーサリングソフト。開発は終わっている）に合わせてある。
Encore を使っていた人は、同じ名前のメニューやパネルで同じように作れる。違うところは
[17.10 まだないもの](17-advanced.md#1710-まだないもの) にある。

## 1.2 このマニュアルの読み方

| 書き方 | 意味 |
|---|---|
| **ファイル ▸ 読み込み ▸ アセット…** | メニューを左から順にたどって選ぶ。太字は画面に出ている名前 |
| Ctrl+I | Ctrl を押したまま I を押す |
| `.dcproj` | ファイルやフォルダーの名前、打ち込む文字 |
| [5.1 読み込み方](05-assets.md#51-読み込み方) | ほかの章や節へのリンク（PDF ではクリックで飛ぶ） |

各章は、その章で何ができるかの囲みから始まる。本文のあいだの囲みは 2 種類ある。

> **ヒント**
>
> 知っておくと作業が楽になること。

> **詳しく**
>
> 細かい決まりや、ディスクの規格に関わること。初めて読むときは飛ばしてよい。

画面の画像は Windows で、日本語の表示で撮った。英語の表示での名前は [用語集](24-glossary.md#24-用語集) に添えてある。
