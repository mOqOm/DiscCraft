# 19. Keyboard Shortcuts

[Contents](README.md) · Previous: [18. Preferences](18-preferences.md#18-preferences) · Next: [20. Command Line and Scripts](20-command-line.md#20-command-line-and-scripts)

> **In this chapter**
>
> - Look up keyboard shortcuts

`Ctrl` is `Cmd` on macOS. Some shortcuts (such as Ctrl+Z) do not work while entering text.

## 19.1 File and Project

| Key | Action |
|---|---|
| Ctrl+N / Ctrl+O / Ctrl+S / Shift+Ctrl+S | **New Project** / **Open** / **Save** / Save As |
| Shift+Ctrl+W | **Close Project** |
| Ctrl+I | **Import ▸ Asset…** |
| Shift+Ctrl+I / Shift+Ctrl+K / Shift+Ctrl+U | **Import ▸ Menu…** / **Pop-up Menu…** / **Menu Page…** |
| Shift+Ctrl+T / Shift+Ctrl+G | **Import ▸ Timeline…** / **Slideshow…** |
| Shift+Ctrl+L | **Check Project…** |
| Alt+Ctrl+Space | **Preview** |
| Ctrl+Q | Exit |

## 19.2 Create and Edit

| Key | Action |
|---|---|
| Ctrl+M / Ctrl+T / Ctrl+G | **New Menu** / **New Timeline** / **New Slideshow** |
| Ctrl+Z / Shift+Ctrl+Z | **Undo** / **Redo** |
| Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D | **Cut** / **Copy** / **Paste** / **Duplicate** |
| Delete | **Clear** |
| Ctrl+A / Shift+Ctrl+A | Select All / Deselect All |
| Alt+Ctrl+R | **Rename…** |
| Ctrl+E | **Edit Original** |
| Ctrl+W | **Close** (Empties the viewer for the selected menu, timeline, slideshow, or chapter playlist. The items remain.) |
| Shift+Delete | **Ripple Delete** (Removes the video clip under the playhead in the Timeline Viewer and closes the gap behind it) |
| Alt+Shift+Ctrl+R / Alt+Shift+Ctrl+H | **Replace Asset…** / **Locate Asset…** (For the asset selected in the Project panel) |
| Shift+`*` on the numeric keypad | **Set Poster Frame** (For the chapter at the playhead. Pressing only `*` on the numeric keypad, or `*` on the main keyboard, adds a chapter point) |
| Alt+Ctrl+T | **Move Track to View** (Scrolls the timeline to the active audio track) |
| Shift+Ctrl+F | **Save Frame as File…** (Saves the frame at the playhead in the Timeline Viewer as a PNG with square pixels) |
| Shift+Ctrl+M | **Edit Menu in PhotoCraft** |
| Ctrl+K | **Preferences…** |

## 19.3 Object

| Key | Action |
|---|---|
| Ctrl+B | **Convert to Button** |
| Ctrl+L | **Specify Link…** |
| Shift+Ctrl+O | **Drop Shadow…** |
| Alt+Ctrl+H / Alt+Ctrl+V | **Flip Horizontal** / **Flip Vertical** |
| Ctrl+] / Shift+Ctrl+] | **Bring Forward** / **Bring to Front** |
| Ctrl+[ / Shift+Ctrl+[ | **Send Backward** / **Send to Back** |
| Ctrl+Alt+M | **Save Menu as Template…** |
| V / A / M / R / T / Y / Z | Select / Direct Select / Move / Rotate / Text / Vertical Text / **Zoom Tool** |

## 19.4 View and Playback

| Key | Action |
|---|---|
| Space | **Play** / **Stop** |
| L / J / K | **Play Faster** (Normal speed if stopped) / **Play Slower** (0.5× if stopped) / **Stop** |
| + / - / \\ | **Zoom In** / **Zoom Out** / **Fit in Window** |
| ← / → | Back 1 Frame / Forward 1 Frame |
| Home / End | Go to Start of Timeline / Go to End of Timeline |
| `*` (numeric keypad) | **Add Chapter Point** |
| Ctrl+3 / Ctrl+4 / Ctrl+5 | Show Subpicture: Normal / Selected / Activated |
| Ctrl+6 / Ctrl+7 / Ctrl+8 | Show Safe Area / Button Route / **Chapter Names** |
| Ctrl+: / Shift+Ctrl+: / Alt+Ctrl+: | **Show Guides** / **Snap to Guides** / **Lock Guides** |
| Shift+Alt+Ctrl+: | **New Guide…** |

## 19.5 Window

| Key | Action |
|---|---|
| F1 | **DiscCraft Help…** (This manual) |
| F2 / F3 / F4 / F5 | **Build** / Text / Checks / **Flowchart** |
| F6 / F7 / F8 / F9 / F10 | Layers / Library / Menus / Monitor / Progress |
| F11 / F12 / Ctrl+F2 / Ctrl+F3 | Project / Properties / Styles / Timeline |
| Ctrl+F4 | Tools: Show/hide the toolbar below the menu bar (Persists to the next launch) |
