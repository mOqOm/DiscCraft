## 24.2 Numbers

### 1080i / 1080p / 720p

HD video formats. The numbers indicate the vertical pixel count (1920 × 1080, 1280 × 720), i stands for interlaced, and
p stands for progressive. These go directly onto Blu-ray discs; when placed on a DVD, they are converted to SD.

→ [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc) · Related: [Interlaced](#interlaced),
[Progressive](#progressive), [SD / HD](#sd--hd)

## 24.3 A

### AC-3 (Dolby Digital)

The standard compressed audio format for DVDs and Blu-rays. Audio that does not match the disc specifications is
converted to 192 kbps stereo AC-3 during the build. Existing AC-3 files are included without conversion.

→ [5.3 About Assets](05-assets.md#53-about-assets), [22. Limits and Rules](22-limits.md#22-limits-and-rules) · Related:
[LPCM](#lpcm), [DTS](#dts), [Transcode](#transcode)

### Activated

*アクティベート*

Confirming a menu button (pressing the Enter button on the remote). The color of the button when pressed is called the
"Activated Color," which can be set separately from the "Selected Color" used when the cursor is over it.

→ [9.4 Colors and Highlights](09-menus.md#94-colors-and-highlights) · Related: [Highlight](#highlight),
[Subpicture](#subpicture)

### Aspect ratio (16:9 / 4:3)

The ratio of the screen's width to its height. 16:9 is widescreen, while 4:3 is the shape of older televisions. DVDs
support both formats; choose one in **Advanced** when creating a new project, or change it later in the Disc panel.

→ [2.2 New Project](02-getting-started.md#22-new-project) · Related: [TV mode](#tv-mode)

### Asset

*アセット*

Imported media files (video, audio, images, subtitles). They are listed in the Project panel and used in timelines,
menus, and slideshows. The files are not copied; they are used from their original locations.

→ [5. Importing Assets](05-assets.md#5-importing-assets) · Related: [Offline](#offline), [Transcode](#transcode)

### Audio Track

*オーディオトラック*

The audio lanes in the Timeline. A single title can contain multiple audio tracks, such as different languages or
commentary, which viewers switch using the remote control.

→ [6.4 Tracks](06-timelines.md#64-tracks) · Related: [Subtitle Track](#subtitle-track), [Timeline](#timeline)

### Authoring

*オーサリング*

The process of assembling video, menus, and navigation to create a disc. DiscCraft is an application for this purpose.

→ [1. About DiscCraft](01-about.md#1-about-disccraft)

### Authoring mode

*オーサリングモード*

The type of disc being created (DVD or Blu-ray). You select this when creating a new project, but you can switch it
later in the Disc panel, allowing you to build the same project for both formats.

→ [2.2 New Project](02-getting-started.md#22-new-project),
[16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc)

## 24.4 B

### BD-25 / BD-50

Single-layer (25 GB) and dual-layer (50 GB) Blu-ray discs. Select the type in **Advanced** when creating a new project,
or choose the **Size** in the Build panel. The usage bar displays capacity relative to this size.

→ [2.2 New Project](02-getting-started.md#22-new-project), [22. Limits and Rules](22-limits.md#22-limits-and-rules) ·
Related: [DVD-5 / DVD-9](#dvd-5--dvd-9)

### BDMV

The folder containing the contents of a Blu-ray disc. This is created when you select a folder as the destination during
the build.

→ [14.2 Destination](14-build.md#142-destination), [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc) ·
Related: [VIDEO_TS](#video_ts), [ISO image](#iso-image)

### Bitrate

*ビットレート*

The amount of data per second (Mbps). Higher bitrates provide better quality but use more disc capacity. The maximum
video bitrate for DVD is 9.8 Mbps, and by default, it is automatically determined based on the disc's capacity.

→ [5.3 About Assets](05-assets.md#53-about-assets) · Related: [VBR / CBR](#vbr--cbr), [Transcode](#transcode)

### Build

*ビルド*

Creating the disc contents (`VIDEO_TS` / `BDMV` folders, ISO image, DDP image) from the project. This performs asset
conversion, menu rendering, and multiplexing all at once, and you can also write to a disc.

→ [14. Building](14-build.md#14-building) · Related: [Multiplexing](#multiplexing), [ISO image](#iso-image)

### Button

*ボタン*

An item in a menu that viewers select. It has a link (destination when pressed) and a highlight. In PSDs, layer sets
starting with `(+)` become buttons.

→ [9.2 Buttons](09-menus.md#92-buttons) · Related: [Link](#link), [Highlight](#highlight), [Layer Set](#layer-set)

## 24.5 C

### Cache

*キャッシュ*

Data kept to speed up work. The media cache stores asset lengths, thumbnails, and indexes, while the build cache keeps
converted video and audio so that conversion can be skipped in the next build.

→ [18.5 Media](18-preferences.md#185-media) · Related: [Transcode](#transcode)

### Chapter

*チャプター*

A division within a title. Viewers can jump to chapters using the "Next" and "Previous" buttons on the remote, or play
them directly from menu buttons. You create chapters by placing chapter points on the timeline.

→ [6.3 Chapter Points](06-timelines.md#63-chapter-points) · Related: [Chapter Index](#chapter-index),
[GOP (group of pictures)](#gop-group-of-pictures), [Playhead](#playhead)

### Chapter Index

*チャプターインデックス*

A row of buttons for each chapter in a menu (Scene Selection). Choose **Menu ▸ Create Chapter Index** to create the
buttons and links automatically. If there are many buttons, they are split into pages.

→ [8.3 Chapter Index](08-playlists.md#83-chapter-index),
[17.1 Scene Selection Menus with Images](17-advanced.md#171-scene-selection-menus-with-images) · Related:
[Chapter](#chapter), [Menu](#menu)

### Chapter Playlist

*チャプター再生リスト*

An item that plays selected chapters from a single timeline in any order. You can create digest versions without
duplicating the video.

→ [8.2 Chapter Playlist](08-playlists.md#82-chapter-playlist) · Related: [Playlist](#playlist), [Chapter](#chapter)

### Clip

*クリップ*

Segments of video, audio, or subtitles arranged on the Timeline. You can also trim their start and end points.

→ [6.2 Multiple Video Clips](06-timelines.md#62-multiple-video-clips) · Related: [Timeline](#timeline)

### Color Set

*カラーセット*

A group of colors used for menu button highlights and subtitles. Since DVD highlights have a limited number of colors,
you define the colors to use as a set. **Automatic** takes colors from the button layers.

→ [9.4 Colors and Highlights](09-menus.md#94-colors-and-highlights), [11.3 Appearance](11-subtitles.md#113-appearance) ·
Related: [Highlight](#highlight), [Subpicture](#subpicture)

### Copy protection

*コピーガード*

A mechanism to prevent duplication of commercial discs (CSS for DVD, AACS for Blu-ray). DiscCraft does not include this.
You can only set the region code flag for DVDs.

→ [17.10 Not Yet Available](17-advanced.md#1710-not-yet-available) · Related: [Region Code](#region-code)

## 24.6 D

### DDP image

*DDP イメージ*

A set of files containing the disc contents and description (Disc Description Protocol) delivered to pressing plants
instead of a master disc. This can only be created for DVDs.

→ [14.2 Destination](14-build.md#142-destination) · Related: [ISO image](#iso-image), [Layer Break](#layer-break)

### Disc label

*レーベル*

The image printed on the printable face of the disc. Create it in DesignCraft with the disc name, etc., and save it
linked to the project.

→ [15. Making a Disc Label](15-labels.md#15-making-a-disc-label) · Related: [Project](#project)

### DTS

A compressed audio format used in films and other media. DTS files (`.dts`) are included directly on DVD and Blu-ray
Audio Tracks without conversion (up to 48 kHz, 1509.75 kbps). DiscCraft cannot convert audio to DTS.

→ [5.2 Supported Files](05-assets.md#52-supported-files) · Related: [AC-3 (Dolby Digital)](#ac-3-dolby-digital),
[Audio Track](#audio-track)

### Duration

*デュレーション*

Length. You set the length of new slides (default 6 seconds) and the length of subtitles added in the Monitor (default 2
seconds) in Preferences.

→ [7. Making Slideshows](07-slideshows.md#7-making-slideshows), [18.3 Timeline](18-preferences.md#183-timeline) ·
Related: [Slideshow](#slideshow)

### DVD+R DL

A writable dual-layer DVD. It holds a DVD-9 image.

→ [14.7 Writing to a Disc](14-build.md#147-writing-to-a-disc) · Related: [DVD-5 / DVD-9](#dvd-5--dvd-9)

### DVD-5 / DVD-9

Single-layer (4.7 GB) and dual-layer (8.5 GB) DVDs. For DVD-9, DiscCraft determines the position where the disc switches
from layer 0 to layer 1 (Layer Break). You can also set this manually.

→ [14.3 Disc Info](14-build.md#143-disc-info) · Related: [Layer Break](#layer-break), [DVD+R DL](#dvdr-dl),
[BD-25 / BD-50](#bd-25--bd-50)

### DVD-ROM / BD-ROM content

*ROM コンテンツ*

Files included on the disc for reading on a computer (such as PDF manuals or photos). Select the folder in **DVD-ROM
Content** / **BD-ROM Content** in the Build panel.

→ [14.3 Disc Info](14-build.md#143-disc-info)

## 24.7 E–G

### End Action

*エンドアクション*

The destination to go to after playing a timeline, slideshow, playlist, etc., to the end. For example, you can return to
the Main Menu when the main movie finishes. Set this in **End Action** in the Properties panel.

→ [6.5 End Action, Override, Remote Menu](06-timelines.md#65-end-action-override-remote-menu) · Related:
[Override](#override), [Remote Menu](#remote-menu), [Link](#link)

### First Play

*ファーストプレイ*

The item that plays first when the disc is inserted. This is often a warning video or the Main Menu. You set this in the
disc's Properties.

→ [10.1 First Play and Title Button](10-navigation.md#101-first-play-and-title-button) · Related:
[Title Button](#title-button)

### Flowchart

*フローチャート*

A diagram showing disc items (menus, timelines, etc.) as boxes and connections as arrows. It is used to find items with
no links or dead ends.

→ [10.2 Flowchart](10-navigation.md#102-flowchart),
[17.8 Using the Flowchart as a Disc Map](17-advanced.md#178-using-the-flowchart-as-a-disc-map) · Related:
[Navigation](#navigation)

### Frame rate

*フレームレート*

The number of frames (images) per second. NTSC is 29.97, and PAL is 25. Assets that do not match the TV standard are
converted during the build.

→ [5.3 About Assets](05-assets.md#53-about-assets) · Related: [NTSC / PAL (TV standard)](#ntsc--pal-tv-standard),
[Interlaced](#interlaced)

### GOP (group of pictures)

A group of frames encoded together in compressed video. In MPEG-2 files that go directly onto a disc, chapter points and
trim cuts can only be placed at the start of a GOP, so DiscCraft snaps them to the nearest GOP boundary.

→ [6.2 Multiple Video Clips](06-timelines.md#62-multiple-video-clips) · Related: [MPEG-2](#mpeg-2), [Chapter](#chapter)

## 24.8 H–L

### H.264

A video compression method (AVC). It is used for HD video on Blu-ray discs and results in smaller files than MPEG-2 at
the same quality. On Windows, conversion can also be performed using the graphics card's encoder.

→ [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc), [18.7 Memory](18-preferences.md#187-memory) ·
Related: [MPEG-2](#mpeg-2), [SD / HD](#sd--hd)

### HDMV / BD-J

The two menu systems for Blu-ray discs. HDMV menus are built with buttons and navigation commands, while BD-J menus are
built with Java programs. DiscCraft uses HDMV for Blu-ray, so the menu creation process is the same as for DVDs.

→ [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc) · Related: [Pop-up Menu](#pop-up-menu)

### Highlight

*ハイライト*

The color or shape indicating the selected button in a menu. On DVDs, this is drawn using subpictures, and you can
change the color for Selected and Activated states.

→ [9.4 Colors and Highlights](09-menus.md#94-colors-and-highlights) · Related: [Subpicture](#subpicture),
[Color Set](#color-set), [Route](#route)

### Interlaced

*インターレース*

Video that splits each frame into two fields (odd and even lines) and transmits them alternately. This is common in
television and video camera footage. Footage with the same frame rate as DVD goes onto the disc with the two fields kept
separate.

→ [5.1 How to Import](05-assets.md#51-how-to-import) · Related: [Progressive](#progressive),
[1080i / 1080p / 720p](#1080i--1080p--720p)

### ISO image

*ISO イメージ*

A single file (`.iso`) containing the entire disc contents. You can write it to a disc or mount it to check playback in
a player.

→ [14.2 Destination](14-build.md#142-destination), [14.7 Writing to a Disc](14-build.md#147-writing-to-a-disc) ·
Related: [VIDEO_TS](#video_ts), [BDMV](#bdmv), [DDP image](#ddp-image)

### Layer

*レイヤー*

The stacking of menu images (background, buttons, text, etc.). They are listed in the Layers panel, where you can change
visibility and order.

→ [4.3 Panels](04-screen.md#43-panels) · Related: [Layer Set](#layer-set)

### Layer Break

*レイヤーブレーク*

The position where the disc switches from layer 0 to layer 1 on a dual-layer disc. Since some players pause briefly
during the switch, it is best to place this at scene changes. DiscCraft determines this automatically, or you can set it
manually using timecode.

→ [14.1 Build Panel](14-build.md#141-build-panel) · Related: [DVD-5 / DVD-9](#dvd-5--dvd-9), [DVD+R DL](#dvdr-dl)

### Layer Set

*レイヤーセット*

A group of PSD layers. Groups with names starting with `(+)` become menu buttons, and layers within them starting with
`(=1)` etc. become highlights.

→ [9.2 Buttons](09-menus.md#92-buttons) · Related: [PSD](#psd), [Button](#button)

### Library

*ライブラリ*

A shelf of templates for menus, buttons, backgrounds, and more. Drag items to assemble menus. You can also add your own
items.

→ [17.2 Building Menus from the Library](17-advanced.md#172-building-menus-from-the-library),
[18.5 Media](18-preferences.md#185-media) · Related: [Menu](#menu)

### Link

*リンク*

The destination for a button or End Action. It can point to menus, timelines (chapters), slideshows, playlists, etc.
Select from the Properties field or connect using the pick whip.

→ [10.3 Types of Links](10-navigation.md#103-types-of-links),
[17.7 Five Ways to Link Buttons](17-advanced.md#177-five-ways-to-link-buttons) · Related: [Pick whip](#pick-whip),
[End Action](#end-action)

### LPCM

Uncompressed audio (Linear PCM). WAV audio goes directly onto the disc as LPCM. The sound quality is high, but the file
size is much larger than AC-3.

→ [5.2 Supported Files](05-assets.md#52-supported-files) · Related: [AC-3 (Dolby Digital)](#ac-3-dolby-digital)

## 24.9 M

### MCP (Model Context Protocol)

A mechanism for controlling DiscCraft from AI agents. `disccraft-cli mcp` runs as an MCP server, allowing agents to
execute commands and check projects.

→ [21. Using DiscCraft from AI Agents (MCP)](21-mcp.md#21-using-disccraft-from-ai-agents-mcp) · Related:
[Project](#project)

### Menu

*メニュー*

A screen with arranged buttons. It consists of a background image or video, text, and buttons, from which viewers go to
titles or other menus. You can create menus from Library templates or PSDs.

→ [9. Making Menus](09-menus.md#9-making-menus) · Related: [Button](#button), [Library](#library), [PSD](#psd)

### Menu Viewer

*メニュービューア*

The panel for editing menus. You place buttons and text, and can display safe areas and button routing.

→ [4.3 Panels](04-screen.md#43-panels), [9.1 How to Create Them](09-menus.md#91-how-to-create-them) · Related:
[Menu](#menu)

### Monitor

*モニター*

A panel that displays timeline video or the built disc. When not built, it plays the selected timeline with audio and
subtitles.

→ [13.2 Monitor (Playing Build Output)](13-preview.md#132-monitor-playing-build-output) · Related:
[Project Preview](#project-preview)

### Motion Menu

*モーションメニュー*

A menu with a moving background or sound. You create it by placing video and audio in the background; during the build,
animated images are generated (you can generate them in advance using **File ▸ Render**).

→ [9.5 Backgrounds and Motion Menus](09-menus.md#95-backgrounds-and-motion-menus),
[17.6 Adding Sound and Motion to Motion Menus](17-advanced.md#176-adding-sound-and-motion-to-motion-menus) · Related:
[Menu](#menu)

### MPEG-2

A video compression method. All DVD video is MPEG-2, and it can also be used for SD video on Blu-ray discs. MPEG-2 files
that comply with the standard are included without conversion.

→ [5.3 About Assets](05-assets.md#53-about-assets) · Related: [GOP (group of pictures)](#gop-group-of-pictures),
[H.264](#h264), [Transcode](#transcode)

### Multiplexing

*多重化*

Combining video, audio, and subtitles into a single continuous data stream for the disc. This is part of the build
process, and the disc usage calculation includes the overhead added by multiplexing (about 2%).

→ [14.3 Disc Info](14-build.md#143-disc-info) · Related: [Build](#build)

## 24.10 N–O

### Navigation

*ナビゲーション*

The movement within the disc connected by buttons, End Actions, and remote control buttons. View the overall structure
in the Flowchart and test it in Project Preview.

→ [10. Building the Navigation](10-navigation.md#10-building-the-navigation) · Related: [Link](#link),
[Flowchart](#flowchart), [VM (virtual machine)](#vm-virtual-machine)

### NTSC / PAL (TV standard)

Television standards. Japan and North America use NTSC (720 × 480, 29.97 frames per second), while Europe and other
regions use PAL (720 × 576, 25 frames). You select this when creating a new project, which determines the DVD video size
and frame rate.

→ [2.2 New Project](02-getting-started.md#22-new-project), [18.1 General](18-preferences.md#181-general) · Related:
[Frame rate](#frame-rate)

### Offline

*オフライン*

The state where an asset's file cannot be found in its original location. This happens if you move or rename the file.
Right-click in the Project panel and choose **Replace Asset…** to specify the new location.

→ [2.3 Saving](02-getting-started.md#23-saving), [23. Troubleshooting](23-troubleshooting.md#23-troubleshooting) ·
Related: [Asset](#asset)

### Override

*上書き*

The destination to go to after the target reached via an End Action finishes. It is used instead of the original End
Action of the target, allowing flows like "Warning → Main Movie → Extras Menu."

→ [6.5 End Action, Override, Remote Menu](06-timelines.md#65-end-action-override-remote-menu) · Related:
[End Action](#end-action), [Link](#link)

## 24.11 P

### Parental level

*視聴制限*

A setting that prevents disc playback based on age or other criteria (parental lock). In the DVD Build panel, you set
the parental level (None, or 1–8; 8 is the strictest). Discs with a higher level than the player's will not play.

→ [14.4 Region and Parental Level](14-build.md#144-region-and-parental-level),
[18.4 Preview](18-preferences.md#184-preview) · Related: [Region Code](#region-code)

### Pick whip

*ピックウィップ*

Dragging the circle on the left of a Properties field and dropping it onto a link destination (an item in the Project
panel, a box in the Flowchart, a chapter marker, etc.). This is faster than selecting from a long list.

→ [17.7 Five Ways to Link Buttons](17-advanced.md#177-five-ways-to-link-buttons) · Related: [Link](#link)

### Playhead

*再生ヘッド*

The vertical line in the Timeline or Monitor that indicates the current position. Chapter points and poster frames can
be placed at the playhead's location.

→ [6.3 Chapter Points](06-timelines.md#63-chapter-points) · Related: [Chapter](#chapter), [Poster frame](#poster-frame)

### Playlist

*再生リスト*

An item that plays several timelines or slideshows consecutively in a specified order. It is used for buttons that play
the main movie and extras together, for example.

→ [8.1 Playlist](08-playlists.md#81-playlist) · Related: [Chapter Playlist](#chapter-playlist)

### Pop-up Menu

*ポップアップメニュー*

A menu overlaid on the video during playback on Blu-ray. Viewers can select chapters, etc., without stopping the video.
Create it in the **Pop-up** tab of the menu and set it as the timeline's Remote Menu.

→ [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc) · Related: [Remote Menu](#remote-menu),
[HDMV / BD-J](#hdmv--bd-j)

### Poster frame

*ポスターフレーム*

The representative image for a timeline or chapter. It is used for menu button images and Flowchart boxes. Choose
**Timeline ▸ Set Poster Frame** to use the image at the playhead's position.

→ [6.3 Chapter Points](06-timelines.md#63-chapter-points),
[17.1 Scene Selection Menus with Images](17-advanced.md#171-scene-selection-menus-with-images) · Related:
[Playhead](#playhead)

### Progressive

*プログレッシブ*

Video that draws each frame in one pass. This is common in videos from computers and smartphones.

→ [5.1 How to Import](05-assets.md#51-how-to-import) · Related: [Interlaced](#interlaced)

### Project

*プロジェクト*

The DiscCraft work file (`.dcproj`). It does not contain the assets themselves but remembers their file paths. It
includes menus, timelines, navigation, and build settings.

→ [2. Getting Started](02-getting-started.md#2-getting-started), [2.3 Saving](02-getting-started.md#23-saving) ·
Related: [Asset](#asset)

### Project Preview

*プロジェクトプレビュー*

A window for testing the disc without building it. You can check menus and navigation using remote control operations.

→ [13.1 Project Preview (Preview Without Building)](13-preview.md#131-project-preview-preview-without-building) ·
Related: [VM (virtual machine)](#vm-virtual-machine), [Monitor](#monitor)

### Properties

*プロパティ*

A panel listing the settings for the selected item (disc, timeline, menu, button, etc.). If nothing is selected, it
shows the disc's settings.

→ [4.3 Panels](04-screen.md#43-panels)

### PSD

Photoshop format images. Files that follow the layer naming conventions (groups starting with `(+)` become buttons,
etc.) can be used directly as menus.

→ [9.6 Rebuilding in PSD](09-menus.md#96-rebuilding-in-psd) · Related: [Layer Set](#layer-set), [Menu](#menu)

## 24.12 R

### Region Code

*リージョンコード*

The specification of regions where a DVD can be played. Choose All Regions or 1–8 (DVD only). Discs will not play in
players from other regions.

→ [14.4 Region and Parental Level](14-build.md#144-region-and-parental-level),
[18.4 Preview](18-preferences.md#184-preview) · Related: [Parental level](#parental-level),
[Copy protection](#copy-protection)

### Remote Menu

*リモートメニュー*

The menu that appears when the viewer presses the Menu button on the remote during playback. You set this for each
timeline. On Blu-ray, this becomes a Pop-up Menu.

→ [6.5 End Action, Override, Remote Menu](06-timelines.md#65-end-action-override-remote-menu) · Related:
[Pop-up Menu](#pop-up-menu), [Title Button](#title-button)

### Route

*ルート*

The path the highlight follows from button to button when the viewer presses the arrow keys. DiscCraft draws this
automatically, but you can also redraw it manually.

→ [17.3 Setting Routing and Numbers Manually](17-advanced.md#173-setting-routing-and-numbers-manually) · Related:
[Highlight](#highlight), [Button](#button)

## 24.13 S

### Safe area

*セーフエリア*

The area visible on a television without being cut off at the edges. Menu text, buttons, and subtitles should be placed
within this area (subtitle characters within the title safe area of 80% of the frame). Choose **View ▸ Show Safe Areas**
(Ctrl+6) to display the guides.

→ [4.3 Panels](04-screen.md#43-panels), [11.3 Appearance](11-subtitles.md#113-appearance) · Related:
[Menu Viewer](#menu-viewer)

### SD / HD

Standard definition (such as 720 × 480 for DVD) and high definition (1920 × 1080, 1280 × 720). DVDs support only SD,
while Blu-ray discs support both SD and HD.

→ [16. Making a Blu-ray Disc](16-bluray.md#16-making-a-blu-ray-disc) · Related:
[1080i / 1080p / 720p](#1080i--1080p--720p)

### Slideshow

*スライドショー*

A title that displays still images in sequence. You set the length (default 6 seconds) and transition for each slide,
and you can add music.

→ [7. Making Slideshows](07-slideshows.md#7-making-slideshows) · Related: [Transition](#transition),
[Duration](#duration)

### Subpicture

*サブピクチャ*

Low-color images overlaid on video in DVDs. They are used for menu button highlights and subtitles. You select the
colors for the three states (Standard, Selected, Activated) from a Color Set.

→ [9.4 Colors and Highlights](09-menus.md#94-colors-and-highlights) · Related: [Highlight](#highlight),
[Color Set](#color-set), [Activated](#activated)

### Subtitle Track

*字幕トラック*

The subtitle lanes in the Timeline. Each track contains subtitles for one language, which viewers can switch or turn off
using the remote control. You create them by importing a subtitle file or typing them in the Monitor.

→ [11. Subtitles](11-subtitles.md#11-subtitles) · Related: [Audio Track](#audio-track), [Color Set](#color-set)

## 24.14 T

### Timeline

*タイムライン*

Video, audio, and subtitles arranged along a time axis. It becomes one title on the disc and is divided by chapter
points.

→ [6. Making Timelines](06-timelines.md#6-making-timelines) · Related: [Timeline Viewer](#timeline-viewer),
[Clip](#clip), [Chapter](#chapter)

### Timeline Viewer

*タイムラインビューア*

The panel for editing timelines. Video, audio, and subtitle tracks are arranged in lanes, where you place clips and
chapter points.

→ [4.3 Panels](04-screen.md#43-panels), [6. Making Timelines](06-timelines.md#6-making-timelines) · Related:
[Timeline](#timeline)

### Title

*タイトル*

A single video program on the disc. In DiscCraft, each timeline, slideshow, and chapter playlist becomes one title.

→ [6. Making Timelines](06-timelines.md#6-making-timelines) · Related: [Timeline](#timeline), [Slideshow](#slideshow),
[Chapter Playlist](#chapter-playlist)

### Title Button

*タイトルボタン*

The destination when the viewer presses the Title button (Top Menu button) on the remote. You set this in the disc's
Properties, usually to the Main Menu.

→ [10.1 First Play and Title Button](10-navigation.md#101-first-play-and-title-button) · Related:
[First Play](#first-play), [Remote Menu](#remote-menu)

### Transcode

*トランスコード*

Converting assets that do not match the specifications into a format suitable for the disc (such as MPEG-2 and AC-3 for
DVD). This happens automatically during the build, but you can also do it in advance using **Transcode Now**. Converted
files are kept in the cache.

→ [5.3 About Assets](05-assets.md#53-about-assets) · Related: [Bitrate](#bitrate), [VBR / CBR](#vbr--cbr),
[Cache](#cache)

### Transition

*トランジション*

The effect used when switching slides (such as Cross Dissolve).

→ [7. Making Slideshows](07-slideshows.md#7-making-slideshows) · Related: [Slideshow](#slideshow)

### TV mode

*テレビモード*

The display method that adapts widescreen video to the shape of the television connected to the player. Options include
16:9 Widescreen, 4:3 Letterbox (bars on top and bottom), and 4:3 Pan & Scan (sides cropped). Select this in Preferences
when testing in Preview.

→ [18.4 Preview](18-preferences.md#184-preview) · Related: [Aspect ratio (16:9 / 4:3)](#aspect-ratio-169--43)

## 24.15 U–W

### User Operations

*ユーザー操作*

Allowing or forbidding viewer remote control operations (fast forward, chapter skip, moving to menus, etc.) for specific
scenes. This is used, for example, to prevent skipping warning videos.

→ [9.7 User Operations](09-menus.md#97-user-operations)

### VBR / CBR

Methods for setting the bitrate. VBR (Variable Bitrate) adjusts the data amount based on scene complexity, while CBR
(Constant Bitrate) keeps the data amount constant. Two-pass VBR analyzes the entire video once before conversion; it
takes twice as long but allocates more data to complex scenes.

→ [5.3 About Assets](05-assets.md#53-about-assets) · Related: [Bitrate](#bitrate), [Transcode](#transcode)

### VIDEO_TS

The folder containing the contents of a DVD disc. This is created when you select a folder as the destination during the
build.

→ [14.2 Destination](14-build.md#142-destination) · Related: [BDMV](#bdmv), [ISO image](#iso-image)

### VM (virtual machine)

The mechanism within a player that executes disc navigation (commands for buttons and End Actions). Project Preview
reproduces the same behavior as the disc using DiscCraft's VM.

→ [13.1 Project Preview (Preview Without Building)](13-preview.md#131-project-preview-preview-without-building) ·
Related: [Navigation](#navigation), [Project Preview](#project-preview)

### Workspace

*ワークスペース*

The arrangement of panels. You can save arrangements with names and switch between them using **Window ▸ Workspace**. If
the arrangement becomes disordered, you can reset it from there.

→ [4.4 Rearranging Panels and Workspaces](04-screen.md#44-rearranging-panels-and-workspaces)
