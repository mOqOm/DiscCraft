# 残りの課題と予定

[English](open-issues.md) | 日本語

DiscCraft がまだできないこと、予定していること、確認に協力してほしいことの一覧。2026-11-20 時点（0.1.0 のアルファ）。
動いた / 動かなかったの報告を歓迎します。

状態の言葉の意味:

| 状態 | 意味 |
|---|---|
| 予定 | すぐ取りかかれる |
| 大きい | 予定しているが、大きな作業 |
| 判断待ち | 方針・費用・やり方の選択の判断を待っている |
| 依存先 | DiscCraft が使うライブラリ（craft-libs）の側の作業が要る |
| 実機 | 実際のプレーヤーやドライブでの確認が要る |
| 保留 | 公開資料を待っている（DiscCraft は公開された仕様だけから作っている） |
| 対象外 | 予定していない |

## 1. ディスクへの書き込み

DiscCraft は VIDEO_TS / BDMV のフォルダーと ISO イメージを書き出す。ディスクに焼くのは、今は別のソフトに任せている。

| 状態 | 項目 |
|---|---|
| 大きい | Windows でビルド結果を DVD / Blu-ray に焼く（OS のディスク書き込みの機能を使う）。ドライブ・速度・枚数を選べるようにし、ビルドパネルの出力「ディスク」にする |
| 大きい | 2 層のディスク（DVD-9、BD-50）: イメージに入れた位置で層が切り替わるかを確かめる |
| 大きい | macOS と Linux での書き込み |
| 判断待ち | DDP の書き出し、両面ディスク |
| 実機 | 上のどれも、書き込みドライブと空のディスクでの確認が要る |

## 2. Blu-ray と HD

| 状態 | 項目 |
|---|---|
| 保留 | Blu-ray の視聴制限。DVD とは仕組みが違い（プレーヤーが持つのは 1〜8 のレベルではなく年齢）、ディスクのナビゲーションの命令がプレーヤーの設定を読む方法が、見つかった公開資料に書かれていない |
| 大きい | 2 つのフィールドが別々に動くインターレースの素材を、フィールドとして符号化する。MPEG-2 エンコーダーはインターレースのピクチャを作れるが、まだ画質が上がらなかったので、変換では使っていない |
| 大きい | HD の MPEG-2 をそのまま収録するときの残り: フィールドピクチャ、GOP 単位のトリム、ほかのクリップとのつなぎ、プログラムストリームの HD |
| 大きい | HD のモーションメニューを、ビルドの前にプレビューで動かす |
| 依存先 | 1080i の H.264 へのエンコード |
| 依存先 | インターレースの H.264（ビデオカメラやレコーダーの 1080i）のデコード: 今は絵を表示できず、DVD 用にも変換できない（Blu-ray へはそのまま収録でき、音は鳴る） |
| 判断待ち | DiscCraft のデコーダーが読めないものに、利用者が入れた ffmpeg を任意で使う（今の DiscCraft は ffmpeg を使っていない） |
| 依存先 | HD の MPEG-2 の B ピクチャ |
| 実機 | 実機の Blu-ray プレーヤーが求めることのある HRD / SEI の細部 |
| 判断待ち | 4K（Ultra HD Blu-ray） |
| 対象外 | DTS-HD、Dolby TrueHD のそのままの収録 |

## 3. DVD

| 状態 | 項目 |
|---|---|
| 予定 | 国ごとの視聴制限のマスク |
| 大きい | DVD 規格のパレンタルブロック（レベルでセルを選ぶ）。プレーヤーのレベルが足りないときに代わりに再生するものは、今もタイトルごとに指定できる |
| 判断待ち | マルチアングルのタイトル（Encore にはない機能） |
| 依存先 | VCD 形式の MPEG-1 のシステムストリームをメディアリーダーで開く（DiscCraft 側では回避済み） |

## 4. 取り込みと速さ

| 状態 | 項目 |
|---|---|
| 予定 | HD のメニュー（モーションメニュー）とタイトルの音の変換を並べて行う（HD のタイトルはすでに並べている） |
| 予定 | トランスポートストリームの HD の MPEG-2 を、キャッシュに写さずに多重化する（H.264 はすでにそうしている） |
| 予定 | 元の動画のデコードを区間に分けて並べる（エンコーダーのほうが遅いので、効き目は小さい） |
| 大きい | GPU での変換（拡大縮小と色の変換、ハードウェアエンコーダー）。先にライセンスを調べる |
| 依存先 | 大きな MKV / MP4 は、開くたびに索引を作る（18 GB で 15〜25 秒） |
| 依存先 | トランスポートストリームの索引を、次の起動まで残す |
| 依存先 | インターレースの H.264 のトランスポートストリームのチャプターのサムネール（上のデコードが要る） |

## 5. タイムライン・メニュー・パネル

| 状態 | 項目 |
|---|---|
| 予定 | アセットのプロパティに、変換になる理由を出す（例: H.264 のレベルが 4.1 を超える） |
| 予定 | ディスクに余裕があるとき、変換のビットレートを上げる |
| 予定 | ビデオクリップをトリム / 削除すると、横の音のクリップも一緒に切れる（Encore はリンクしている） |
| 予定 | オーディオトラックのない複数クリップのタイトル: ビルドでも各クリップの音を出す（プレビューでは今も鳴る） |
| 大きい | 段落の中で、文字ごとに書式を変える |
| 大きい | テキストの枠のオーバーセットの「＋」から、別の枠へテキストを流す |
| 判断待ち | メタデータの編集と書き戻し（DiscCraft は素材のファイルを書き換えない） |

## 6. リリースとパッケージ

| 状態 | 項目 |
|---|---|
| 予定 | 0.1.0-alpha.6 には x86_64 の Flatpak がない（ビルドに失敗した）。修正は次のリリースに入る |
| 実機 | `.msi` でのインストール、Arm64 版、macOS、Linux のパッケージ（AppImage、Flatpak、deb、rpm、Arch）は、実機で試していない |
| 判断待ち | Flatpak の OCI イメージでの公開 |
| 判断待ち | プログラムへの署名（初回は Windows の SmartScreen と macOS の Gatekeeper が確認を求める） |
| 対象外 | コピープロテクション（CSS、AACS） |

## 7. 実際のプレーヤーでの確認

| 状態 | 項目 |
|---|---|
| 実機 | 家庭用の DVD / Blu-ray プレーヤーでの再生 |
| 実機 | VLC は Blu-ray のハイライトを置いた位置より少し横に広く描き、DVD のメニューのサブピクチャはハイライトの部分しか描かない。VLC 自身の動きと思われる |
| 実機 | 途中のチャプターから始まる Blu-ray のチャプター再生リストで、ffmpeg が最初にエラーを出す |
